Anthropic의 AI 챗봇 Claude(클로드)를 쓰다 보면 "무료로 계속 써도 될까, 프로로 올리면 뭐가 달라질까"가 가장 먼저 궁금해집니다. 이 글은 클로드 가격을 처음 알아보는 분들께 무료와 프로의 차이, 그 위의 맥스·울트라 요금제, 팀 요금제, 결제와 환불 규칙을 한 번에 정리한 글입니다. 가격과 기능은 2026년 11월 Claude 공식 요금 페이지와 고객센터 기준입니다.

## 결론부터 — 클로드 가격 한눈에 보기

개인이 고를 수 있는 요금제는 무료, 프로(Pro), 맥스(Max), 울트라(Ultra) 네 가지입니다. 가격은 모두 미국 달러 기준이며 세금은 포함되어 있지 않습니다.

| 요금제 | 가격 (2026년 11월 기준) | 사용량 | 이런 분께 맞습니다 |
|---|---|---|---|
| 무료 (Free) | $0 | 5시간·주간 단위의 제한된 사용량 | 가끔 질문하고 글을 다듬는 분 |
| 프로 (Pro) | 월 $20, 연간 결제 시 월 $17 (연 $200 선결제) | 프로 기준 1배 | 매일 업무에 쓰는 분 |
| 맥스 (Max) | 월 $100 | 프로의 5배 | 긴 작업이나 Claude Code를 많이 쓰는 분 |
| 울트라 (Ultra) | 월 $200 | 주간 기준 프로의 10배 | 하루 종일 쓰는 개발자·전문가 |

정리하면, 가볍게 쓰는 용도라면 무료로 충분하고, 사용량 제한에 자주 걸리거나 Claude Code·프로젝트 기능이 필요할 때 월 20달러 프로를 고려하면 됩니다. 맥스와 울트라는 프로로도 사용량이 부족한 경우에 올리는 요금제입니다.

## 클로드 무료와 프로 차이

검색하는 분들이 가장 많이 비교하는 부분입니다. 공식 요금 페이지에 적힌 기능을 기준으로 나란히 놓으면 아래와 같습니다.

| 항목 | 무료 (Free) | 프로 (Pro) |
|---|---|---|
| 가격 | $0 | 월 $20 (연간 결제 시 월 $17) |
| 사용량 | 5시간·주간 단위로 제한 | 무료보다 많은 사용량 |
| 사용 가능한 모델 | Sonnet, Haiku | Opus, Sonnet, Haiku, Fable(사용량 크레딧으로 이용) |
| 웹 검색·파일 만들기·코드 실행 | 가능 | 가능 |
| 메모리·앱 연결(커넥터)·아티팩트 | 가능 | 가능 |
| 프로젝트(Projects) | 요금 페이지에는 프로 기능으로 표시 | 가능 |
| Claude Code | 불가 | 가능 |
| 작업 예약·맡기기 | 불가 | 가능 |
| Chrome·Microsoft 365 연동 | 불가 | 가능 |
| 사용량 크레딧(한도 초과 시 추가 이용) | 불가 | 가능 |

가장 크게 체감되는 차이는 두 가지입니다. 첫째는 **모델**입니다. 무료에서는 Sonnet과 Haiku만 쓸 수 있고, 가장 성능이 높은 Opus는 프로부터 쓸 수 있습니다. 둘째는 **사용량**입니다. 공식 고객센터는 프로가 무료보다 세션당 더 많은 사용량을 제공한다고 안내하며, 무료 사용량은 수요에 따라 달라질 수 있다고 밝히고 있습니다.

또 하나 알아 둘 점은 프로 구독에 **API 사용료가 포함되지 않는다**는 것입니다. 개발자가 자신의 서비스에 Claude를 붙이는 API는 Claude Console에서 따로 설정하고 따로 결제합니다.

## 클로드 사용량 제한은 어떻게 계산되나요

클로드 요금제는 "하루 몇 개 메시지"처럼 고정된 숫자로 안내되지 않습니다. 대신 5시간 단위의 세션 한도와 일주일 단위의 주간 한도가 함께 적용됩니다.

| 구분 | 내용 |
|---|---|
| 5시간 한도 | 무료·프로·맥스에 적용됩니다. 울트라는 인증된 계정이면 5시간 한도가 없습니다. |
| 주간 한도 | 모든 모델을 합쳐 일주일 단위로 적용되고, 계정마다 정해진 시각에 초기화됩니다. |
| Fable 주간 한도 | 맥스와 울트라에는 Fable 모델용 주간 한도가 따로 있습니다. |
| 한도에 영향을 주는 것 | 메시지 길이, 첨부 파일 크기, 대화 길이, 사용하는 모델과 기능 |
| 남은 사용량 확인 | 설정(Settings) → 사용량(Usage)에서 다음 초기화 시각을 볼 수 있습니다. |

같은 프로 요금제라도 긴 PDF를 여러 개 올리고 긴 대화를 이어 가면 한도에 빨리 도달합니다. 주제가 바뀌면 새 대화를 열고, 큰 파일은 필요한 부분만 올리면 같은 한도 안에서 더 오래 쓸 수 있습니다.

유료 요금제에서는 한도를 다 쓴 뒤에도 **사용량 크레딧(usage credits)** 을 켜 두면 계속 쓸 수 있습니다. 이때는 구독료와 별도로 API 표준 요금으로 청구되며, 설정의 사용량 메뉴에서 월 상한을 정할 수 있습니다. 공식 고객센터는 2026년 12월 7일 이후 구매한 크레딧은 구매 후 12개월이 지나면 만료된다고 안내합니다.

## 맥스·울트라 가격과 차이

프로로도 한도에 자주 걸린다면 맥스와 울트라를 비교해 볼 수 있습니다. 예전에는 맥스가 월 100달러(프로의 5배)와 월 200달러(프로의 20배) 두 단계로 나뉘어 있었지만, 현재 공식 요금 페이지에는 월 200달러 요금제가 울트라라는 이름으로 따로 표시됩니다. 예전 글에서 보던 "맥스 월 200달러"는 지금의 울트라에 해당합니다.

| 항목 | 맥스 (Max) | 울트라 (Ultra) |
|---|---|---|
| 가격 | 월 $100 | 월 $200 |
| 사용량 | 5시간·주간 모두 프로의 5배 | 주간 기준 프로의 10배 |
| 5시간 한도 | 있음 | 인증된 계정은 없음 |
| 포함 API 크레딧 | 월 $100 (Claude Platform) | 월 $200 (Claude Platform) |
| 결제 주기 | 월 결제만 가능 | 월 결제만 가능 |
| 그 밖의 혜택 | 새 기능 우선 이용, 혼잡 시간 우선 접속 | 맥스 혜택 모두 포함 |

울트라의 '인증된 계정'은 Anthropic이 계정과 결제 이력 등을 바탕으로 자동으로 판단합니다. 설정 → 사용량 화면에 '현재 세션(Current session)' 막대가 보이지 않으면 인증된 상태라고 공식 고객센터가 안내합니다. 맥스에서 울트라로 올리면 남은 결제 기간만큼 일할 계산해 청구됩니다.

## 팀·엔터프라이즈 요금제 가격

회사나 동아리처럼 여러 명이 함께 쓴다면 팀 요금제가 따로 있습니다. 팀 요금제는 기본적으로 대화 내용을 모델 학습에 쓰지 않고, 중앙 결제와 관리자 기능을 제공합니다.

| 요금제 | 가격 (좌석당) | 특징 |
|---|---|---|
| 팀 스탠다드 좌석 | 연간 결제 시 월 $20, 월 결제 시 월 $25 | 프로보다 많은 사용량, Claude Code 포함 |
| 팀 프리미엄 좌석 | 연간 결제 시 월 $100, 월 결제 시 월 $125 | 스탠다드 좌석의 5배 사용량 |
| 엔터프라이즈 | 연간 결제 시 월 $20 + API 요금 기준 사용료 | 최소 20좌석, 감사 로그·SCIM·접근 제어 등 |

팀 요금제는 스탠다드 좌석과 프리미엄 좌석을 섞어서 구성할 수 있습니다. 실제로 많이 쓰는 사람에게만 프리미엄 좌석을 배정하면 비용을 줄일 수 있습니다.

## 결제·세금·환불에서 주의할 점

클로드 가격은 지역마다 다르게 표시될 수 있습니다. 공식 고객센터는 지원되는 지역에서는 현지 통화로 가격을 보여 주며, 지역에 따라 세금이 표시 가격에 포함되기도 하고 결제 단계에서 더해지기도 한다고 안내합니다. 앱스토어나 구글 플레이로 결제하면 웹과 가격이 다를 수 있으므로 claude.ai/upgrade 화면의 금액과 비교해 보는 것을 추천합니다.

| 상황 | 공식 안내 내용 |
|---|---|
| 기본 환불 규칙 | 이용약관이나 법률이 정한 경우를 제외하면 결제 금액은 환불되지 않습니다. |
| EEA·영국 사용자 | 구매 후 14일 이내 환불 가능, 사용량에 따라 일할 계산 |
| 웹 결제 환불 요청 | 왼쪽 아래 이름 → Get help → Send us a message → Claude Refund Request 순서 |
| iOS 앱 결제 | 애플이 환불을 처리하므로 reportaproblem.apple.com에서 요청, 구독 해지는 따로 해야 함 |
| 안드로이드 앱 결제 | Claude 고객센터가 환불 가능 여부를 확인 |
| 사용량 크레딧 | 원칙적으로 환불 불가, 이미 쓴 크레딧은 환불되지 않음 |

한국 사용자를 위한 별도 환불 기간은 공식 환불 문서에 따로 적혀 있지 않습니다. 결제 전에 무료 요금제로 충분히 써 보고, 정말 한도가 부족할 때 월 결제로 시작하는 편이 안전합니다. 1년 이상 쓸 것이 확실할 때만 연간 결제를 고르면 프로 기준 연 40달러를 아낄 수 있습니다.

## 나에게 맞는 클로드 요금제 고르기

| 이런 경우 | 추천 요금제 | 이유 |
|---|---|---|
| 하루 몇 번 질문하고 글을 다듬음 | 무료 | Sonnet으로도 일상 작업은 충분 |
| 매일 업무 문서·블로그 초안을 씀 | 프로 월 결제 | Opus와 프로젝트 기능, 더 많은 사용량 |
| 1년 이상 꾸준히 쓸 계획 | 프로 연간 결제 | 월 $17로 월 결제보다 저렴 |
| Claude Code로 개발을 많이 함 | 맥스 | 프로의 5배 사용량 |
| 하루 종일 쉬지 않고 씀 | 울트라 | 인증 계정은 5시간 한도 없음 |
| 회사에서 여러 명이 함께 씀 | 팀 | 데이터 학습 미사용, 관리자 기능 |

요금제를 정했다면 활용법도 함께 익혀 두면 좋습니다. 클로드로 글 초안을 쓰는 순서와 프롬프트는 [클로드 블로그 글쓰기 프롬프트](../claude-blog-draft-writing/)에서, 비슷한 가격대의 AI 검색 서비스 요금 비교는 [퍼플렉시티 무료와 프로 차이](../perplexity-free-vs-pro/)에서 확인할 수 있습니다.

## 마무리

클로드 가격은 무료, 월 20달러 프로, 월 100달러 맥스, 월 200달러 울트라로 나뉩니다. 무료와 프로의 핵심 차이는 Opus 모델 사용 여부, 사용량, 그리고 Claude Code·프로젝트 같은 작업 기능입니다. 대부분은 무료로 시작해 한도가 자주 부족해질 때 프로로 올리는 순서가 무난하고, 맥스와 울트라는 프로로도 부족한 경우에만 고려하면 됩니다.

Anthropic은 요금제 이름과 한도를 자주 바꿉니다. 결제 전에는 공식 요금 페이지와 결제 화면에서 최신 가격과 조건을 다시 확인하시기 바랍니다.
