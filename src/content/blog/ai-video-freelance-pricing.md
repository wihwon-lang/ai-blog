AI 영상으로 외주를 받기 시작하면 가장 먼저 막히는 질문이 "얼마를 받아야 하지?"입니다. AI 영상은 촬영이 없어서 싸게 해 줘야 할 것 같지만, 기획과 생성 반복, 편집에 생각보다 많은 시간이 들어갑니다. 이 글은 AI 영상 외주를 시작하려는 분들께 단가를 계산하는 기준과 작업 범위를 정하는 방법을 정리한 글입니다.

## 시장 가격보다 내 원가부터 계산하기

외주 플랫폼에 올라온 다른 사람의 가격을 보고 단가를 정하는 경우가 많습니다. 하지만 같은 "30초 AI 영상"이라도 포함된 작업이 서로 달라서 가격만 비교하면 손해를 보기 쉽습니다. 그래서 먼저 **내가 한 건을 만드는 데 드는 원가**를 계산하고, 그 위에 이윤을 붙이는 방식을 추천합니다.

견적은 크게 네 가지 항목으로 나눠 생각하면 됩니다.

| 항목 | 내용 | 놓치기 쉬운 부분 |
|---|---|---|
| 작업 시간 | 기획, 프롬프트 작성, 생성, 편집, 수정에 드는 시간 | 마음에 드는 결과가 나올 때까지 다시 생성하는 시간 |
| 도구 비용 | AI 영상·음악·음성 도구의 구독료와 크레딧 | 실패한 생성에도 크레딧이 소모됨 |
| 소통 시간 | 미팅, 메시지 응대, 시안 공유 | 작업 시간만큼 걸리는 경우도 있음 |
| 이윤·여유분 | 위험 대비, 장비·학습 비용 | 일정 지연, 추가 요청 대비 |

AI 영상 도구는 요금제마다 크레딧 단가가 다르므로, 내가 쓰는 도구의 요금을 먼저 정리해 두면 계산이 쉬워집니다. 주요 도구의 요금은 [AI 영상 제작 도구 요금제 비교](../ai-video-tools-pricing-2026/)에서 한 번에 확인할 수 있습니다.

## 견적 계산 공식

단가는 아래 공식으로 계산할 수 있습니다.

```
견적 = (예상 작업 시간 × 내 시간당 단가) + 도구 비용 + 소통 시간 비용 + 여유분(10~30%)
```

시간당 단가는 스스로 정하는 값입니다. 참고로 2026년 최저임금은 고용노동부 고시 기준 시간급 10,320원입니다. 외주는 고용이 아니라서 최저임금이 그대로 적용되지는 않지만, 일이 없는 기간과 세금, 장비 비용을 스스로 감당해야 하므로 내 시간당 단가는 이보다 넉넉하게 잡는 것이 일반적입니다.

아래는 계산 방법을 보여 주기 위한 **가상의 예시**입니다. 실제 숫자는 각자의 작업 속도와 도구에 맞게 바꿔 넣으세요.

| 단계 | 예상 시간 (예시) | 비고 |
|---|---|---|
| 요청 파악·기획·콘티 | 2시간 | 대본, 장면 구성, 참고 이미지 정리 |
| 이미지·영상 생성 | 4시간 | 장면당 여러 번 생성 후 고르기 |
| 편집·자막·음악 | 2시간 | 컷 편집, 자막, 배경음악 |
| 수정 2회 | 2시간 | 범위 안의 수정 |
| 합계 | 10시간 | 소통 시간은 별도로 계산 |

예를 들어 시간당 단가를 3만 원으로 정했다면 작업비는 30만 원입니다. 여기에 이번 작업에 쓴 크레딧 비용과 소통 시간, 여유분 20%를 더하면 최종 견적이 나옵니다. 처음에는 예상 시간을 짧게 잡는 경우가 많으므로, 실제 작업 시간을 기록해 두고 다음 견적에 반영하는 습관이 중요합니다.

## 작업 유형별로 가격이 달라지는 요소

같은 길이의 영상이라도 아래 요소에 따라 작업량이 크게 달라집니다. 견적서를 쓰기 전에 의뢰 내용을 이 기준으로 확인하면 좋습니다.

| 요소 | 작업량이 적은 경우 | 작업량이 많은 경우 |
|---|---|---|
| 기획 | 대본·콘티를 클라이언트가 제공 | 기획부터 맡음 |
| 등장인물 | 인물 없음, 풍경·제품 위주 | 같은 인물이 여러 장면에 나옴 |
| 소스 이미지 | 클라이언트 제공 사진 사용 | 이미지부터 AI로 새로 생성 |
| 음성 | 자막만 사용 | AI 내레이션, 립싱크 포함 |
| 화면 비율 | 한 가지 비율 | 9:16, 16:9 등 여러 버전 |
| 브랜드 요소 | 로고 삽입 정도 | 제품 모양을 정확히 재현해야 함 |

특히 같은 인물을 여러 장면에서 유지해야 하는 작업이나, 실제 제품의 모양을 정확히 보여 줘야 하는 작업은 생성 반복 횟수가 늘어나기 쉽습니다. 이런 요소가 있으면 견적에 추가 시간을 반영하는 것이 좋습니다.

## 작업 범위와 수정 횟수 정하기

외주 분쟁의 상당수는 단가가 아니라 **작업 범위가 불분명해서** 생깁니다. 견적을 보낼 때 아래 항목을 함께 적어 두면 추가 요청이 왔을 때 기준이 됩니다.

| 정할 항목 | 적는 예 |
|---|---|
| 결과물 | 30초 영상 1개, 9:16 비율, MP4 |
| 포함 작업 | 콘티, AI 영상 생성, 편집, 자막, 저작권 문제없는 배경음악 |
| 제외 작업 | 성우 녹음, 실사 촬영, 원본 프로젝트 파일 제공 |
| 수정 횟수 | 시안 확정 후 2회까지 무료 |
| 추가 수정 | 3회차부터 회당 추가 비용, 장면 변경은 별도 견적 |
| 일정 | 콘티 확정 후 영업일 기준 며칠 안에 초안 전달 |
| 권리 범위 | 사용 매체와 기간, 포트폴리오 공개 가능 여부 |

AI 영상은 "조금만 다르게 다시 뽑아 주세요"라는 요청이 자주 나옵니다. 생성 결과는 매번 달라지기 때문에, 같은 장면을 다시 생성하는 것도 수정 1회로 볼지 미리 정해 두는 것이 좋습니다. 콘티 단계에서 장면 구성을 확정받으면 이후 수정 범위가 크게 줄어듭니다.

## 견적서와 계약서에 넣을 내용

작은 작업이라도 메시지로만 합의하기보다 간단한 견적서를 보내고 확인을 받아 두는 것을 추천합니다.

| 항목 | 이유 |
|---|---|
| 항목별 금액 | 기획, 생성, 편집을 나눠 적으면 가격 협상 때 무엇을 뺄지 정하기 쉬움 |
| 선금 비율 | 작업 중단 위험 대비. 착수 전 일부를 받는 방식이 흔함 |
| AI 사용 사실 | 클라이언트가 AI 제작임을 알고 동의했다는 기록 |
| 사용한 도구와 요금제 | 상업 이용 가능 여부를 설명할 근거 |
| 실존 인물·타사 로고 제외 | 초상권·상표권 문제 예방 |
| 세금 처리 방식 | 원천징수, 세금계산서 발행 여부를 미리 합의 |

AI 영상의 상업 이용 범위와 저작권은 도구 약관과 사람의 창작적 기여에 따라 달라집니다. 계약서에 권리 범위를 적기 전에 [AI 영상 상업적 이용·저작권 정리](../ai-video-copyright-commercial/)를 함께 읽어 보면 도움이 됩니다.

## 가격을 낮춰 달라는 요청에 대응하는 법

"AI로 만드는 건데 더 싸게 안 되나요?"라는 질문은 자주 나옵니다. 이때 무작정 깎아 주기보다 작업 범위를 조정해 가격을 맞추는 방법이 서로에게 부담이 적습니다.

| 요청 | 대응 방법 |
|---|---|
| 전체 금액을 낮춰 달라 | 수정 횟수를 줄이거나 기획을 클라이언트가 맡는 조건으로 조정 |
| 영상 여러 개를 묶어 할인해 달라 | 같은 콘티 틀을 재사용할 수 있으면 묶음 가격 제안 |
| 일단 싸게 해 주면 계속 맡기겠다 | 첫 건 금액을 낮추더라도 다음 건부터 적용할 정가를 견적서에 함께 적기 |
| 다른 곳은 더 싸다 | 포함 작업과 수정 횟수를 항목별로 비교해 설명 |

AI라서 빠르다는 인식이 있더라도, 결과물을 고르고 다듬는 시간은 사람이 들인다는 점을 견적서의 항목별 금액으로 보여 주면 설명이 쉬워집니다.

## 세금은 미리 알고 시작하기

개인 프리랜서로 외주를 받으면 클라이언트가 대가를 지급할 때 세금을 미리 떼고 주는 원천징수를 하는 경우가 많습니다. 2026년 10월 현재 인적용역 사업소득의 원천징수율은 소득세 3%와 지방소득세 0.3%를 더한 3.3%입니다.

| 구분 | 내용 |
|---|---|
| 현재 원천징수율 | 3.3% (소득세 3% + 지방소득세 0.3%) |
| 인하 추진 내용 | 2.2% (소득세 2% + 지방소득세 0.2%) |
| 적용 예정 시기 | 국회 통과 시 2027년 1월 1일 이후 발생 소득부터 |
| 연말 이후 할 일 | 다음 해 5월 종합소득세 신고로 실제 세금 정산 |

견적을 낼 때는 금액이 세금을 떼기 전 금액인지, 세금을 뗀 뒤 받는 금액인지 분명히 적어야 합니다. 사업자등록을 하고 세금계산서를 발행하는 경우에는 부가가치세 처리 방식이 달라지므로, 정확한 내용은 국세청 안내나 세무 전문가에게 확인하세요. 이 글은 일반적인 정보 정리이며 세무 자문이 아닙니다.

## 마무리

AI 영상 외주 단가는 다른 사람의 가격표보다 **내 작업 시간과 도구 비용**에서 출발해야 오래 할 수 있습니다. 작업 시간을 기록하고, 작업 범위와 수정 횟수를 견적서에 적고, 세금 처리 방식을 미리 합의하는 것만으로도 대부분의 분쟁을 줄일 수 있습니다.

처음에는 포트폴리오를 위해 낮은 가격으로 시작하더라도, 작업 기록이 쌓이면 그 데이터를 근거로 단가를 조정해 나가는 것을 추천합니다.
