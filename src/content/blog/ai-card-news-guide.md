카드뉴스는 인스타그램, 블로그, 사내 공지까지 두루 쓰이지만 기획하고 문구를 다듬고 디자인까지 하려면 한 세트에 몇 시간이 걸리기 쉽습니다. 이 글은 소상공인, 1인 마케터, SNS 운영 담당자를 위해 AI로 카드뉴스를 만드는 전체 순서를 정리합니다. 기획과 문구는 대화형 AI에, 디자인은 디자인 도구나 이미지 생성 AI에 나눠 맡기는 방식이며, 도구 정보는 2026년 10월 공식 안내를 기준으로 했습니다.

## 카드뉴스 작업, AI에 어디까지 맡길까

카드뉴스 한 세트는 주제 정하기, 장별 구성, 문구 쓰기, 디자인, 검수의 다섯 단계로 나눌 수 있습니다. 단계마다 AI가 잘하는 일과 사람이 직접 챙겨야 할 일이 다릅니다.

| 단계 | AI에 맡기기 좋은 일 | 사람이 직접 챙길 일 | 추천 도구 |
|---|---|---|---|
| 주제 정하기 | 타깃별 주제 후보 10~20개 뽑기 | 우리 계정·브랜드에 맞는지 고르기 | ChatGPT, Claude, Gemini |
| 장별 구성 | 표지-본문-마무리 흐름 짜기 | 장수와 핵심 메시지 확정 | ChatGPT, Claude |
| 문구 쓰기 | 장마다 제목·본문 초안, 짧게 줄이기 | 사실 확인, 브랜드 말투 맞추기 | ChatGPT, Claude |
| 디자인 | 템플릿 추천, 배경·일러스트 생성 | 글자 크기·가독성, 브랜드 색 | 캔바, 미리캔버스, 이미지 생성 AI |
| 검수 | 맞춤법·어색한 문장 찾기 | 숫자·출처·저작권 최종 확인 | 대화형 AI + 사람 |

가장 효율이 좋은 방법은 **문구를 먼저 완성하고 디자인은 나중에** 하는 것입니다. 문구가 정해지지 않은 상태에서 디자인부터 만들면 글자 수가 맞지 않아 레이아웃을 여러 번 고치게 되는 경우가 많습니다.

## 1단계: 주제와 장별 구성 짜기

카드뉴스는 한 장에 담을 수 있는 정보가 적기 때문에 **한 세트에 메시지 하나**가 원칙입니다. AI에 주제를 물을 때는 누가 볼지, 무엇을 얻어 가야 하는지를 함께 알려 주세요.

```
인스타그램 카드뉴스 주제를 정하려고 합니다.
- 계정: 동네 필라테스 스튜디오
- 독자: 운동을 막 시작하려는 30~40대 직장인
- 목적: 저장과 공유가 많이 되는 정보형 콘텐츠
주제 후보 15개를 표로 정리해 주세요.
열은 '주제 / 독자가 얻는 것 / 예상 장수'로 해 주세요.
```

주제를 골랐다면 장별 구성을 요청합니다. 정보형 카드뉴스는 보통 아래 같은 흐름을 많이 씁니다.

| 순서 | 역할 | 들어갈 내용 | 문구 분량 기준 |
|---|---|---|---|
| 1장 (표지) | 넘겨 보게 만들기 | 독자의 고민을 건드리는 제목, 부제 | 제목 15자 안팎 |
| 2장 | 문제 제기 | 왜 이 내용이 필요한지 | 2~3줄 |
| 3~7장 | 핵심 정보 | 한 장에 한 가지 팁·단계 | 소제목 1줄 + 본문 2~3줄 |
| 8장 | 요약 | 앞 내용을 한눈에 정리 | 목록 3~5개 |
| 마지막 장 | 행동 유도 | 저장·팔로우·문의 안내 | 1~2줄 |

인스타그램 캐러셀 게시물은 2024년 8월부터 한 번에 최대 20장까지 올릴 수 있습니다. 다만 장수가 많다고 좋은 것은 아니므로, 정보형은 6~10장 정도로 짜고 끝까지 넘겨 보게 만드는 데 집중하는 것을 추천합니다.

## 2단계: 장마다 들어갈 문구 쓰기

구성이 정해지면 장별 문구를 요청합니다. 이때 **글자 수 제한과 말투**를 분명히 적어야 디자인에 바로 옮길 수 있는 문구가 나옵니다.

```
아래 구성으로 카드뉴스 문구를 써 주세요.
주제: 운동 처음 시작할 때 흔히 하는 실수 5가지
조건:
- 총 8장, 장마다 '제목(15자 이내) / 본문(40자 이내, 2줄)'로 나눠 주세요.
- 존댓말, 쉬운 말, 전문 용어는 풀어서 설명
- 과장 표현("무조건", "100%")은 쓰지 마세요.
- 건강 관련 내용은 일반적인 정보 수준으로만 쓰고, 근거가 필요한 숫자는 넣지 마세요.
- 마지막 장은 '저장해 두고 다시 보세요'라는 행동 유도로 마무리해 주세요.
```

처음 받은 문구는 대체로 길거나 밋밋합니다. 아래처럼 다듬기 요청을 이어서 하면 완성도가 올라갑니다.

| 다듬기 목적 | 요청 문장 예시 |
|---|---|
| 더 짧게 | "각 장 본문을 25자 이내로 줄이고, 꼭 필요한 단어만 남겨 주세요." |
| 표지 제목 후보 늘리기 | "1장 제목을 질문형, 숫자형, 공감형으로 각각 3개씩 다시 써 주세요." |
| 말투 맞추기 | "아래 기존 게시물 문구의 말투를 참고해서 전체를 다시 써 주세요." |
| 중복 줄이기 | "장끼리 겹치는 표현이 있으면 찾아서 다른 표현으로 바꿔 주세요." |
| 캡션 만들기 | "이 카드뉴스를 올릴 때 쓸 캡션 3가지와 해시태그 10개를 추천해 주세요." |

숏폼 영상 대본도 같은 방식으로 장면을 나눠 요청하면 됩니다. 영상용 구성이 궁금하다면 [ChatGPT로 숏폼 대본·콘티 짜는 법](../chatgpt-shorts-script/)도 함께 참고하세요.

## 3단계: 디자인 도구 고르기

문구가 완성되면 디자인으로 넘어갑니다. 방법은 크게 디자인 도구의 템플릿을 쓰는 방법과 이미지 생성 AI로 그림을 만드는 방법이 있습니다.

| 구분 | 캔바(Canva) | 미리캔버스 | ChatGPT 이미지 생성 | Gemini 나노바나나 |
|---|---|---|---|---|
| 작업 방식 | 템플릿 + Magic Studio AI 기능 | 한국어 템플릿 + AI 기능 | 대화로 이미지 생성·수정 | 대화로 이미지 생성·수정 |
| 강점 | 템플릿이 많고 여러 장을 한 번에 관리 | 한글 폰트와 국내용 템플릿이 많음 | 2026년 4월 Images 2.0에서 글자 표현과 인포그래픽 생성이 개선됨 | 한글 문구를 넣은 이미지와 인포그래픽 예시를 공식 안내 |
| 글자 수정 | 텍스트를 그대로 고칠 수 있음 | 텍스트를 그대로 고칠 수 있음 | 이미지 속 글자는 다시 생성해야 함 | 이미지 속 글자는 다시 생성해야 함 |
| 잘 맞는 용도 | 꾸준히 올리는 시리즈물 | 국내 소상공인·기관 홍보물 | 표지 일러스트, 배경 그림 | 표지 일러스트, 배경 그림 |
| AI 사용 한도 | 요금제별 월간 한도 | 요금제별 한도 | 요금제별 한도 | 요금제별 한도 |

요금과 AI 사용 한도는 요금제와 결제 경로에 따라 자주 바뀌므로 각 서비스의 공식 요금 페이지에서 확인하세요. 캔바는 설정의 결제(Billing) 메뉴에서 남은 AI 사용량을 볼 수 있다고 안내합니다.

추천하는 방법은 **글자는 디자인 도구에서, 그림은 이미지 생성 AI에서** 만드는 조합입니다. OpenAI와 구글 모두 이미지 속 글자 표현이 좋아졌다고 밝히고 있지만, 구글 공식 안내에서도 작은 글씨나 철자가 완벽하지 않을 수 있다고 설명합니다. 문구를 이미지 안에 넣어 생성하면 오타 하나를 고치려고 그림 전체를 다시 만들어야 하는 경우가 생깁니다. 이미지 도구 선택이 고민된다면 [미드저니 vs 나노바나나 비교](../midjourney-vs-nano-banana/) 글이 도움이 됩니다.

## 4단계: 디자인 만들기와 이미지 프롬프트

인스타그램용 카드뉴스는 세로형 4:5 비율, 1080×1350픽셀이 널리 쓰이는 크기입니다. 캐러셀은 첫 장의 비율을 나머지 장이 따르므로 모든 장을 같은 크기로 만드는 것이 안전합니다. 디자인 도구에서 작업할 때는 아래 순서를 추천합니다.

| 순서 | 할 일 | 요령 |
|---|---|---|
| 1 | 캔버스 크기 정하기 | 인스타그램은 4:5 세로형, 블로그 본문용은 1:1도 많이 씀 |
| 2 | 템플릿 고르기 | 정보형이면 글 영역이 넓은 템플릿 선택 |
| 3 | 브랜드 색·폰트 지정 | 색은 2~3개, 폰트는 제목용·본문용 2개로 제한 |
| 4 | 문구 붙여넣기 | 2단계에서 만든 장별 문구를 그대로 옮기기 |
| 5 | 표지 이미지 넣기 | 이미지 생성 AI로 만든 그림을 배경이나 일러스트로 배치 |
| 6 | 전체 장 맞추기 | 제목 위치, 쪽 번호, 로고 위치를 모든 장에서 통일 |

표지 그림을 이미지 생성 AI로 만들 때는 **글자 없이** 요청하고, 문구가 들어갈 빈 공간을 지정하는 것이 핵심입니다.

```
인스타그램 카드뉴스 표지 배경 이미지를 만들어 주세요.
- 비율: 4:5 세로형
- 장면: 밝은 필라테스 스튜디오에서 매트를 펼치는 사람, 뒷모습
- 스타일: 부드러운 자연광, 파스텔 톤 플랫 일러스트
- 구도: 아래쪽 1/3에 인물, 위쪽 2/3는 제목을 넣을 수 있게 비워 둘 것
- 이미지 안에 글자, 로고, 워터마크를 넣지 마세요.
```

구도와 조명 용어를 더 알고 싶다면 [AI 이미지 프롬프트 기본 공식](../ai-image-prompt-formula/)에 정리된 표현을 그대로 가져다 쓸 수 있습니다.

## 5단계: 발행 전 검수 체크리스트

AI가 만든 문구와 그림은 그럴듯해 보여도 틀린 정보나 어색한 부분이 섞여 있을 수 있습니다. 올리기 전에 아래 항목을 한 번씩 확인하세요.

| 확인 항목 | 확인 방법 | 자주 생기는 문제 |
|---|---|---|
| 숫자·통계 | 출처를 직접 찾아 대조 | AI가 그럴듯한 수치를 만들어 냄 |
| 맞춤법 | 대화형 AI에 "맞춤법과 띄어쓰기만 고쳐 주세요" 요청 후 사람이 재확인 | 띄어쓰기 오류, 어색한 번역투 |
| 이미지 속 글자 | 확대해서 한 글자씩 확인 | 철자 깨짐, 없는 글자 생성 |
| 가독성 | 휴대폰 화면에서 직접 넘겨 보기 | 글자가 작거나 배경과 색이 겹침 |
| 인물·손 표현 | 그림을 확대해서 확인 | 손가락 개수, 얼굴 왜곡 |
| 저작권·초상권 | 실존 인물·브랜드 로고가 들어갔는지 확인 | 유명인과 닮은 얼굴, 다른 회사 로고 |
| 전문 분야 내용 | 건강·법률·금융 정보는 공식 자료와 대조 | 일반화된 조언이 사실처럼 표현됨 |

건강, 금융, 법률처럼 독자에게 영향이 큰 주제는 AI 문구를 그대로 쓰지 말고 공신력 있는 기관 자료로 한 번 더 확인하는 것을 추천합니다. 상업용 게시물에 AI 이미지를 쓸 때는 각 서비스의 이용약관에서 상업적 이용 조건도 확인해 두세요.

## 시리즈로 꾸준히 만드는 요령

카드뉴스는 한 번 만들고 끝나기보다 매주 같은 형식으로 올릴 때 효과가 쌓이는 경우가 많습니다. 한 번 만든 작업 흐름을 재사용할 수 있게 정리해 두면 다음 세트부터는 시간이 크게 줄어듭니다.

| 재사용할 것 | 저장 방법 | 다음 작업에서 쓰는 법 |
|---|---|---|
| 문구 요청 프롬프트 | 메모장이나 대화형 AI의 프로젝트 지침에 저장 | 주제만 바꿔서 그대로 요청 |
| 디자인 템플릿 | 디자인 도구에서 완성본을 복제 | 문구와 그림만 교체 |
| 표지 이미지 프롬프트 | 스타일 문장을 고정해 두기 | 장면만 바꿔서 같은 톤 유지 |
| 검수 체크리스트 | 위 표를 저장해 두기 | 발행 전마다 같은 순서로 확인 |
| 캡션·해시태그 | 자주 쓰는 해시태그 묶음 저장 | 주제별로 일부만 바꾸기 |

ChatGPT나 Claude의 프로젝트 기능에 계정 소개, 독자, 말투, 금지 표현을 지침으로 넣어 두면 새 주제를 줄 때마다 같은 기준으로 문구가 나옵니다. 프로젝트 세팅 방법은 [Claude로 블로그 글 초안 쓰는 법](../claude-blog-draft-writing/)에서 설명한 방식을 카드뉴스에도 그대로 적용할 수 있습니다.

## 마무리

AI로 카드뉴스를 만들 때는 기획과 문구는 대화형 AI에, 글자 배치는 캔바나 미리캔버스 같은 디자인 도구에, 표지 그림은 이미지 생성 AI에 나눠 맡기는 방식이 가장 고치기 쉽습니다. 문구를 먼저 완성하고, 이미지는 글자 없이 생성하고, 올리기 전에 숫자와 글자를 사람이 확인하는 세 가지만 지켜도 완성도가 눈에 띄게 달라집니다. 처음에는 6~8장짜리 정보형 카드뉴스 한 세트로 시작해 보고, 쓸 만한 프롬프트와 템플릿을 저장해 시리즈로 이어 가는 것을 추천합니다.
