AI 프로필 사진 만들기는 셀카 한 장만 있으면 사진관에 가지 않고도 깔끔한 증명사진풍 사진이나 SNS용 일러스트 프로필을 얻을 수 있어 많이 찾는 작업입니다. 이 글은 돈을 들이지 않고 AI 프로필 사진을 만들고 싶은 분을 위해, 무료로 쓸 수 있는 도구와 만드는 순서, 바로 복사해 쓰는 프롬프트 예시를 2026년 11월 기준으로 정리했습니다. 얼굴이 내가 아닌 것처럼 바뀌는 문제와 개인정보 설정까지 함께 다룹니다.

## AI 프로필 사진, 무료로 만들 수 있을까

결론부터 말하면 **무료로 만들 수 있습니다.** 구글 Gemini 앱의 이미지 모델(나노바나나)과 ChatGPT의 이미지 기능은 무료 계정에서도 사진을 올려 편집할 수 있습니다. 다만 하루에 만들 수 있는 양에 한도가 있고, 그 숫자는 두 회사 모두 공식적으로 고정해 밝히지 않습니다.

| 방법 | 무료 가능 여부 | 특징 | 알아 둘 점 |
|---|---|---|---|
| Gemini 앱 (나노바나나 2) | 가능 | 사진을 올리고 말로 배경·옷·조명을 바꾸는 편집에 강함 | 무료는 기본 한도, 유료 플랜은 한도가 높고 상위 모델 사용 |
| ChatGPT 이미지 생성 | 가능 | 대화로 여러 번 고치기 편하고 일러스트 변환도 자연스러움 | 무료는 생성 횟수가 가장 적음 |
| 유료 AI 프로필 앱 | 일부 무료 체험 | 사진 여러 장을 올리면 정해진 콘셉트로 묶어서 만들어 줌 | 대부분 건당 또는 구독 결제, 앱마다 조건이 다름 |

2026년 11월 기준 구글 공식 Gemini 안내에 따르면 **나노바나나 2는 무료로 제공**되고, 더 높은 성능의 나노바나나 2.1은 Google AI 유료 플랜에서 쓸 수 있습니다. 무료 사용자는 '기본 한도'가 적용되고, AI Plus는 2배, AI Pro는 4배 높은 한도가 주어진다고 안내되어 있습니다. ChatGPT는 2026년 9월 공개된 Images 2.5를 무료를 포함한 모든 요금제에 제공한다고 발표했지만, 무료 계정은 유료보다 만들 수 있는 양이 적습니다.

프로필 사진처럼 몇 장만 필요한 작업이라면 무료 한도로도 충분한 경우가 많습니다. 한도에 걸리면 몇 시간 뒤나 다음 날 다시 시도하면 됩니다.

## 원본 사진 고르는 기준

AI 프로필 사진의 결과는 원본 사진에서 대부분 결정됩니다. AI는 올린 사진에서 얼굴 정보를 읽어 새 이미지를 만들기 때문에, 얼굴이 작거나 흐리면 다른 사람처럼 나올 가능성이 커집니다.

| 항목 | 좋은 원본 | 피해야 할 원본 |
|---|---|---|
| 얼굴 크기 | 얼굴이 화면의 3분의 1 이상 | 전신 사진, 단체 사진 속 작은 얼굴 |
| 각도 | 정면 또는 살짝 비스듬한 각도 | 아래에서 올려 찍은 셀카, 옆모습 |
| 조명 | 창가의 고른 자연광 | 역광, 한쪽만 어두운 사진 |
| 가림 | 얼굴 전체가 보임 | 선글라스, 마스크, 손으로 가린 얼굴 |
| 화질 | 흔들림 없는 원본 파일 | 메신저로 여러 번 전달돼 뭉개진 사진 |
| 표정 | 평소 표정, 가벼운 미소 | 과장된 표정, 눈을 감은 사진 |

필터 앱으로 이미 보정한 사진보다 **보정하지 않은 원본**을 쓰는 편이 좋습니다. 보정된 얼굴을 기준으로 AI가 한 번 더 바꾸면 실제 모습과 거리가 더 멀어집니다.

## 제미나이 나노바나나로 만드는 순서

Gemini 앱은 사진을 올리고 바꿀 부분을 문장으로 적는 방식이라, 프로필 사진처럼 "얼굴은 그대로, 배경과 옷만 바꾸기" 작업에 잘 맞습니다.

| 순서 | 할 일 | 요령 |
|---|---|---|
| 1 | Gemini 앱이나 웹(gemini.google.com)에 구글 계정으로 로그인 | 모바일 앱과 웹 모두 가능 |
| 2 | 입력창의 이미지 추가 버튼으로 원본 사진 업로드 | 사진은 한 장부터 시작 |
| 3 | 원하는 프로필 스타일을 문장으로 입력 | 아래 프롬프트 예시를 복사해 단어만 변경 |
| 4 | 결과를 보고 한 가지씩 고쳐 달라고 요청 | "조명만 더 밝게"처럼 한 번에 하나만 |
| 5 | 마음에 드는 결과를 다운로드 | 프로필 칸에 맞춰 정사각형으로 잘라 사용 |

Gemini로 만든 이미지에는 AI 생성 이미지임을 알리는 **보이지 않는 SynthID 워터마크와 눈에 보이는 워터마크**가 함께 들어간다고 구글은 안내합니다. 사진 보정에 쓰는 나노바나나 프롬프트를 더 보고 싶다면 [나노바나나 사용법](../nano-banana-photo-editing-guide/) 글을 참고하세요.

## ChatGPT로 만드는 순서

ChatGPT도 사진을 올리고 원하는 스타일을 적으면 프로필 이미지를 만들어 줍니다. 대화를 이어 가며 여러 번 고치기 편해서, 일러스트·캐릭터풍 프로필을 만들 때 많이 씁니다.

1. ChatGPT에 로그인한 뒤 입력창의 첨부 버튼으로 원본 사진을 올립니다.
2. "이 사진으로 프로필 사진을 만들어 줘"처럼 목적을 먼저 말하고, 배경·옷·스타일을 이어서 적습니다.
3. 결과에서 바꾸고 싶은 부분만 다시 요청합니다.
4. 마음에 드는 이미지를 다운로드합니다.

이미지 안에 이름이나 직함 같은 한글 문구를 넣고 싶다면 문구를 따옴표로 감싸 정확히 적는 것이 좋습니다. 자세한 요령은 [챗GPT 이미지 생성 사용법](../chatgpt-image-generation-korean-text/) 글에 정리해 두었습니다.

## 용도별 AI 프로필 사진 프롬프트 예시

프롬프트는 **얼굴 유지 요청 + 배경 + 옷 + 조명 + 구도** 순서로 쓰면 결과가 안정적입니다. 아래 예시는 Gemini와 ChatGPT 모두에서 그대로 쓸 수 있습니다.

**증명사진·이력서풍 프로필**

```
첨부한 사진 속 인물의 얼굴 생김새, 헤어스타일, 피부 톤은 그대로 유지해 줘.
밝은 회색 단색 배경의 스튜디오 증명사진처럼 바꿔 줘.
옷은 단정한 남색 재킷과 흰 셔츠로, 조명은 정면에서 부드럽게.
어깨 위까지 보이는 정면 구도, 세로 3:4 비율.
```

**링크드인·회사 소개용 비즈니스 프로필**

```
첨부한 사진 속 인물의 얼굴은 바꾸지 말고 그대로 유지해 줘.
배경은 흐릿하게 처리된 밝은 사무실, 자연스러운 창가 빛.
옷은 깔끔한 니트 또는 셔츠, 편안한 미소.
가슴 위까지 보이는 구도, 정사각형 비율, 실제 사진처럼 자연스럽게.
```

**카카오톡·인스타그램 감성 프로필**

```
첨부한 사진 속 인물의 얼굴과 표정은 유지하고,
배경을 해 질 녘 바닷가로 바꿔 줘.
따뜻한 역광이 머리카락 가장자리에 살짝 비치게, 필름 카메라 느낌의 색감.
얼굴이 중앙에 오는 정사각형 구도.
```

**일러스트·캐릭터 프로필**

```
첨부한 사진 속 인물을 부드러운 수채화 일러스트로 바꿔 줘.
헤어스타일, 안경, 옷 색은 사진과 같게 유지해 줘.
배경은 연한 하늘색 단색, 어깨 위까지 보이는 정면 구도, 정사각형 비율.
```

스타일을 바꾸고 싶을 때는 마지막 줄의 단어만 바꾸면 됩니다.

| 원하는 느낌 | 바꿔 넣을 표현 |
|---|---|
| 깔끔한 증명사진 | 밝은 회색 단색 배경, 정면 스튜디오 조명 |
| 신뢰감 있는 비즈니스 | 흐릿한 사무실 배경, 재킷 또는 셔츠 |
| 따뜻한 감성 | 해 질 녘 역광, 필름 카메라 색감 |
| 귀여운 캐릭터 | 3D 애니메이션 캐릭터 스타일, 둥근 얼굴선 |
| 차분한 그림 | 수채화 일러스트, 연한 파스텔 배경 |
| 흑백 인물 사진 | 흑백 인물 사진, 대비가 강한 측면 조명 |

남성·여성 프로필에 따로 정해진 프롬프트가 있는 것은 아닙니다. 옷차림과 헤어스타일만 원하는 대로 구체적으로 적으면 됩니다. 프로필 외에 피규어 만들기, 그림체 변환 예시는 [나노바나나 프롬프트 모음](../nano-banana-prompt-collection/)에서 볼 수 있습니다.

## 얼굴이 달라질 때 고치는 법

AI 프로필 사진에서 가장 흔한 불만은 "잘 나왔는데 내가 아니다"입니다. 원인과 고치는 방법을 정리하면 다음과 같습니다.

| 증상 | 주된 원인 | 해결 방법 |
|---|---|---|
| 다른 사람처럼 보임 | 얼굴 유지 요청이 없거나 원본 얼굴이 작음 | 첫 줄에 "얼굴 생김새를 그대로 유지"를 넣고, 얼굴이 큰 사진으로 다시 시도 |
| 피부가 지나치게 매끈함 | 보정 효과가 강하게 적용됨 | "피부 결과 점을 자연스럽게 유지, 과한 보정 없이" 추가 |
| 나이가 달라 보임 | 스타일 단어가 인상을 바꿈 | "나이와 인상은 원본과 같게" 추가 |
| 여러 번 고칠수록 점점 달라짐 | 수정본을 기준으로 계속 바뀜 | 새 대화에서 원본 사진으로 다시 시작 |
| 손이나 어깨 모양이 어색함 | 구도가 넓어 신체가 많이 보임 | 어깨 위까지 보이는 구도로 좁히기 |
| 배경과 인물이 합성한 티가 남 | 조명 방향이 맞지 않음 | "배경 빛 방향에 맞춰 얼굴 조명도 조정" 추가 |

한 번에 여러 가지를 고쳐 달라고 하면 얼굴까지 함께 바뀌기 쉽습니다. **한 번에 한 가지만** 요청하고, 마음에 드는 중간 결과가 나오면 바로 저장해 두는 것을 추천합니다.

## 쓰기 전에 확인할 개인정보와 사용 범위

얼굴 사진은 민감한 개인정보입니다. 올리기 전에 서비스의 데이터 설정을 확인하는 것이 좋습니다.

| 항목 | 확인할 내용 |
|---|---|
| Gemini 활동 기록 | 'Keep Activity'가 켜져 있으면 대화와 업로드한 내용이 저장되고, 구글 서비스 개선과 AI 모델 학습에 쓰일 수 있으며 일부는 사람 검토자가 볼 수 있음 |
| Gemini 기록 끄기 | Gemini 앱 활동 설정에서 끌 수 있으며, 끈 뒤에도 대화는 응답과 안전을 위해 최대 72시간 보관됨 |
| ChatGPT 데이터 설정 | 설정의 데이터 제어 메뉴에서 모델 개선에 내 대화를 쓰지 않도록 바꿀 수 있음 |
| 다른 사람 사진 | 본인 동의 없이 타인의 얼굴로 프로필을 만들어 쓰지 않기 |
| 공식 증명사진 | 여권·신분증·자격증 사진은 기관마다 촬영·보정 기준이 있으므로 AI로 바꾼 사진이 맞는지 해당 기관 기준을 먼저 확인 |
| 이력서·채용용 | 실제 모습과 크게 다르면 오해를 살 수 있으므로 배경·옷 정리 정도로만 쓰는 편이 안전 |

AI로 만든 이미지를 상업적으로 쓰거나 판매할 계획이라면 저작권 문제도 따져 봐야 합니다. 이 부분은 [AI 그림 저작권](../ai-image-copyright-commercial/) 글에서 자세히 다뤘습니다.

## 마무리

AI 프로필 사진 만들기는 Gemini의 나노바나나 2나 ChatGPT 이미지 기능으로 무료로 시작할 수 있습니다. 결과를 좌우하는 것은 얼굴이 크고 밝게 나온 원본 사진, 그리고 프롬프트 첫 줄의 "얼굴 생김새를 그대로 유지" 요청입니다. 배경·옷·조명은 한 번에 하나씩 고치고, 얼굴이 점점 달라지면 새 대화에서 원본으로 다시 시작하세요. 무료 한도와 제공 모델은 자주 바뀌므로 많이 만들 계획이라면 각 서비스의 공식 안내를 확인하시기 바랍니다.
