퍼플렉시티(Perplexity)는 질문하면 웹을 검색해 출처 번호와 함께 답을 정리해 주는 AI 검색 서비스입니다. 처음 써 보는 분들이 가장 많이 묻는 것은 퍼플렉시티 무료로 계속 써도 충분한지, 월 20달러짜리 프로로 올리면 무엇이 달라지는지입니다. 이 글은 2026년 11월 기준 퍼플렉시티 공식 고객센터 내용을 바탕으로 무료 플랜의 범위, 요금제별 차이, 할인을 받을 수 있는 방법을 정리했습니다.

## 결론부터 — 퍼플렉시티 무료로 되는 것과 안 되는 것

일상적인 검색과 간단한 자료 조사라면 무료 플랜으로도 충분히 쓸 수 있습니다. 다만 무료 플랜은 더 깊게 조사하는 **프로 검색(Pro Search)** 이 아주 적게 주어지고, GPT·Claude·Gemini 같은 고급 모델을 직접 고를 수 없습니다.

| 질문 | 답 (2026년 11월 기준) |
|---|---|
| 무료로 기본 검색을 계속 쓸 수 있나요? | 공식 고객센터는 무료 플랜의 기본 검색을 "사실상 무제한"으로 안내합니다. |
| 무료에서도 프로 검색이 되나요? | 됩니다. 다만 "매우 제한된 횟수"로 안내되어 있습니다. |
| 고급 모델(GPT, Claude, Gemini)을 고를 수 있나요? | 무료 플랜에서는 직접 고를 수 없고, 퍼플렉시티가 질문에 맞는 모델을 자동으로 고릅니다. |
| 이미지 생성이 되나요? | 무료 플랜에서는 이용할 수 없습니다. |
| 파일 업로드가 되나요? | 기본 업로드는 되지만 횟수가 제한됩니다. |
| 프로는 얼마인가요? | 월 20달러 또는 연 200달러입니다. |

무료 프로 검색이 하루 정확히 몇 번인지는 공식 고객센터에 숫자로 나와 있지 않습니다. 인터넷에는 하루 3회, 5회 등 여러 숫자가 돌아다니지만 시점마다 다르게 보고되므로, 남은 사용량은 자신의 계정 화면에서 확인하는 것이 가장 정확합니다.

## 퍼플렉시티 무료와 프로 차이

공식 고객센터의 '어떤 요금제가 맞을까요' 문서를 기준으로 무료(Standard)와 프로를 나란히 놓으면 아래와 같습니다.

| 항목 | 무료 (Standard) | 프로 (Pro) |
|---|---|---|
| 기본 검색 | 사실상 무제한 | 사실상 무제한 |
| 프로 검색 | 매우 제한된 횟수 | 확장된 이용 (요금제 한도 내) |
| AI 모델 선택 | 자동 선택(Best)만 가능 | GPT-5.2, Claude Sonnet 4.6, Gemini 3.1 Pro 등 선택 가능 |
| 답변당 인용 출처 | 기본 | 공식 안내 기준 10배 많은 인용 |
| 파일·이미지 업로드 | 기본(제한적) | 업로드·분석 한도 확대, 프로젝트당 최대 50개 파일 |
| 이미지 생성 | 이용 불가 | 이용 가능 |
| 영상 생성 | 이용 불가 | 제한적으로 이용 가능 |
| 파일·앱 만들기 | 안내 없음 | 30일마다 제한된 횟수 |
| 지원 | 일반 | 프로 전용 디스코드 채널, 우선 문의 |

프로 검색은 따로 켜는 버튼이 없습니다. 검색창에서 **Search**를 고르고 질문하면, 요금제에 포함된 한도 안에서 자동으로 프로 검색이 적용됩니다. 질문을 여러 단계로 나눠 조사하고 더 많은 출처를 읽기 때문에, 비교·분석처럼 손이 많이 가는 질문에서 차이가 크게 납니다.

또 프로라도 고급 모델은 사용량이 아주 많은 주간에 제한될 수 있다고 공식 문서에 적혀 있습니다. 반면 자동 선택 모드인 'Best'는 횟수 제한 없이 쓸 수 있다고 안내합니다.

## 퍼플렉시티 요금제 한눈에 보기

개인용과 기업용 요금제를 함께 정리했습니다. 가격은 공식 고객센터에 표시된 미국 달러 기준입니다.

| 요금제 | 가격 | 대상 | 핵심 차이 |
|---|---|---|---|
| 무료 (Standard) | $0 | 가볍게 검색하는 개인 | 기본 검색 중심, 프로 검색 소량 |
| 프로 (Pro) | 월 $20 / 연 $200 | 매일 조사·정리가 필요한 개인 | 고급 모델 선택, 프로 검색 확대, 이미지 생성 |
| 교육용 프로 (Education Pro) | 월 $10 | 인증된 학생·교직원 | 프로 기능 전체 + 학습 모드 |
| 맥스 (Max) | 월 $200 / 연 $2,000 | 사용량이 아주 많은 전문가 | 최고 수준 모델 접근, 파일·앱 만들기 한도 확대, 우선 지원 |
| 엔터프라이즈 프로 | 좌석당 월 $40 / 연 $400부터 | 회사·조직 | 데이터 학습 미사용, 좌석 관리, 사내 자료 검색 |

연간 결제를 고르면 프로는 연 200달러로, 월 결제 12개월(240달러)보다 40달러 저렴합니다. 맥스의 연간 결제는 웹에서만 가능하다고 안내되어 있습니다.

웹사이트(perplexity.ai)에서 구독하면 결제 화면에서 **달러 또는 현지 통화**를 고를 수 있습니다. 한 번 고른 통화는 이후 정기 결제에도 그대로 쓰이고, 통화를 바꾸려면 구독을 해지한 뒤 다시 가입해야 합니다. 앱스토어나 구글 플레이에서 결제하면 이 선택이 적용되지 않고 스토어 가격으로 결제됩니다.

한편 여러 단계 작업을 대신 해 주는 '퍼플렉시티 컴퓨터(Computer)'는 별도의 **크레딧**을 씁니다. 공식 안내 기준 100크레딧이 1달러이고, 유료 프로 플랜에는 매주 일정량의 컴퓨터 사용량이 포함되어 크레딧을 쓰기 전에 먼저 소진됩니다.

## 퍼플렉시티 할인 받는 법

정가보다 싸게 쓰고 싶다면 아래 방법을 확인해 보세요. 예전에 있던 방법 중 이미 끝난 것도 함께 정리했습니다.

| 방법 | 내용 | 2026년 11월 기준 상태 |
|---|---|---|
| 연간 결제 | 프로를 연 200달러로 결제 | 이용 가능 |
| 교육용 프로 | 학생·교직원 인증 시 월 10달러 (프로 대비 50%) | 이용 가능 |
| 제휴 프로모션 코드 | 통신사·카드사 등 파트너가 배포하는 할인·무료 코드 | 시기마다 다름 |
| 친구 추천 "한 달 주고 한 달 받기" | 추천 링크로 가입하면 서로 1개월 무료 | 2025년 10월 6일 종료 |
| 코멧(Comet) 추천 프로그램 | 코멧 브라우저 추천 보상 | 2025년 11월 6일 종료 |
| 국가·나이별 특별 할인 | 지역·통화·인구 조건에 따른 할인 | 공식적으로 제공하지 않는다고 안내 |

### 교육용 프로(학생 할인) 신청 순서

교육용 프로는 학생 할인 인증 서비스인 SheerID로 재학·재직을 확인합니다. 퍼플렉시티 계정은 개인 이메일로 만들어도 됩니다.

| 단계 | 할 일 |
|---|---|
| 1 | 데스크톱 브라우저에서 perplexity.ai에 로그인합니다. |
| 2 | 왼쪽 아래 업그레이드(Upgrade)를 누르고 교육(Education) 요금제로 전환합니다. |
| 3 | 'Verify as student'를 눌러 SheerID 인증을 진행합니다. |
| 4 | 인증이 승인되면 프로를 선택해 결제합니다. 할인은 결제 화면에서 적용됩니다. |
| 5 | 학교가 목록에 없으면 SheerID에 학교 추가를 요청합니다. |

인증이 끝났는데 정가 결제 화면이 나온다면 결제하지 말고 고객센터에 문의하라고 공식 문서가 안내합니다. 이전 구독에 미납 금액이 있으면 할인 결제가 막히는 경우가 있기 때문입니다. 학생 할인은 다른 이메일 계정으로 옮길 수 없고, 새 계정에서 쓰려면 다시 인증해야 합니다.

### 제휴 프로모션 코드를 쓸 때 주의할 점

국내에서는 2024년 9월 SKT가 전 고객에게 퍼플렉시티 프로 1년 이용권을 제공한 사례가 있었습니다. 이런 제휴 혜택은 시기마다 새로 생기고 끝나므로, 해당 통신사·카드사의 이벤트 페이지에서 현재 진행 여부를 확인해야 합니다. 공식 고객센터가 안내하는 공통 조건은 다음과 같습니다.

| 항목 | 내용 |
|---|---|
| 사용 장소 | 할인 코드는 웹에서만 등록되고 모바일 앱에서는 등록되지 않습니다. |
| 결제 수단 | 무료 기간이라도 유효한 신용·체크카드 등록이 필요합니다. |
| 무료 기간 중 청구 | 프로모션 기간에는 청구되지 않습니다. |
| 기간 종료 후 | 해지하지 않으면 정가로 자동 갱신됩니다. |
| 중복 사용 | 결제 주기마다 코드 1개만 적용됩니다. |
| 양도 | 다른 계정이나 이메일로 옮길 수 없고, 코드 공유는 이용약관 위반입니다. |
| 앱스토어 구독 중 | 앱스토어·구글 플레이 구독이 끝난 뒤에야 코드를 쓸 수 있습니다. |

무료 기간이 끝나기 전에 계속 쓸지 정해 두지 않으면 정가로 결제되므로, 등록한 날 바로 달력에 종료일을 적어 두는 것을 추천합니다.

## 해지와 환불 — 한국 사용자는 7일

요금제를 써 보고 맞지 않으면 해지하면 됩니다. 해지해도 현재 결제 주기가 끝날 때까지는 프로 기능을 쓸 수 있고, 이후 무료 플랜으로 돌아갑니다. 구독 일시 정지 기능은 없습니다.

| 구분 | 환불 가능 기간 (공식 고객센터 기준) |
|---|---|
| 한국·브라질 사용자 | 구매 후 7일 이내 해지 시 (월·연 결제 모두) |
| EU·영국·튀르키예 사용자 | 구매 후 14일 이내 해지 시 |
| 그 밖의 지역 월 결제 | 구매 후 24시간 이내 요청 |
| 그 밖의 지역 연 결제 | 구매 후 72시간 이내 요청 |

한국에서 환불을 요청할 때는 한국 사용자라는 점을 요청 내용에 적으라고 안내되어 있습니다. 웹에서 결제했다면 구독 관리에서 'Cancel Plan'을 고를 때 환불 요청 옵션이 함께 나타납니다. 애플 앱스토어로 결제했다면 애플의 문제 신고 페이지에서, 구글 플레이로 결제했다면 퍼플렉시티 고객센터(Help > Contact Support)에 구글 플레이 이메일을 적어 요청합니다. 환불은 한 번 받으면 추가 환불 요청이 처리되지 않는다는 점도 기억해 두세요.

## 나에게 맞는 요금제 고르기

어떤 요금제가 맞는지는 쓰는 목적과 빈도로 정하는 것이 현실적입니다.

| 이런 경우 | 추천 요금제 | 이유 |
|---|---|---|
| 하루 몇 번 궁금한 것을 찾아봄 | 무료 | 기본 검색은 사실상 무제한 |
| 업무 자료 조사·비교를 매일 함 | 프로 | 프로 검색과 고급 모델 선택이 필요 |
| 대학생·대학원생·교직원 | 교육용 프로 | 프로와 같은 기능을 절반 가격에 이용 |
| 보고서·대시보드를 대량으로 만듦 | 맥스 | 파일·앱 만들기 한도가 가장 넉넉함 |
| 회사 자료를 팀이 함께 검색 | 엔터프라이즈 프로 | 데이터 학습 미사용, 관리자 기능 |
| 1년 이상 쓸 것이 확실함 | 프로 연간 결제 | 월 결제보다 연 40달러 절약 |

무료 플랜을 쓰는 동안에는 프로 검색 횟수를 아끼는 것이 중요합니다. 간단한 사실 확인은 기본 검색으로 하고, 여러 출처를 비교해야 하는 질문만 한 번에 구체적으로 묻는 편이 효율적입니다.

```
2026년 기준 국내 무선 이어폰 3개 제품(A, B, C)을
가격, 배터리 시간, 노이즈 캔슬링 유무로 비교해 표로 정리해 주세요.
출처가 서로 다르면 어느 출처의 숫자인지 함께 적어 주세요.
```

이미 갖고 있는 PDF나 문서를 요약하는 일이라면 퍼플렉시티 대신 다른 도구를 쓰는 것도 방법입니다. 자료를 올려 놓고 질문하는 방식은 [NotebookLM 사용법](../notebooklm-guide/)에서, 여러 AI의 무료 요약 기능 비교는 [PDF 요약 AI 추천](../ai-pdf-document-summary/)에서 자세히 다룹니다.

## 마무리

퍼플렉시티 무료 플랜은 기본 검색을 사실상 제한 없이 쓸 수 있어 가벼운 검색 용도로는 충분합니다. 프로 검색을 자주 쓰거나 GPT·Claude·Gemini 같은 고급 모델을 골라 쓰고 싶다면 월 20달러 프로가 필요하고, 학생·교직원이라면 월 10달러 교육용 프로를 먼저 확인해 보는 것을 추천합니다. 친구 추천으로 무료 개월을 받던 프로그램은 이미 끝났으므로, 현재 할인은 연간 결제, 교육용 프로, 제휴 프로모션 코드가 중심입니다.
