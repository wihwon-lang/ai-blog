스마트스토어나 쿠팡에서 물건을 파는 분들에게 상세페이지 이미지는 매출과 바로 이어지는 작업이지만, 촬영과 디자인을 맡기면 비용이 만만치 않습니다. 요즘은 AI 이미지 도구로 배경 연출, 사용 장면, 설명용 그래픽을 직접 만드는 판매자가 늘고 있습니다. 이 글에서는 AI로 상세페이지 이미지를 만드는 순서와 프롬프트, 그리고 2026년에 새로 생긴 플랫폼 정책과 법적 주의점을 정리했습니다.

## 상세페이지에서 AI가 잘하는 일과 못 하는 일

AI 이미지 도구는 상세페이지의 모든 장면을 대신하기보다, **실제 상품 사진을 바탕으로 주변을 꾸미는 역할**에 가장 잘 맞습니다. 상품 자체를 AI가 새로 그리게 하면 로고, 구성품, 색상이 실제와 달라지기 쉽고, 이는 뒤에서 설명할 정책 위반으로 이어질 수 있습니다.

| 작업 | AI 활용 적합도 | 설명 |
|---|---|---|
| 배경 바꾸기·연출 | 높음 | 실제 상품 사진은 그대로 두고 배경만 거실, 카페 등으로 교체 |
| 사용 장면(라이프스타일) 컷 | 높음 | 상품이 놓인 분위기 연출, 계절감 표현 |
| 설명 그래픽·아이콘 | 높음 | 특징 요약, 사용 순서 그림, 비교 도표 배경 |
| 상품 자체를 새로 그리기 | 낮음 | 디자인·색상·구성품이 실제와 달라질 위험 |
| 착용샷·모델 컷 | 주의 | 가상 인물 표시 의무, 실제 착용감과 다를 수 있음 |
| 효과 전후 비교 | 사용하지 않는 것을 추천 | 효능 과장으로 판단될 가능성이 큼 |

핵심 원칙은 간단합니다. **상품의 모양·색·크기·구성은 실제 사진으로 보여 주고, AI는 분위기와 설명을 돕는 데 쓰는 것**입니다.

## 2026년에 바뀐 AI 생성물 정책 먼저 확인하기

2026년에는 AI로 만든 상품 이미지와 관련된 규칙이 여러 곳에서 새로 생겼습니다. 이미지를 만들기 전에 아래 내용을 먼저 확인해 두는 것이 안전합니다.

| 구분 | 시행 시점 | 핵심 내용 |
|---|---|---|
| 인공지능 기본법 | 2026년 1월 22일 | 생성형 AI 결과물 표시 의무 시행. 의무 대상은 주로 AI 서비스를 제공하는 사업자이며, 과태료는 계도기간 운영 중 |
| 공정위 추천·보증 심사지침 개정 | 2026년 6월 1일 | AI로 만든 가상 인물이 광고에 나오면 '가상인물' 등 표시 필요. 위반 시 기만 광고로 제재될 수 있음 |
| 네이버쇼핑 AI 생성물 기준 | 2026년 7월 10일 | 소비자가 오인할 수 있는 AI 활용 제한, 일부 카테고리는 AI 활용 제한, 위반 시 검색 제외 등 조치 |
| 쿠팡 생성 AI 콘텐츠 활용 가이드 | 2026년 판매자 공지 | 실제와 현저히 다른 이미지, AI 생성물 미표시, 효과 과장 연출 등을 허위·과장 광고 소지로 안내 |

### 네이버쇼핑에서 주의할 점

보도와 판매자 안내 자료에 따르면, 네이버쇼핑은 AI 사용 자체를 막는 것이 아니라 **소비자가 상품 정보를 잘못 알게 만드는 AI 활용**을 제한합니다. AI로 만들거나 바꾼 콘텐츠는 이미지 안에 문구나 아이콘으로, 또는 해당 콘텐츠 가까운 위치에 AI 활용 사실을 안내하는 방식이 소개되어 있습니다.

또한 의료기기, 건강기능식품, 유아식품, 신선식품(농·축·수산물), 의약외품, 반려동물 건강식품·간식, 이미용 가전 등 일부 카테고리는 AI 활용이 제한되는 것으로 알려져 있습니다. 해당 카테고리를 판매한다면 스마트스토어센터 공지사항에서 정확한 범위를 꼭 확인하세요.

### 쿠팡에서 주의할 점

쿠팡은 판매자 대상 가이드에서 AI로 만든 이미지·영상이 실제 상품과 크게 다르거나, 품질·효능·크기·구성을 오인하게 만들면 허위·과장 광고나 소비자 기만에 해당할 수 있다고 안내했습니다. 문제가 될 수 있는 예로 AI 생성물 미표시, 유명인·실존 인물을 흉내 낸 가상 인물 사용, 다이어트·체형 변화 같은 효과 과장, 성능을 오인하게 하는 배경 연출 등이 꼽혔습니다.

정책 문구는 수시로 바뀌므로, 상품을 올리기 전에는 각 판매자센터 공지사항에서 최신 기준을 다시 확인하는 것을 추천합니다.

## 준비물과 도구 고르기

AI 상세페이지 작업에는 이미지 생성·편집 도구와 간단한 디자인 도구가 함께 필요합니다.

| 준비물 | 용도 | 팁 |
|---|---|---|
| 실제 상품 사진 | AI 편집의 기준 이미지 | 밝은 곳에서 정면·측면·디테일을 스마트폰으로 촬영 |
| 나노바나나(Gemini) | 배경 교체, 연출 컷, 부분 수정 | 한국어로 "배경만 바꿔 줘"처럼 대화로 수정 가능 |
| 미드저니 | 분위기 있는 배경·무드 이미지 | 상품 없이 배경 소스만 만들 때 유용 |
| 디자인 도구(미리캔버스, 캔바 등) | 글자, 아이콘, 레이아웃 배치 | AI 이미지에 직접 글자를 넣기보다 여기서 넣는 편이 수정이 쉬움 |
| 상품 정보 정리표 | 문구 작성, 사실 확인 | 크기·소재·구성품·주의사항을 먼저 정리 |

두 이미지 도구의 차이와 요금은 [미드저니 vs 나노바나나 비교](../midjourney-vs-nano-banana/) 글에 자세히 정리해 두었습니다. 상세페이지처럼 **실제 사진을 기준으로 일부만 고치는 작업**에는 대화로 수정할 수 있는 나노바나나가 시작하기 쉽습니다. 다만 Gemini 무료·AI Pro 요금제 결과물에는 눈에 보이는 표시가 붙을 수 있으니, 상업용으로 쓰기 전에 요금제별 워터마크 조건을 확인하세요.

## 상세페이지 이미지 만드는 순서

상세페이지는 보통 위에서 아래로 "첫인상 → 특징 → 사용 장면 → 상세 정보 → 안내" 흐름으로 구성합니다. AI로 만들 때도 이 흐름을 먼저 정해 두면 작업이 빨라집니다.

| 단계 | 할 일 | AI 활용 방법 |
|---|---|---|
| 1. 구성 기획 | 섹션 순서와 각 섹션에 들어갈 문구 정리 | ChatGPT·Claude에 상품 정보를 주고 섹션 구성 초안 요청 |
| 2. 상품 촬영 | 실제 상품을 여러 각도로 촬영 | 사용하지 않음 (실물 기준 확보) |
| 3. 대표이미지 | 흰 배경 또는 깔끔한 배경의 정사각형 이미지 | 배경 정리·그림자 보정 정도만 활용 |
| 4. 연출 컷 | 사용 장면, 계절·공간 연출 | 상품 사진을 올리고 배경만 바꾸도록 요청 |
| 5. 설명 그래픽 | 특징 아이콘, 사용 순서 그림 | 아이콘·배경 소스 생성 후 디자인 도구에서 조합 |
| 6. 글자 배치 | 제목, 특징 문구, 주의사항 | 디자인 도구에서 직접 입력 |
| 7. 검수와 표시 | 실제 상품과 비교, AI 활용 안내 표시 | 사람이 직접 확인 |

구성 기획 단계에서는 아래처럼 요청하면 섹션별 초안을 받을 수 있습니다.

```
아래 상품의 스마트스토어 상세페이지 구성안을 만들어 주세요.
- 상품: 스테인리스 텀블러 500ml, 색상 3종(화이트, 네이비, 베이지)
- 특징: 보온 보냉, 손잡이 일체형, 식기세척기 사용 가능
- 타깃: 출퇴근하는 20~30대 직장인
섹션은 6개 이내로, 각 섹션마다 제목 한 줄과 설명 두 줄, 들어갈 이미지 설명을 표로 정리해 주세요.
과장 표현이나 확인되지 않은 수치는 넣지 마세요.
```

마지막 줄처럼 **확인되지 않은 수치를 넣지 말라는 조건**을 꼭 넣는 것을 추천합니다. AI가 "12시간 보온" 같은 그럴듯한 숫자를 지어내는 경우가 있기 때문입니다.

## 연출 컷 프롬프트 예시

연출 컷은 실제 상품 사진을 함께 올리고, **상품은 그대로 두고 배경만 바꾸라**고 분명히 적는 것이 중요합니다.

```
첨부한 텀블러 사진을 사용해 주세요.
텀블러의 모양, 색상, 로고, 크기 비율은 바꾸지 말고 그대로 유지해 주세요.
배경만 아침 햇살이 들어오는 사무실 책상으로 바꿔 주세요.
책상 위에는 노트북과 노트가 살짝 흐리게 보이고, 텀블러가 화면 중앙에 오도록 해 주세요.
자연스러운 그림자, 밝고 깨끗한 톤, 정사각형 비율로 부탁합니다.
```

결과가 마음에 들면 같은 대화에서 부분만 고칩니다.

```
좋아요. 텀블러는 그대로 두고, 배경의 노트북만 지워 주세요.
전체 밝기를 조금 더 따뜻한 톤으로 바꿔 주세요.
```

구도와 조명 용어를 더 알고 싶다면 [AI 이미지 프롬프트 기본 공식](../ai-image-prompt-formula/) 글을 함께 보면 도움이 됩니다. 섹션별로 쓰기 좋은 요청 문장은 아래처럼 정리할 수 있습니다.

| 섹션 | 요청 예시 | 주의할 점 |
|---|---|---|
| 첫 화면 | "상품을 중앙에 두고 단색 파스텔 배경, 여백 넉넉하게" | 상품 색이 바뀌지 않았는지 확인 |
| 사용 장면 | "캠핑장 테이블 위, 저녁 조명, 상품은 그대로 유지" | 실제 쓰임과 맞는 장면인지 확인 |
| 크기 안내 | "손에 든 모습" 대신 실제 촬영 사진 사용 권장 | AI는 크기 비율을 틀리기 쉬움 |
| 색상 옵션 | 옵션별 실제 사진에 같은 배경만 적용 | 색상을 AI로 바꾸면 실제와 달라질 수 있음 |
| 특징 그래픽 | "보온을 나타내는 단순한 아이콘, 흰 배경, 선 스타일" | 효능을 과장하는 그림은 피하기 |

## 이미지 규격과 업로드 전 점검

스마트스토어와 쿠팡은 이미지 규격 기준이 조금씩 다르고, 공식 기준은 판매자센터 안내에서 바뀔 수 있습니다. 판매자 안내 자료에서 흔히 소개되는 실무 기준은 아래와 같습니다.

| 항목 | 스마트스토어 (실무 권장) | 쿠팡 (실무 권장) |
|---|---|---|
| 대표이미지 비율 | 1:1 정사각형 | 1:1 정사각형 |
| 대표이미지 크기 | 1000×1000px 안팎 | 1000×1000px 안팎 |
| 대표이미지 배경 | 깔끔한 배경 권장 | 흰 배경, 글자·로고·워터마크 넣지 않기 권장 |
| 상세이미지 가로 폭 | 860px 기준이 많이 쓰임 | 780px 기준이 많이 쓰임 |
| 파일 형식 | JPG, PNG 등 | JPG, PNG 등 |

정확한 최소·최대 크기와 용량은 스마트스토어센터와 쿠팡 윙의 상품 등록 화면 안내를 기준으로 맞추세요. AI 이미지 도구는 결과물 해상도가 요금제나 설정에 따라 다르므로, 상세이미지로 쓸 때는 가로 폭이 충분한지 먼저 확인하는 것이 좋습니다.

업로드 전에는 아래 점검표로 한 번 더 확인합니다.

| 점검 항목 | 확인 방법 |
|---|---|
| 상품 모양·색상이 실물과 같은가 | 실제 상품을 옆에 두고 비교 |
| 로고·글자가 깨지거나 바뀌지 않았는가 | 확대해서 확인 |
| 구성품이 추가·누락되지 않았는가 | 판매 구성표와 대조 |
| 효능·크기를 과장하는 연출이 없는가 | 전후 비교, 과장된 크기감 제거 |
| AI 활용 사실을 안내했는가 | 이미지 안 문구 또는 가까운 위치에 표시 |
| 가상 인물이 나오면 표시했는가 | 인물 근처에 '가상인물' 등 표시 |
| 제한 카테고리에 해당하지 않는가 | 판매자센터 공지 확인 |

## 마무리

AI로 상세페이지 이미지를 만들면 촬영과 디자인 비용을 줄이면서도 다양한 연출 컷을 빠르게 준비할 수 있습니다. 다만 2026년부터는 인공지능 기본법, 공정위 가상인물 표시 지침, 네이버쇼핑과 쿠팡의 AI 생성물 기준이 함께 적용되면서 **실물과 다른 이미지에 대한 책임이 판매자에게 더 분명하게 돌아오게 되었습니다**.

가장 안전한 방법은 상품은 실제 사진으로 보여 주고, AI는 배경·분위기·설명 그래픽에만 쓰는 것입니다. 그리고 AI를 활용한 이미지에는 활용 사실을 안내하고, 업로드 전에는 실물과 꼼꼼히 비교하는 습관을 들이는 것을 추천합니다. 정책과 규격은 자주 바뀌므로 상품을 등록하기 전에 스마트스토어센터와 쿠팡 윙의 최신 공지를 꼭 확인하시기 바랍니다.
