사진 보정이라고 하면 보통 포토샵이나 보정 앱의 슬라이더를 떠올리지만, 구글 Gemini의 나노바나나(Nano Banana)는 "배경의 사람을 지워 줘", "조명을 저녁 노을처럼 바꿔 줘"처럼 말로 요청해서 사진을 고칠 수 있습니다. 이 글은 편집 프로그램을 잘 다루지 못하는 분이 나노바나나로 사진을 보정할 때 알아 두면 좋은 사용 순서, 프롬프트 쓰는 요령, 주의할 점을 2026년 10월 기준으로 정리했습니다.

## 나노바나나 사진 편집, 무엇이 다른가

기존 보정 앱은 밝기, 대비, 채도 같은 값을 직접 조절하는 방식입니다. 나노바나나는 사진을 이해한 뒤 요청한 부분을 새로 그려 넣는 방식이라, 사진에 없던 것을 추가하거나 있던 것을 지우는 작업도 문장 하나로 처리합니다.

| 비교 항목 | 일반 보정 앱 | 나노바나나 (Gemini 앱) |
|---|---|---|
| 조작 방식 | 슬라이더, 브러시, 필터 | 한국어 문장으로 요청 |
| 잘하는 작업 | 밝기·색감 미세 조정 | 배경 교체, 물체 제거, 분위기 변경 |
| 수정 범위 지정 | 직접 선택 영역을 그림 | 문장으로 위치 설명, 이미지 위에 표시 |
| 반복 수정 | 작업 기록에서 되돌리기 | 같은 대화에서 "다시", "조금 덜" 요청 |
| 원본 보존 | 픽셀 단위로 보존 | 요청하지 않은 부분도 조금씩 바뀔 수 있음 |

마지막 줄이 가장 중요한 차이입니다. 나노바나나는 결과 이미지를 새로 만들어 내기 때문에, 얼굴의 작은 특징이나 글자처럼 정확히 유지되어야 하는 부분이 미세하게 달라질 수 있습니다. 그래서 정밀한 색 보정은 기존 앱으로, 구성 자체를 바꾸는 편집은 나노바나나로 나눠 쓰는 경우가 많습니다.

## 지금 쓸 수 있는 모델과 요금제 (2026년 10월 기준)

나노바나나는 구글 이미지 모델의 별명이라 버전이 여러 개입니다. 구글은 2026년 10월 6일 Gemini API에서 Nano Banana 2.1을 정식 출시했고, 공식 모델 문서에서는 이전 버전보다 시각 품질, 프롬프트 반영, 여러 번 대화하며 수정할 때의 인물 일관성, 글자 표현이 개선되었다고 안내합니다. Gemini 앱에도 순차적으로 적용되고 있어 사용자마다 화면에 보이는 모델 이름이 다를 수 있습니다.

| 모델 | 특징 | Gemini 앱에서 쓰는 법 |
|---|---|---|
| 나노바나나 2 / 2.1 | 빠르고 가벼움, 일상적인 사진 편집에 적합 | 이미지 만들기 도구에서 기본으로 사용 |
| 나노바나나 Pro | 세밀한 표현, 글자·인포그래픽에 강함 | 유료 구독자는 결과 이미지 메뉴의 'Pro로 다시 만들기(Redo with Pro)' 사용 |
| 나노바나나 2 Lite | 가장 가벼운 모델 | 여러 장 참조나 반복 편집용으로는 권장되지 않음 |

무료 사용자도 Gemini 앱에서 사진 편집을 할 수 있지만 사용량에 한도가 있고, 구글은 하루 몇 장인지 고정된 숫자를 공식적으로 안내하지 않고 있습니다. Google AI Plus, Pro, Ultra 구독자는 더 높은 한도와 Pro 모델을 쓸 수 있습니다. 요금제별 가격과 혜택은 [미드저니 vs 나노바나나 비교](../midjourney-vs-nano-banana/) 글에 정리해 두었으며, 결제 전에는 Gemini 구독 페이지에서 현재 혜택을 다시 확인하는 것을 추천합니다.

## 사진 올리고 편집하는 기본 순서

Gemini 앱(안드로이드, iOS)과 웹(gemini.google.com)에서 같은 흐름으로 쓸 수 있습니다. 메뉴 이름은 앱 업데이트에 따라 조금씩 달라질 수 있습니다.

| 단계 | 할 일 | 요령 |
|---|---|---|
| 1 | 입력창의 + 버튼에서 사진 추가 | 원본에 가까운 고화질 사진을 올림 |
| 2 | 도구 메뉴에서 이미지 만들기 선택 | 일반 대화보다 이미지 편집 요청이 명확해짐 |
| 3 | 바꿀 내용과 유지할 내용을 함께 적기 | "얼굴과 옷은 그대로"처럼 보존 조건을 먼저 씀 |
| 4 | 결과 확인 후 같은 대화에서 추가 요청 | 한 번에 한 가지씩 고치기 |
| 5 | 마음에 드는 결과 다운로드 | 여러 버전을 받아 두고 비교 |

모바일 앱과 웹에서는 사진을 연 뒤 직접 동그라미나 화살표를 그려 수정할 위치를 표시하는 기능도 제공됩니다. "왼쪽 위에 있는 표지판"처럼 문장으로 위치를 설명하기 어려울 때는 해당 부분에 표시를 하고 "표시한 물체를 지워 줘"라고 요청하면 범위가 분명해집니다.

## 대화로 고칠 때의 프롬프트 요령

나노바나나 편집의 성패는 **무엇을 바꾸고 무엇을 지킬지**를 얼마나 분명하게 적느냐에 달려 있습니다. 기본 형식은 아래와 같습니다.

```
[유지할 것]은 그대로 두고, [바꿀 부분]을 [원하는 모습]으로 바꿔 줘.
[분위기나 용도]에 맞게 자연스럽게 부탁해.
```

| 이렇게 쓰면 좋습니다 | 이렇게 쓰면 결과가 흔들립니다 |
|---|---|
| "인물의 얼굴, 머리 모양, 옷은 그대로 두고 배경만 바꿔 줘" | "배경 좀 예쁘게 해 줘" |
| 한 번에 한 가지만 요청 | 배경, 조명, 옷, 표정을 한꺼번에 요청 |
| "조금 더 밝게", "채도를 약간 낮춰서"처럼 정도를 표시 | "완전히 다르게" 같은 막연한 표현 |
| "따뜻한 오후 햇살", "흐린 날의 부드러운 빛"처럼 빛을 묘사 | "분위기 있게"만 적기 |
| 결과가 어긋나면 "방금 결과에서 하늘만 원래대로" | 처음부터 다시 긴 요청 반복 |

여러 번 고치다 보면 얼굴이나 색감이 조금씩 원본에서 멀어질 수 있습니다. 대여섯 번 이상 수정했는데도 어색하다면 새 대화를 열고 원본 사진을 다시 올려, 지금까지 정리된 요청을 한 문장으로 합쳐 넣는 편이 결과가 안정적인 경우가 많습니다. 조명·구도 용어를 더 알고 싶다면 [AI 이미지 프롬프트 기본 공식](../ai-image-prompt-formula/) 글을 함께 참고하세요.

## 상황별 보정 프롬프트 예시

자주 쓰이는 보정 작업을 상황별로 묶었습니다. 그대로 복사해서 사진에 맞게 단어만 바꿔 쓰면 됩니다.

| 상황 | 요청 핵심 | 주의할 점 |
|---|---|---|
| 여행 사진 속 행인 지우기 | 지울 대상의 위치와 옷차림을 설명 | 사람이 많으면 한 명씩 나눠 요청 |
| 흐린 날 사진을 맑게 | 하늘, 빛 방향, 그림자를 함께 설명 | 인물 피부색이 같이 바뀌지 않게 유지 조건 추가 |
| 프로필 사진 배경 정리 | 단색이나 스튜디오 배경 지정 | 얼굴 특징 유지 문장을 맨 앞에 |
| 오래된 사진 복원 | 긁힘 제거, 선명도, 컬러 여부 지정 | 표정·이목구비가 달라질 수 있어 원본과 비교 |
| 음식·제품 사진 보정 | 조명, 그릇·소품, 배경 정리 | 제품 글자와 로고는 바꾸지 말라고 명시 |
| 방 사진 정리 | 바닥의 물건 치우기, 조명 밝게 | 가구 배치는 유지하도록 요청 |

행인을 지울 때는 이렇게 요청할 수 있습니다.

```
사진 속 가운데 인물은 그대로 두고, 오른쪽 뒤편에 서 있는 검은 옷의 사람 두 명을 지워 줘.
지운 자리는 주변 건물과 길바닥에 자연스럽게 이어지게 채워 줘.
```

흐린 날 풍경을 맑게 바꿀 때의 예시입니다.

```
건물과 나무의 모양, 구도는 그대로 유지해 줘.
흐린 하늘을 옅은 구름이 있는 맑은 파란 하늘로 바꾸고, 오후 3시쯤 햇살이 왼쪽에서 비추는 것처럼 그림자를 맞춰 줘.
```

오래된 가족사진을 복원할 때는 원래 모습을 지키는 조건을 강하게 적는 것이 좋습니다.

```
이 오래된 흑백 사진의 긁힘과 얼룩을 없애고 선명하게 복원해 줘.
사람들의 얼굴 생김새, 표정, 옷은 바꾸지 말고, 흑백 그대로 유지해 줘.
```

제품 사진을 판매용으로 다듬는 작업은 [AI 이미지 배경 제거·합성](../ai-background-removal-product-photo/) 글에서 누끼 도구와 함께 더 자세히 다뤘습니다.

## 워터마크와 사용 시 주의할 점

편집한 사진을 SNS나 판매용으로 쓸 계획이라면 표시 방식과 권리 문제를 미리 확인해야 합니다.

| 확인 항목 | 2026년 10월 기준 내용 |
|---|---|
| 보이지 않는 워터마크 | 나노바나나 결과물에는 SynthID와 C2PA 메타데이터가 들어가며 끌 수 없음 |
| 눈에 보이는 워터마크 | Gemini 반짝이 표시가 기본으로 붙음 |
| 표시 끄기 설정 | 2026년 8월 '미디어 워터마크' 설정이 추가됨, 한국에서는 AI Ultra 구독자만 쓸 수 있다고 보도됨 |
| 다른 사람 사진 | 본인 동의 없이 얼굴을 바꾸거나 합성해 게시하면 초상권·명예 문제가 생길 수 있음 |
| 업무·학교 계정 | 워터마크 설정 등 일부 기능이 다르게 제공될 수 있음 |

워터마크 설정 위치와 대상 요금제는 국가별로 다르고 계속 바뀌고 있으므로, Gemini 웹의 설정 메뉴에서 직접 확인하는 것이 정확합니다. 또한 Gemini 생성형 AI 금지 사용 정책에 따라 실존 인물을 오해하게 만드는 합성, 신분증·공문서 위조 같은 요청은 거절되거나 계정 제재 사유가 될 수 있습니다.

## 자주 생기는 문제와 해결법

| 문제 | 원인 | 해결법 |
|---|---|---|
| 얼굴이 원본과 달라짐 | 수정 범위가 얼굴까지 번짐 | "얼굴은 절대 바꾸지 말 것"을 첫 문장에 쓰고 수정 범위를 좁힘 |
| 요청하지 않은 부분도 바뀜 | 요청이 막연하거나 여러 개를 한꺼번에 요청 | 한 번에 한 가지씩, 위치를 표시해서 요청 |
| 사진 비율이 바뀜 | 결과 비율을 지정하지 않음 | "원본과 같은 비율로" 또는 "4:5 비율로"를 명시 |
| 화질이 떨어져 보임 | 저해상도 원본, 무료 사용 시 해상도 제한 | 고화질 원본 사용, 업스케일 도구로 보완 |
| 편집 요청이 거절됨 | 실존 인물, 신분증 등 정책 제한 | 요청 내용을 바꾸거나 정책 안내 확인 |
| 같은 요청에 결과가 매번 다름 | 생성 방식 특성 | 여러 번 만들어 고르고, 마음에 든 결과를 기준으로 이어서 수정 |

해상도가 아쉬운 결과물은 별도의 업스케일 도구로 키우는 방법도 있습니다. 반대로 결과물을 영상의 첫 장면으로 활용하고 싶다면 [이미지 한 장으로 AI 영상 만들기](../image-to-video-guide/) 글이 도움이 됩니다.

## 마무리

나노바나나는 사진 편집 프로그램을 몰라도 한국어 문장으로 배경을 바꾸고, 필요 없는 물체를 지우고, 오래된 사진을 복원할 수 있는 도구입니다. 좋은 결과를 얻는 핵심은 **유지할 것을 먼저 쓰고, 한 번에 한 가지씩 고치고, 위치가 애매하면 사진 위에 표시하는 것**입니다.

다만 결과 이미지를 새로 그려 내는 방식이라 얼굴이나 글자가 미세하게 달라질 수 있으니, 중요한 사진은 원본과 꼭 비교해 보세요. 워터마크 설정과 요금제별 한도는 2026년 들어서도 여러 번 바뀌었으므로, 상업적으로 쓰기 전에는 Gemini 공식 도움말과 구독 페이지에서 현재 조건을 확인하시기 바랍니다.
