AI 영상을 광고나 외주 작업에 쓰기 시작하면 꼭 나오는 질문이 있습니다. "이거 상업적으로 써도 되나요?", "저작권은 누구한테 있나요?", "AI라고 표시해야 하나요?" 2026년 1월 AI 기본법이 시행되면서 헷갈리는 부분이 더 늘었습니다. 이 글에서는 실무에서 알아 둬야 할 내용만 정리했습니다.

이 글은 일반적인 정보 정리이며 법률 자문이 아닙니다. 중요한 계약이나 분쟁은 전문가와 상담하세요.

> ✍️ 직접 작성: 클라이언트나 지인에게 실제로 받아 본 저작권 관련 질문이 있다면 한두 문장.

## 한눈에 정리

| 질문 | 짧은 답 |
|---|---|
| AI 영상, 상업적으로 써도 되나? | 대부분 **유료 요금제**에서는 가능. 도구별 약관 확인 필요 |
| 무료 요금제로 만든 영상은? | 워터마크가 있거나 상업 이용이 제한되는 경우가 많음 |
| AI 영상에 저작권이 생기나? | 프롬프트만 넣어 나온 결과물은 **저작물로 보기 어려움** |
| 저작권 등록 가능한 경우는? | 사람이 선택·배열·수정 등 **창작적으로 기여한 부분** |
| AI 기본법 워터마크, 내가 넣어야 하나? | 의무는 **AI 서비스 제공 사업자**에게. 콘텐츠를 만들어 올리는 이용자에게는 법적 의무 없음 |

## 1. 상업적 이용: 도구 약관이 기준

AI 영상의 상업적 이용 가능 여부는 **각 도구의 이용약관**이 정합니다. 일반적인 경향은 이렇습니다.

| 구분 | 일반적인 경우 |
|---|---|
| 유료 요금제 | 상업적 이용 허용 (광고, 클라이언트 작업 포함) |
| 무료 요금제 | 워터마크 포함, 상업 이용 제한이 있는 경우 있음 |
| 실존 인물·브랜드 묘사 | 도구 약관과 별개로 초상권·상표권 문제 가능 |
| 다른 사람 이미지를 참조로 사용 | 원본 이미지의 저작권 문제 가능 |

약관은 자주 바뀌니, 클라이언트 작업에 쓰기 전에 사용하는 도구의 최신 약관을 확인하고 **어떤 요금제로 만들었는지 기록**해 두는 것이 좋습니다.

> ✍️ 직접 작성: 클라이언트 작업에서 상업 이용을 어떻게 확인하고 있는지 (요금제 기록, 계약서 문구 등).

## 2. 저작권: 사람의 창작적 기여가 핵심

한국저작권위원회는 2026년 4월 생성형 AI 관련 안내서 4종을 모아 공개했습니다. 핵심 원칙은 **"인간의 창작적 기여가 있어야 저작권 등록이 가능하다"**는 것입니다.

| 경우 | 저작권 보호 |
|---|---|
| 프롬프트 한 줄 입력 → 결과물 그대로 사용 | 보호받기 어려움 |
| 여러 결과물 중 의도에 맞게 선택·배열 | 선택·배열에 대해 보호 가능성 |
| AI 결과물을 사람이 직접 수정·편집 | 사람이 기여한 부분 보호 가능성 |
| 직접 쓴 대본·촬영 소스 + AI 영상 편집 | 사람이 만든 부분은 보호 |

실무적으로는 **기획안, 대본, 콘티, 수정 과정**을 남겨 두면 나중에 창작적 기여를 설명하는 데 도움이 됩니다.

## 3. AI 기본법 워터마크: 누구의 의무인가

2026년 1월 22일 시행된 「인공지능기본법」에는 AI 생성물 표시 의무가 들어 있습니다.

| 대상 | 의무 |
|---|---|
| 생성형 AI 서비스 제공 사업자 (클링, 구글 등) | AI 생성물임을 알리는 표시(워터마크 등) |
| 실제와 구분하기 어려운 딥페이크 | 사람이 명확히 알아볼 수 있게 표시 |
| AI 결과물로 콘텐츠를 만들어 올리는 이용자 | 법적 의무 없음 |

즉 AI 영상을 만들어 SNS에 올리거나 광고에 쓰는 **이용자 본인에게 직접 부과되는 표시 의무는 없습니다.** 다만 실제 사람·장소로 오해할 수 있는 영상이라면, 법적 의무와 별개로 "AI로 제작된 영상입니다" 같은 안내를 넣는 것이 신뢰와 분쟁 예방에 좋습니다. 플랫폼(유튜브, 인스타그램 등)도 자체적으로 AI 콘텐츠 표시를 요구하는 경우가 있으니 업로드할 때 확인하세요.

## 4. 실무 체크리스트

| 체크 | 내용 |
|---|---|
| ☐ | 유료 요금제로 만들었는가 |
| ☐ | 사용한 도구의 최신 상업 이용 약관을 확인했는가 |
| ☐ | 실존 인물, 유명인, 타사 로고가 들어가지 않았는가 |
| ☐ | 남의 사진·작품을 참조 이미지로 쓰지 않았는가 |
| ☐ | 실제로 오해할 수 있는 장면에 AI 제작 안내를 넣었는가 |
| ☐ | 업로드 플랫폼의 AI 콘텐츠 표시 규정을 확인했는가 |
| ☐ | 클라이언트 계약서에 AI 사용 사실과 권리 범위를 적었는가 |
| ☐ | 기획안·대본·수정 이력을 보관하고 있는가 |

> ✍️ 직접 작성: 이 체크리스트 중 본인이 실제로 챙기는 것, 또는 추가하고 싶은 항목.

## 마무리

AI 영상의 상업 이용은 "유료 요금제 + 도구 약관 확인 + 실존 인물·브랜드 피하기"만 지켜도 대부분의 문제를 피할 수 있습니다. 저작권은 결과물 자체보다 **내가 기획하고 고친 과정**에서 생긴다는 점을 기억해 두면 좋습니다.
