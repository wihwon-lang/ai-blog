미드저니 가격이 궁금한 분들이 가장 많이 묻는 것은 "한 달에 얼마인지", "무료로는 못 쓰는지", "가장 싼 요금제로 몇 장이나 만들 수 있는지"입니다. 이 글에서는 2026년 11월 기준 미드저니 공식 문서를 바탕으로 요금제 4종의 차이와 무료 사용 가능 여부, 요금제를 고르는 기준을 표로 정리합니다. 미드저니는 달러로 결제하므로 원화 금액은 환율과 카드사 해외 결제 수수료에 따라 달라진다는 점을 먼저 알아 두세요.

## 미드저니 가격 한눈에 보기

결론부터 말하면 미드저니는 **월 10달러(Basic)부터 120달러(Mega)까지 4개 요금제**가 있고, 연간 결제를 하면 20% 할인됩니다. 웹사이트와 디스코드에서는 무료 체험이 없습니다.

| 요금제 | 월 결제 | 연간 결제 (1년 총액) | 연간 결제 시 월 환산 | Fast GPU 시간 (월) |
|---|---|---|---|---|
| Basic | $10 | $96 | $8 | 약 3.3시간 (200분) |
| Standard | $30 | $288 | $24 | 15시간 |
| Pro | $60 | $576 | $48 | 30시간 |
| Mega | $120 | $1,152 | $96 | 60시간 |

미드저니 요금제의 핵심은 "이미지 몇 장"이 아니라 **GPU 시간**으로 사용량을 나눈다는 점입니다. 이미지를 빠르게 만드는 Fast 모드는 이 시간을 차감하고, 시간을 다 쓰면 대기 시간이 긴 Relax 모드로 넘어가거나 추가 시간을 사야 합니다. 그래서 같은 요금제라도 어떤 설정으로 만드느냐에 따라 만들 수 있는 양이 달라집니다.

## 미드저니 무료로 쓸 수 있을까

미드저니 공식 도움말에 따르면 **midjourney.com 웹사이트와 디스코드에서는 현재 무료 체험을 제공하지 않습니다.** 예전에는 가입하면 일정량을 무료로 써 볼 수 있었지만 지금은 유료 구독을 해야 이미지를 만들 수 있습니다.

다만 미드저니가 운영하는 애니메이션 그림체 전용 앱 **niji·journey**(iOS·안드로이드)에서는 제한된 무료 체험이 안내되어 있습니다. 미드저니 본 서비스와 같은 경험은 아니지만, 결제 전에 분위기를 보고 싶다면 이 방법을 확인해 볼 수 있습니다.

| 무료로 써 보는 방법 | 가능 여부 | 참고 |
|---|---|---|
| midjourney.com 웹 무료 체험 | 불가 | 유료 구독 필요 |
| 디스코드 무료 체험 | 불가 | 유료 구독 필요 |
| niji·journey 모바일 앱 | 제한적으로 가능 | 애니메이션 그림체 위주 |
| 갤러리 둘러보기·프롬프트 참고 | 가능 | 다른 사용자의 공개 이미지 감상 |
| 무료 대안 도구 사용 | 가능 | 구글 Gemini의 나노바나나 등 |

비용 없이 AI 이미지를 먼저 만들어 보고 싶다면 무료 사용자도 쓸 수 있는 나노바나나로 시작하는 방법이 있습니다. 두 도구의 차이는 [미드저니 vs 나노바나나 비교](../midjourney-vs-nano-banana/) 글에 정리해 두었습니다.

## 요금제별 기능 차이

가격 차이는 GPU 시간뿐 아니라 무제한 Relax 모드, 비공개 생성(Stealth 모드), 동시 작업 수에서도 납니다.

| 기능 | Basic | Standard | Pro | Mega |
|---|---|---|---|---|
| Relax 모드 이미지 무제한 | 없음 | 있음 | 있음 | 있음 |
| Relax 모드 영상 무제한 | 없음 | 없음 | 있음 | 있음 |
| Stealth 모드 (갤러리 비공개) | 없음 | 없음 | 있음 | 있음 |
| 동시 Fast 작업 수 | 3개 | 3개 | 12개 | 12개 |
| 동시 Relax 작업 수 | 해당 없음 | 공식 문서에서 확인 | 3개 | 3개 |
| Repeat 반복 생성 | 2~4회 | 2~10회 | 2~40회 | 2~40회 |
| 추가 Fast 시간 구매 | 시간당 $4 | 시간당 $4 | 시간당 $4 | 시간당 $4 |

**Relax 모드**는 GPU 시간을 차감하지 않는 대신 대기열에 들어가 결과가 늦게 나오는 방식입니다. Basic에는 Relax 모드가 없어서 Fast 시간을 다 쓰면 추가 구매나 다음 달 갱신을 기다려야 합니다. 이미지를 꾸준히 많이 만드는 분이 Standard를 많이 고르는 이유가 여기에 있습니다.

**Stealth 모드**는 만든 이미지를 미드저니 웹사이트의 다른 사용자에게 보이지 않게 하는 기능으로 Pro와 Mega에만 있습니다. 다만 공식 문서는 디스코드 공용 채널에서 만든 이미지는 Stealth 모드여도 같은 채널 사용자에게 보인다고 안내합니다. 클라이언트 작업이나 출시 전 제품 이미지처럼 공개되면 곤란한 결과물이 있다면 Pro 이상을 고려해야 합니다.

## Fast 시간으로 몇 장 만들 수 있나

미드저니 공식 버전 문서에 따르면 V8.1·V8.2 기준으로 일반 해상도(SD) 이미지 프롬프트 1회는 GPU 시간 약 0.8분, 2K 해상도(HD, `--hd`)는 약 1.3분이 듭니다. 영상은 SD 해상도 4개 묶음 기준 약 8분, HD는 약 26분이 든다고 안내되어 있습니다. 이 숫자로 요금제별 Fast 시간을 나누면 대략적인 사용량을 가늠할 수 있습니다.

| 요금제 | Fast 시간 | SD 이미지 프롬프트 (약 0.8분) | HD 이미지 프롬프트 (약 1.3분) | SD 영상 4개 묶음 (약 8분) |
|---|---|---|---|---|
| Basic | 200분 | 약 250회 | 약 150회 | 약 25회 |
| Standard | 900분 | 약 1,120회 | 약 690회 | 약 110회 |
| Pro | 1,800분 | 약 2,250회 | 약 1,380회 | 약 225회 |
| Mega | 3,600분 | 약 4,500회 | 약 2,770회 | 약 450회 |

이 표는 공식 수치를 단순히 나눈 이론상 값입니다. 업스케일, 비표준 비율, 이전 모델 버전, Turbo 모드(Fast 시간의 2배 차감)를 쓰면 실제로는 더 빨리 줄어듭니다. 반대로 V7·V8.1에서 지원하는 Draft 모드는 프롬프트 1회에 약 0.4분이라 시안을 많이 뽑을 때 시간을 아낄 수 있습니다(V8.2에서는 Draft 미지원). 남은 시간은 디스코드에서 `/info` 명령이나 웹사이트 계정 페이지에서 확인할 수 있습니다.

알아 둘 점이 두 가지 있습니다. 첫째, 매달 받는 Fast 시간은 **다음 달로 이월되지 않습니다.** 둘째, 따로 산 추가 Fast 시간은 **구매 후 60일이 지나면 만료**됩니다. 한 번에 많이 사 두기보다 필요할 때 조금씩 사는 편이 낫습니다.

## 어떤 요금제를 골라야 할까

사용 목적에 따라 고르면 불필요한 지출을 줄일 수 있습니다.

| 이런 분에게 | 추천 요금제 | 이유 |
|---|---|---|
| 한 달만 써 보고 판단하고 싶은 분 | Basic 월 결제 | 가장 저렴하고 약 150~250회 프롬프트로 충분히 체험 가능 |
| 블로그·SNS용 이미지를 꾸준히 만드는 분 | Standard | Relax 모드 무제한으로 시간 걱정이 줄어듦 |
| 미드저니로 영상까지 많이 만드는 분 | Pro | 영상도 Relax 모드 무제한 |
| 외주·클라이언트 작업을 하는 분 | Pro | Stealth 모드로 결과물 비공개 |
| 연 매출 100만 달러 초과 기업 | Pro 또는 Mega | 약관상 필수 조건 |
| 팀 단위 대량 작업 | Mega | Fast 시간 60시간과 동시 작업 여유 |

처음이라면 **Basic 월 결제로 한 달 써 본 뒤** 사용량이 부족하면 Standard로 올리는 방법을 추천합니다. 연간 결제는 20% 저렴하지만 1년치를 한 번에 내야 하므로, 꾸준히 쓸 것이 확실할 때 선택하는 것이 안전합니다.

### 기업이라면 약관을 먼저 확인

미드저니 서비스 약관(2026년 5월 27일 시행본)은 **연간 총매출이 100만 달러를 넘는 회사나 그 회사 직원**이 결과물에 대한 권리를 가지려면 Pro 또는 Mega 요금제를 구독해야 한다고 정하고 있습니다. 회사 업무로 쓴다면 Basic이나 Standard로는 조건을 충족하지 못할 수 있으니 결제 전에 확인하세요. AI 이미지의 상업적 이용 범위는 [AI 그림 저작권 정리](../ai-image-copyright-commercial/) 글에서 더 자세히 다룹니다.

## 결제·해지·환불 조건

결제 전에 해지와 환불 조건도 함께 알아 두면 좋습니다.

| 항목 | 공식 안내 내용 |
|---|---|
| 결제 통화 | 달러 결제 (원화 금액은 환율·카드 수수료에 따라 달라짐) |
| 해지 방법 | 계정의 Manage Subscription 페이지에서 Cancel Plan 선택 |
| 해지 후 | 남은 결제 기간에 대한 환불은 원칙적으로 없음 |
| 환불 가능 조건 | 계정 전체 기간 동안 사용한 GPU 시간이 20분 미만일 때 |
| 환불 시 포함되는 시간 | Fast·Turbo·Relax 사용 시간 모두 포함 |
| 환불 신청 방법 | 조건을 충족하면 해지 화면에 환불 요청 버튼이 자동으로 표시됨 |
| 요금제 변경 | Manage Subscription 페이지에서 상위·하위 요금제로 변경 가능 |

환불 조건이 "GPU 20분 미만 사용"이라 엄격한 편입니다. Turbo 모드는 시간을 2배로 쓰기 때문에 몇 번만 써도 조건을 넘길 수 있습니다. 결제 직후 마음이 바뀌었다면 이미지를 많이 만들기 전에 판단하는 것이 좋습니다.

## 미드저니 가격을 아끼는 방법

| 방법 | 설명 |
|---|---|
| 시안은 SD, 최종본만 HD | HD는 SD보다 GPU 시간이 약 1.6배 들기 때문에 고른 이미지만 HD로 다시 생성 |
| Draft 모드 활용 | V7·V8.1에서 시안을 많이 볼 때 약 0.4분으로 절약 |
| Turbo 모드는 급할 때만 | Fast 시간이 2배로 차감됨 |
| Standard 이상은 Relax 활용 | 급하지 않은 작업은 Relax로 돌려 Fast 시간 보존 |
| 추가 시간은 조금씩 구매 | 산 시간은 60일 후 만료 |
| 꾸준히 쓸 때만 연간 결제 | 20% 할인이지만 1년치 선결제 |

프롬프트를 처음부터 잘 쓰면 다시 생성하는 횟수가 줄어 시간도 아낄 수 있습니다. 구도·조명·스타일을 정리하는 방법은 [AI 이미지 프롬프트 작성법](../ai-image-prompt-formula/) 글을 참고하세요.

## 마무리

미드저니 가격은 월 10달러 Basic부터 120달러 Mega까지이며, 연간 결제를 하면 20% 저렴해집니다. 웹과 디스코드에서는 무료 체험이 없고, 요금제 차이는 Fast GPU 시간, Relax 모드 무제한 여부, Stealth 모드 지원에서 갈립니다. 가볍게 써 보려면 Basic, 꾸준히 많이 만들려면 Standard, 결과물을 비공개로 해야 하거나 매출 100만 달러가 넘는 회사라면 Pro 이상이 맞습니다. 요금과 GPU 소모량은 모델 버전이 바뀔 때마다 달라질 수 있으니 결제 전에 공식 요금제 페이지를 다시 확인하시기 바랍니다.
