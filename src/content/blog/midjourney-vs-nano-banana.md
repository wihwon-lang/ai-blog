AI 이미지를 만들기 시작하면 가장 먼저 고민하는 것이 미드저니(Midjourney)와 구글 나노바나나(Nano Banana) 중 무엇을 쓸지입니다. 두 도구는 모두 인기가 많지만 쓰는 방식, 요금 구조, 잘하는 작업이 꽤 다릅니다. 이 글에서는 2026년 10월 기준 공식 정보를 바탕으로 두 도구의 차이를 정리하고, 용도별로 어떤 도구가 맞는지 안내합니다.

## 두 도구 한눈에 보기

미드저니는 이미지 생성만을 위한 전문 서비스이고, 나노바나나는 구글 Gemini에 들어 있는 이미지 생성·편집 모델의 별명입니다. 출발점이 다르기 때문에 쓰는 느낌도 다릅니다.

| 비교 항목 | 미드저니 | 나노바나나 |
|---|---|---|
| 만든 곳 | Midjourney | 구글 (Gemini) |
| 최신 모델 (2026년 10월) | V8.2 (2026년 7월 24일부터 기본 모델) | Nano Banana 2, Nano Banana Pro |
| 사용 위치 | midjourney.com 웹, 디스코드 | Gemini 앱·웹, Google AI Studio, API |
| 입력 방식 | 프롬프트 + 파라미터(`--ar`, `--sref` 등) | 일상 대화체 문장으로 요청 |
| 무료 사용 | 웹·디스코드 무료 체험 없음 | Gemini 무료 사용자도 이용 가능 (한도 있음) |
| 강점 | 분위기, 미감, 스타일 통일 | 대화로 고치는 편집, 인물 일관성, 글자 표현 |
| 영상 기능 | 이미지를 움직이는 V1 Video 모델 | Veo 등 별도 영상 모델과 연계 |

정리하면 미드저니는 **보기 좋은 그림을 뽑는 데 특화된 도구**이고, 나노바나나는 **말로 지시하며 사진을 만들고 고치는 도구**에 가깝습니다.

## 모델과 주요 기능 차이

### 미드저니 V8 계열

미드저니는 2026년 3월 V8 알파를 공개한 뒤 V8.1을 거쳐 현재 V8.2가 기본 모델입니다. V8부터 생성 속도가 크게 빨라졌고, `--hd` 모드로 2K 해상도를 바로 만들 수 있습니다. 글자 표현도 개선되어 이미지에 넣을 문구를 큰따옴표로 감싸면 비교적 정확하게 표시됩니다.

V8.2에서는 예전의 Omni Reference, Character Reference, Retexture 기능이 **Edit Model**로 통합되었습니다. 참조 이미지를 최대 4장까지 넣어 인물이나 사물을 유지하거나 질감을 바꾸는 작업을 한곳에서 처리합니다. 스타일 참조(`--sref`)와 개인화(Personalization) 기능도 계속 쓸 수 있어, 채널이나 브랜드의 그림체를 통일하는 데 유리합니다. 참고로 빠르게 시안을 뽑는 Draft 모드는 V7과 V8.1에서는 지원되지만 V8.2에서는 지원되지 않습니다.

### 나노바나나 계열

나노바나나는 여러 버전이 있어 이름이 헷갈리기 쉽습니다.

| 별명 | 공식 모델 이름 | 특징 |
|---|---|---|
| 나노바나나 | Gemini 2.5 Flash Image | 첫 버전, API에서는 지원 종료 예정으로 안내된 구형 모델 |
| 나노바나나 2 | Gemini 3.1 Flash Image | 2026년 2월 공개, 속도와 비용의 균형 |
| 나노바나나 2 Lite | Gemini 3.1 Flash Lite Image | 2026년 6월 발표된 가벼운 모델 |
| 나노바나나 Pro | Gemini 3 Pro Image | 최대 4K, 생각 단계와 구글 검색 연동, 고품질 |

나노바나나 Pro는 한 번에 **참조 이미지를 최대 14장**(사물 최대 6장, 인물 최대 5장, 스타일 최대 3장)까지 넣을 수 있고, 인물은 최대 5명까지 일관되게 유지하도록 설계되었습니다. 무엇보다 "배경만 바다로 바꿔 줘", "옷 색을 남색으로 바꿔 줘"처럼 **대화로 부분 수정**이 가능하다는 점이 가장 큰 차이입니다.

## 요금제 비교

### 미드저니 요금제

미드저니는 무료 체험이 없고 유료 구독으로만 쓸 수 있습니다. 2026년 10월 공식 문서 기준 요금은 아래와 같습니다.

| 요금제 | 월 결제 | 연 결제 (월 환산) | Fast GPU 시간 | Relax 무제한 | Stealth 모드 |
|---|---|---|---|---|---|
| Basic | $10 | $96 ($8) | 월 약 3.3시간 | 없음 | 없음 |
| Standard | $30 | $288 ($24) | 월 15시간 | 이미지 무제한 | 없음 |
| Pro | $60 | $576 ($48) | 월 30시간 | 이미지·영상 무제한 | 있음 |
| Mega | $120 | $1,152 ($96) | 월 60시간 | 이미지·영상 무제한 | 있음 |

Fast GPU 시간을 다 쓰면 시간당 $4에 추가 구매할 수 있습니다. Relax 모드는 대기 시간이 길어지는 대신 생성 횟수 제한 없이 쓰는 방식이라, 이미지를 많이 만드는 분은 Standard 이상이 효율적입니다. Stealth 모드는 만든 이미지를 공개 갤러리에 노출하지 않는 기능으로, 클라이언트 작업처럼 공개되면 곤란한 결과물이 있다면 Pro 이상이 필요합니다.

### 나노바나나 사용 방법별 비용

나노바나나는 Gemini 앱에서 쓰는 방법과 API로 쓰는 방법에 따라 비용 구조가 다릅니다.

| 사용 방법 | 비용 | 특징 |
|---|---|---|
| Gemini 무료 | 0원 | 나노바나나 2 사용 가능, Pro는 제한적으로 제공 |
| Google AI Plus | 월 7,500원 (한국 공식 페이지 기준) | 무료보다 사용량이 늘어남 |
| Google AI Pro | 미국 월 $19.99, 한국 요금은 공식 페이지에서 확인 | 사용량이 크게 늘어남, Flow 등 영상 도구 포함 |
| Google AI Ultra | 한국 월 119,000원부터 | 가장 높은 한도, 눈에 보이는 워터마크 없음 |
| Gemini API (Pro) | 1K·2K 장당 $0.134, 4K 장당 $0.24 | 개발자·대량 작업용 |
| Gemini API (나노바나나 2) | 1K 장당 $0.067, 2K 장당 $0.101, 4K 장당 $0.151 | Pro보다 저렴 |

요금제별 하루 생성 한도는 공식적으로 고정된 숫자가 안내되지 않고 상황에 따라 달라질 수 있으니, 결제 전에 Gemini 구독 페이지에서 현재 혜택을 확인하는 것을 추천합니다. 구글 AI 구독에는 Veo 영상 생성과 저장공간도 함께 들어 있어, 영상까지 만들 계획이라면 [구글 Veo 3.1과 Flow 사용법](../google-veo-flow-guide/) 글도 함께 참고하면 좋습니다.

## 워터마크와 상업적 이용 조건

상업용으로 쓸 이미지라면 워터마크와 이용 조건을 꼭 확인해야 합니다.

| 확인 항목 | 미드저니 | 나노바나나 |
|---|---|---|
| 눈에 보이는 워터마크 | 없음 | 무료·AI Pro는 Gemini 반짝이 표시가 붙음, Ultra와 AI Studio는 없음 |
| 보이지 않는 워터마크 | 공식 안내에서 확인 필요 | 모든 이미지에 SynthID 삽입 |
| 상업적 이용 | 유료 구독자는 가능 | API 약관상 구글이 결과물 소유권을 주장하지 않음 |
| 주의할 조건 | 연 매출 100만 달러 초과 기업은 Pro 또는 Mega 필요 | 생성형 AI 금지 사용 정책 준수, 비슷한 결과가 다른 사용자에게 나올 수 있음 |
| 결과물 공개 여부 | Pro 미만은 갤러리에 공개됨 | 공개 갤러리 없음 |

나노바나나 결과물을 광고나 상세페이지에 쓸 때 눈에 보이는 워터마크가 문제가 된다면, 요금제를 고르기 전에 이 부분을 먼저 확인하세요. 미드저니는 회사 규모에 따라 필요한 요금제가 달라진다는 점이 핵심입니다. 두 도구 모두 약관이 바뀔 수 있으므로 상업적 사용 전에는 공식 약관을 다시 확인하는 것이 안전합니다. AI 결과물의 저작권 문제는 [AI 영상 상업적 이용·저작권, 어디까지 괜찮을까](../ai-video-copyright-commercial/) 글에 자세히 정리해 두었습니다.

## 프롬프트 쓰는 방식 차이

같은 장면을 만들어도 두 도구에 넣는 문장은 조금 다르게 쓰는 것이 좋습니다. 미드저니는 핵심 단어와 파라미터를 짧게 나열하는 방식이 잘 맞습니다.

```
cozy Korean cafe interior, morning sunlight through large windows, latte on wooden table, soft film photography --ar 4:5 --sref [스타일 코드]
```

나노바나나는 사람에게 부탁하듯 상황과 목적을 문장으로 설명하는 방식이 잘 맞습니다.

```
아침 햇살이 큰 창문으로 들어오는 아늑한 한국 카페 내부를 사진처럼 만들어 줘.
나무 테이블 위에 라떼 한 잔이 있고, 인스타그램 피드용 4:5 비율로 부탁해.
```

| 비교 | 미드저니 | 나노바나나 |
|---|---|---|
| 언어 | 영어 키워드가 안정적 | 한국어 문장도 잘 이해함 |
| 비율 지정 | `--ar 16:9` 같은 파라미터 | 문장으로 "16:9 비율로" 요청 |
| 스타일 통일 | `--sref`, 개인화 프로필 | 기준 이미지를 함께 올리고 "이 스타일로" 요청 |
| 수정 | Edit Model, 부분 다시 그리기 | 같은 대화에서 "여기만 바꿔 줘" |
| 글자 넣기 | 문구를 큰따옴표로 감싸기 | 문장으로 문구와 위치를 지정 |

## 용도별 추천

어느 한쪽이 모든 면에서 낫다고 보기는 어렵습니다. 하려는 작업에 따라 고르는 것을 추천합니다.

| 하려는 작업 | 추천 도구 | 이유 |
|---|---|---|
| 앨범 커버, 포스터, 감성 일러스트 | 미드저니 | 분위기와 미감 표현에 강하고 스타일 참조가 편함 |
| 브랜드 그림체 통일 | 미드저니 | `--sref`와 개인화로 같은 톤 유지 |
| 제품 사진 배경 바꾸기, 사진 보정 | 나노바나나 | 대화로 부분 수정 가능 |
| 시리즈 영상용 캐릭터 | 나노바나나 Pro | 참조 이미지 여러 장과 인물 일관성 기능 |
| 카드뉴스, 인포그래픽 | 나노바나나 Pro | 글자 표현과 검색 연동 |
| 비용 없이 먼저 써 보기 | 나노바나나 | Gemini 무료로 시작 가능 |
| 대량 생성 | 미드저니 Standard 이상 | Relax 모드 무제한 |

두 도구를 함께 쓰는 방법도 많이 쓰입니다. 미드저니로 분위기 좋은 기준 이미지를 만든 뒤, 나노바나나에 올려 세부를 대화로 고치는 식입니다. 이렇게 만든 이미지는 영상의 첫 장면으로도 쓸 수 있는데, 그 과정은 [이미지 한 장으로 AI 영상 만들기](../image-to-video-guide/) 글에서 확인할 수 있습니다.

## 마무리

미드저니는 V8.2에서 속도와 글자 표현이 좋아졌고 Edit Model로 참조 기능이 정리되면서, 분위기 있는 이미지와 일관된 그림체가 필요한 작업에 잘 맞습니다. 다만 무료 체험이 없고, 결과물을 비공개로 두려면 Pro 이상이 필요합니다.

나노바나나는 Gemini 무료 사용자도 시작할 수 있고, 한국어 대화로 이미지를 만들고 고칠 수 있어 처음 시작하는 분에게 부담이 적습니다. 다만 요금제에 따라 눈에 보이는 워터마크가 붙을 수 있어 상업용이라면 확인이 필요합니다. 처음이라면 나노바나나로 시작해 보고, 특정 그림체나 미감이 중요해지면 미드저니 Basic 요금제를 한 달 써 보는 방식을 추천합니다. 요금과 한도는 자주 바뀌므로 결제 전에는 각 공식 페이지를 꼭 확인하시기 바랍니다.
