수십 쪽짜리 보고서나 논문, 사업 공고문을 다 읽을 시간이 없어 핵심만 빠르게 파악하고 싶을 때 AI 요약이 큰 도움이 됩니다. 이 글은 업무나 공부에서 긴 문서를 자주 다루는 분을 위해 ChatGPT, Claude, Gemini 노트북(구 NotebookLM)의 문서 업로드 한도와 특징을 2026년 10월 기준 공식 안내와 공개 자료로 비교하고, 그대로 복사해 쓸 수 있는 요약 프롬프트와 결과 검수 방법을 정리합니다.

## AI 문서 요약이 잘 맞는 경우와 주의할 경우

AI 요약은 "무슨 내용이 들어 있는지 빠르게 훑는 일"에 강하고, "숫자와 조항 하나하나가 정확해야 하는 일"에는 반드시 원문 확인이 필요합니다. 용도에 따라 기대치를 다르게 잡는 것이 좋습니다.

| 문서 종류 | AI 요약 활용도 | 주의할 점 |
|---|---|---|
| 업계 보고서·백서 | 높음 (목차별 핵심 정리) | 표·그래프 속 숫자는 원문 쪽수로 다시 확인 |
| 논문 | 높음 (연구 질문, 방법, 결론 정리) | 한계점·전제 조건이 빠지기 쉬움 |
| 정부·지자체 공고문 | 높음 (지원 대상, 일정, 서류 정리) | 마감일·자격 요건은 원문으로 최종 확인 |
| 계약서·약관 | 중간 (조항 구조 파악용) | 법적 판단은 전문가 검토가 필요 |
| 회의록·인터뷰 녹취 | 높음 (결정 사항, 할 일 정리) | 발언자 구분이 틀리는 경우가 있음 |
| 스캔한 이미지 PDF | 낮음~중간 | 글자 인식(OCR) 오류가 요약에 그대로 반영됨 |

회의 녹음을 글로 옮기고 요약하는 방법은 [AI 회의록 자동 정리](../ai-meeting-notes-transcription/) 글에서 따로 다룹니다. 이 글은 이미 만들어진 PDF·문서 파일을 요약하는 데 집중합니다.

## 도구별 문서 업로드 한도 비교

세 도구 모두 PDF를 올리고 질문할 수 있지만 한 번에 다룰 수 있는 분량과 방식이 다릅니다. 아래 표는 2026년 10월 기준 각 사 공식 도움말과 공개 자료를 정리한 것입니다. 한도는 요금제와 시기에 따라 자주 바뀌므로 중요한 작업 전에는 공식 도움말에서 다시 확인하는 것을 추천합니다.

| 항목 | ChatGPT | Claude | Gemini 노트북 (구 NotebookLM) |
|---|---|---|---|
| 파일 1개 최대 크기 | 512MB | 500MB (채팅 업로드 기준) | 200MB |
| 문서 분량 한도 | 문서 파일 1개당 200만 토큰 | PDF 1,000쪽 | 소스 1개당 50만 단어 |
| 한 번에 올리는 개수 | 3시간당 최대 80개 | 채팅 1개당 20개 | 무료 기준 노트북 1개당 소스 50개 |
| 무료 이용 | 가능 (하루 업로드 횟수 제한) | 가능 | 가능 (유료 요금제는 소스 한도 확대) |
| 이미지·표 인식 | 지원 | 100쪽 이하 PDF는 글과 시각 자료 함께 분석, 101~1,000쪽은 글만 분석 | 지원 |
| 주요 지원 형식 | PDF, 워드, 엑셀, 텍스트 등 | PDF, DOCX, CSV, TXT, HTML, EPUB, XLSX 등 | PDF, 구글 문서, 웹 주소, 유튜브 영상 등 |

NotebookLM은 2026년 7월에 이름이 Gemini 노트북(Gemini Notebook)으로 바뀌었습니다. 구글은 이름과 로고만 바뀌고 기존 노트북과 공유 링크는 그대로 유지된다고 안내했습니다. 검색할 때는 두 이름이 함께 쓰이고 있으니 참고하세요.

## 도구별 특징과 추천 용도

업로드 한도만큼 중요한 것은 "답을 어떻게 보여 주는가"입니다. 같은 문서라도 도구마다 잘하는 작업이 조금씩 다릅니다.

| 도구 | 강점 | 잘 맞는 작업 |
|---|---|---|
| ChatGPT | 요약 결과를 표, 메일, 보고서 형식으로 바로 바꾸기 쉬움 | 요약 후 후속 문서(보고 메일, 발표 개요) 작성 |
| Claude | 긴 PDF를 한 번에 읽고 구조를 유지한 채 정리하는 데 강점 | 100쪽 안팎 보고서의 장별 요약, 문서 간 비교 |
| Gemini 노트북 | 답변마다 근거가 된 원문 위치를 표시하고, 여러 소스를 한 노트북에 모아 둠 | 자료 여러 개를 쌓아 두고 계속 질문하는 리서치, 공부 |

정리하면 한 번 읽고 끝낼 문서는 ChatGPT나 Claude, 여러 자료를 모아 두고 반복해서 찾아볼 주제는 Gemini 노트북이 편한 경우가 많습니다. Claude로 문서를 정리한 뒤 글로 다시 쓰는 과정은 [Claude로 블로그 글 초안 쓰는 법](../claude-blog-draft-writing/)도 함께 참고하세요.

## 긴 문서 요약 순서

좋은 요약은 "요약해 줘" 한 줄보다 단계를 나눠 요청할 때 나오는 경우가 많습니다. 아래 순서를 따르면 빠진 내용과 잘못된 내용을 줄일 수 있습니다.

| 단계 | 하는 일 | 이유 |
|---|---|---|
| 1. 파일 준비 | 스캔 PDF는 글자 인식이 되는지 확인하고, 필요 없는 부록은 빼기 | 인식 오류와 불필요한 분량을 줄임 |
| 2. 목적 알려 주기 | 누가, 왜 읽는 요약인지 먼저 설명 | 같은 문서라도 필요한 내용이 달라짐 |
| 3. 구조 파악 | 목차와 장별 한 줄 요약부터 요청 | 전체 흐름을 먼저 잡으면 누락이 줄어듦 |
| 4. 핵심 요약 | 원하는 분량과 형식(표, 글머리표)을 지정 | 결과물을 바로 쓸 수 있는 형태로 받음 |
| 5. 근거 확인 | 핵심 주장마다 쪽수나 원문 문장을 함께 요청 | 지어낸 내용을 걸러 낼 수 있음 |
| 6. 후속 질문 | 이해가 안 되는 부분, 빠진 부분을 다시 질문 | 요약을 내 상황에 맞게 다듬음 |

문서가 너무 길어 한도를 넘는다면 장별로 나눠 올리고 각각 요약한 뒤, 마지막에 요약본끼리 합쳐 달라고 요청하는 방법이 있습니다.

## 바로 쓰는 요약 프롬프트

아래 프롬프트는 파일을 올린 뒤 그대로 붙여 넣고, 대괄호 부분만 바꿔 쓰면 됩니다.

구조부터 파악할 때 쓰는 프롬프트입니다.

```
첨부한 문서의 목차를 정리하고, 각 장의 핵심 내용을 한 문장씩 써 줘.
문서에 없는 내용은 추가하지 말고, 각 장이 시작하는 쪽수도 함께 적어 줘.
```

목적에 맞춘 핵심 요약 프롬프트입니다.

```
나는 [중소기업 마케팅 담당자]이고, 이 문서를 [팀장 보고용]으로 정리하려고 해.
1. 핵심 내용 5가지를 글머리표로 정리해 줘.
2. 우리 업무에 영향을 줄 수 있는 내용을 따로 표로 정리해 줘.
3. 문서에 나온 숫자는 쪽수와 함께 원문 그대로 적어 줘.
4. 확실하지 않은 내용은 "원문 확인 필요"라고 표시해 줘.
```

공고문에서 신청 정보를 뽑을 때 쓰는 프롬프트입니다.

```
이 공고문에서 아래 항목을 표로 정리해 줘.
지원 대상, 지원 내용, 신청 기간, 제출 서류, 선정 방법, 문의처.
문서에 없는 항목은 비워 두지 말고 "문서에 없음"이라고 적어 줘.
```

문서 두 개를 비교할 때 쓰는 프롬프트입니다.

```
첨부한 [작년 보고서]와 [올해 보고서]를 비교해서
달라진 점, 새로 생긴 내용, 빠진 내용을 표로 정리해 줘.
각 항목에 어느 문서 몇 쪽에서 나온 내용인지 함께 적어 줘.
```

## 요약 결과 검수 체크리스트

AI 요약은 그럴듯해 보여도 원문에 없는 내용을 섞거나 중요한 조건을 빼는 경우가 있습니다. 결과를 보고서나 업무 판단에 쓰기 전에 아래 항목을 확인하는 것을 추천합니다.

| 확인 항목 | 확인 방법 | 자주 생기는 문제 |
|---|---|---|
| 숫자·날짜 | 요약에 나온 숫자를 원문 쪽수에서 직접 찾기 | 단위(만 원, 억 원) 혼동, 연도 착오 |
| 조건·예외 | "단", "다만", "제외" 같은 표현이 요약에 반영됐는지 보기 | 예외 조항이 통째로 빠짐 |
| 출처 표시 | Gemini 노트북의 인용 표시나 요청한 쪽수를 눌러 확인 | 쪽수가 실제 내용과 맞지 않음 |
| 지어낸 내용 | "이 내용은 문서 어디에 있어?"라고 다시 질문 | 문서에 없는 일반 상식이 섞임 |
| 표·그래프 | 원문의 표를 직접 열어 수치 비교 | 표의 행과 열을 잘못 읽음 |
| 개인정보·보안 | 회사 규정상 외부 AI에 올려도 되는 문서인지 확인 | 내부 자료를 개인 계정에 올림 |

특히 회사 문서는 업로드 전에 사내 보안 규정을 먼저 확인하세요. 개인 요금제와 기업용 요금제는 데이터 처리 방식이 다를 수 있으므로, 민감한 자료는 회사가 승인한 도구와 계정으로 다루는 것이 안전합니다.

## 자주 묻는 질문

| 질문 | 답변 |
|---|---|
| 무료로도 충분할까요? | 가끔 한두 개 문서를 요약하는 정도라면 세 도구 모두 무료로 시작할 수 있습니다. 업로드 횟수나 소스 개수가 부족해지면 유료 요금제를 검토하세요. |
| 영어 문서를 한국어로 요약할 수 있나요? | 가능합니다. 프롬프트에 "한국어로 요약해 줘"라고 쓰고, 전문 용어는 영어를 괄호에 함께 적어 달라고 하면 원문과 대조하기 쉽습니다. |
| 스캔한 PDF도 되나요? | 글자 인식이 되는 경우가 많지만 흐리거나 손글씨가 섞이면 오류가 늘어납니다. 요약 전에 일부 문장을 그대로 옮겨 달라고 해 인식 상태를 먼저 확인하세요. |
| 요약을 그대로 보고서에 써도 되나요? | 초안으로는 쓸 만하지만 숫자와 결론은 원문 확인을 거친 뒤 쓰는 것을 추천합니다. |

## 마무리

긴 문서 요약은 생성형 AI가 시간을 가장 크게 줄여 주는 업무 중 하나입니다. 한 번 읽고 끝낼 문서는 ChatGPT나 Claude로, 여러 자료를 쌓아 두고 계속 찾아볼 주제는 Gemini 노트북으로 정리하면 효율이 좋습니다. 어떤 도구를 쓰든 목적을 먼저 알려 주고, 구조 파악과 핵심 요약을 나눠 요청하고, 숫자와 조건은 쪽수와 함께 받아 원문으로 확인하는 습관을 들이면 요약 결과를 안심하고 활용할 수 있습니다. 업로드 한도와 무료 범위는 자주 바뀌므로 작업 전에 각 서비스의 공식 도움말을 한 번 더 확인하세요.
