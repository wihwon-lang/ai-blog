AI 그림 저작권을 검색하는 분들이 가장 궁금해하는 것은 두 가지입니다. "AI로 만든 그림을 블로그 썸네일, 굿즈, 광고에 써도 되나?"와 "내가 만든 AI 그림을 남이 가져가면 막을 수 있나?"입니다. 이 글은 2026년 11월 기준 국내 안내서와 주요 도구 약관을 바탕으로, 상업적으로 써도 되는 경우와 조심해야 하는 경우를 표로 정리했습니다.

이 글은 일반적인 정보 정리이며 법률 자문이 아닙니다. 계약 금액이 크거나 분쟁이 생긴 경우에는 변호사나 한국저작권위원회 상담을 받는 것을 권합니다.

## AI 그림 저작권, 결론부터 정리

먼저 자주 묻는 질문에 대한 짧은 답입니다. 핵심은 **"쓸 수 있는가"(도구 약관)와 "보호받는가"(저작권법)가 서로 다른 문제**라는 점입니다.

| 질문 | 짧은 답 |
|---|---|
| AI 그림을 상업적으로 써도 되나? | 대부분의 유료 요금제는 허용. 기준은 각 도구의 이용약관 |
| 무료로 만든 그림도 상업 이용 가능한가? | 도구마다 다름. 무료 체험 결과물은 조건이 따로 붙는 경우가 있음 |
| AI 그림에 저작권이 생기나? | 프롬프트만 넣어 나온 결과물 자체는 저작물로 인정되지 않음 |
| 저작권 등록이 되는 경우는? | 사람이 그린 부분, 직접 고친 부분, 선택·배열한 구성 등 창작적 기여가 있는 부분 |
| AI 그림을 남이 가져가 쓰면? | 순수 AI 결과물은 저작권으로 막기 어려움. 계약·약관으로 대비해야 함 |
| 유명 캐릭터나 작가 그림을 흉내 낸 결과물은? | 기존 작품과 비슷하면 저작권·상표권 침해 위험이 있음 |

즉 상업적으로 "쓰는 것"은 도구 약관만 지키면 대부분 가능하지만, 그 그림을 "내 저작물로 지키는 것"은 사람이 얼마나 손을 댔는지에 달려 있습니다.

## AI 그림 저작권 등록은 어디까지 되나 — 국내 기준

문화체육관광부와 한국저작권위원회는 2025년 6월 「생성형 인공지능 활용 저작물의 저작권 등록 안내서」를 내놓았습니다. 안내서의 중심 원칙은 **저작권 등록 요건은 인간의 창작적 기여**라는 것입니다. AI가 만든 산출물 자체는 현행법상 저작물로 보지 않고, 사람이 창작적으로 기여한 부분만 등록 대상이 됩니다.

| 만든 방식 | 등록 가능한 부분 |
|---|---|
| 프롬프트 입력 후 결과물을 그대로 사용 | 등록 어려움 |
| 사람이 스케치하고 AI가 채색 | 사람이 그린 스케치 부분 |
| 만화에서 글은 사람이, 그림은 AI가 생성 | 글(스토리·대사) 부분 |
| 여러 AI 이미지를 골라 새로운 구성으로 배열 | 선택·배열에 대한 편집저작물 |
| AI 결과물을 사람이 직접 리터칭·합성 | 사람이 수정한 표현 부분 |

국내에서 실제로 등록된 대표 사례는 생성형 AI로 만든 영화 'AI 수로부인'입니다. 이 작품은 영상저작물이 아니라 **편집저작물**로 등록되었습니다. AI가 만든 이미지·영상 자체가 아니라 사람이 요소를 고르고 배열·편집한 부분에 창작성을 인정한 것입니다. AI 그림을 여러 장 묶은 그림책, 화보집, 웹툰도 같은 방식으로 볼 수 있습니다.

등록 신청을 생각한다면 **작업 과정을 기록으로 남기는 것**이 중요합니다. 안내서에서도 프롬프트를 여러 번 고쳐 가며 목적에 맞게 결과물을 다듬은 과정, 사람이 직접 손댄 부분을 설명할 수 있어야 한다는 점을 강조합니다.

| 남겨 둘 기록 | 쓰임 |
|---|---|
| 직접 그린 스케치·러프 원본 파일 | 사람이 그린 부분 증명 |
| 프롬프트 수정 이력과 단계별 결과물 | 의도를 갖고 다듬은 과정 설명 |
| 포토샵 등 편집 전후 파일(레이어 포함) | 직접 수정한 표현 증명 |
| 기획서, 콘티, 배열 순서 메모 | 선택·배열의 창작성 설명 |

## 해외는 어떨까 — 미국 저작권청 기준

미국 저작권청(U.S. Copyright Office)은 2025년 1월 AI 보고서 2부(저작물성)를 공개했습니다. 보고서는 **프롬프트만으로는 결과물에 대한 충분한 통제가 없다**고 보고, 아무리 자세한 프롬프트를 여러 번 넣어 골랐더라도 그것만으로는 저작자가 되기 어렵다는 입장을 밝혔습니다. 다만 사람이 그린 그림을 AI에 넣어 표현이 그대로 남은 경우, AI 결과물을 사람이 수정·배열한 경우는 사람의 몫을 보호할 수 있다고 정리했습니다.

AI 자체를 저작자로 등록해 달라는 Thaler 사건은 2025년 3월 항소법원에서 패소했고, 2026년 3월 연방대법원이 심리를 받아들이지 않으면서 "저작자는 사람이어야 한다"는 판단이 유지되었습니다. 해외 플랫폼에 그림을 팔 계획이라면 국내와 비슷하게 **사람의 기여 부분만 보호된다**고 생각하는 것이 안전합니다.

| 구분 | 한국 | 미국 |
|---|---|---|
| AI 단독 결과물 | 저작물로 보지 않음 | 저작물로 보지 않음 |
| 프롬프트 반복 수정 | 목적성 있는 개선 과정은 기여로 볼 여지를 안내서에서 언급 | 프롬프트만으로는 부족하다는 입장 |
| 사람이 수정·배열한 부분 | 등록 가능 | 등록 가능 |
| 근거 자료 | 저작권 등록 안내서(2025년 6월) | 저작권청 AI 보고서 2부(2025년 1월) |

## 상업적으로 써도 되는 경우 — 도구별 약관 비교

AI 그림을 판매하거나 광고·외주에 쓸 수 있는지는 저작권법보다 **사용한 도구의 이용약관**이 먼저 정합니다. 2026년 11월 기준 주요 도구의 공개 약관 내용은 아래와 같습니다. 약관은 자주 바뀌므로 작업 전에 최신 내용을 다시 확인하세요.

| 도구 | 결과물 권리 | 상업 이용 시 확인할 점 |
|---|---|---|
| 미드저니 | 유료 구독자는 법이 허용하는 범위에서 결과물을 소유 | 연 매출 100만 달러를 넘는 회사(또는 그 직원)는 Pro·Mega 요금제가 필요 |
| ChatGPT(OpenAI) | 법이 허용하는 범위에서 결과물 권리를 이용자에게 양도 | 다른 사람도 비슷한 결과물을 받을 수 있다고 약관에 명시 |
| 어도비 파이어플라이 | 베타 표시가 없는 기능의 결과물은 상업 프로젝트에 사용 가능 | 베타 기능 결과물은 상업 이용 대상에서 빠질 수 있음 |

여기서 "결과물을 소유한다"는 말은 **도구 회사가 권리를 주장하지 않는다**는 뜻에 가깝습니다. 저작권법상 보호를 받는지는 앞에서 본 것처럼 별개 문제입니다. 예를 들어 미드저니로 만든 그림을 그대로 굿즈로 팔 수는 있지만, 다른 판매자가 같은 그림을 베껴 팔 때 저작권으로 막기는 어렵습니다.

어도비는 파이어플라이 모델을 어도비 스톡처럼 라이선스를 받은 콘텐츠와 저작권이 만료된 공공 도메인 자료로 학습했다고 안내합니다. 학습 데이터 출처를 설명해야 하는 기업 클라이언트 작업에서는 이런 차이가 선택 기준이 되기도 합니다. 도구별 가격과 기능 차이는 [미드저니 vs 나노바나나](../midjourney-vs-nano-banana/) 글에서 비교했습니다.

## 상업적으로 쓰면 안 되는 경우 — AI 그림 저작권 침해 사례 유형

도구 약관에서 상업 이용을 허용해도, 결과물이 **다른 사람의 권리를 침해하면** 책임은 그림을 쓴 사람에게 돌아옵니다. 저작권 침해는 일반적으로 기존 작품을 보고 만들었는지(의거성)와 표현이 실질적으로 비슷한지를 함께 따집니다. 자주 문제가 되는 유형은 아래와 같습니다.

| 위험한 경우 | 왜 문제인가 | 대신 할 수 있는 것 |
|---|---|---|
| 유명 애니·게임 캐릭터를 그대로 생성 | 캐릭터 저작권·상표권 침해 | 직접 설정한 오리지널 캐릭터 사용 |
| 특정 작가 이름을 넣어 작품을 거의 그대로 재현 | 기존 작품과 실질적으로 비슷해질 위험 | 색감·조명·기법 같은 일반 용어로 스타일 지정 |
| 남의 사진·그림을 참조 이미지로 넣어 변형 | 원본 이미지의 2차적 저작물 문제 | 직접 찍은 사진이나 라이선스 있는 이미지 사용 |
| 실존 인물 얼굴을 넣은 광고 이미지 | 초상권·퍼블리시티권 문제 | 가상 인물 생성, 모델 동의서 확보 |
| 브랜드 로고·제품 디자인이 들어간 결과물 | 상표권·디자인권 문제 | 로고 없는 일반 제품으로 묘사 |

화풍이나 분위기 자체는 일반적으로 저작권 보호 대상이 아니라는 해석이 많지만, 특정 작품의 구도·캐릭터·세부 표현까지 따라가면 이야기가 달라집니다. 프롬프트에 작가 이름이나 작품 제목을 넣는 습관은 상업용 작업에서는 피하는 것이 좋습니다. 조명·구도 같은 일반 용어로 원하는 느낌을 내는 방법은 [AI 이미지 프롬프트 작성법](../ai-image-prompt-formula/) 글에 정리했습니다.

```
상업용으로 쓰기 좋은 프롬프트 예시
A cozy cafe interior illustration, warm afternoon light, soft watercolor texture,
pastel color palette, wide shot, original characters, no logos, no text
```

## AI 그림 상업 이용 전 체크리스트

판매·광고·외주에 쓰기 전에 아래 항목을 확인하면 대부분의 문제를 미리 걸러낼 수 있습니다.

| 체크 | 확인할 내용 |
|---|---|
| ☐ | 유료 요금제(또는 상업 이용이 허용된 요금제)로 만들었는가 |
| ☐ | 회사 매출 기준 등 도구별 추가 조건에 해당하지 않는가 |
| ☐ | 베타 기능이나 무료 체험으로 만든 결과물이 섞이지 않았는가 |
| ☐ | 유명 캐릭터, 실존 인물, 브랜드 로고가 들어가지 않았는가 |
| ☐ | 프롬프트에 작가 이름·작품 제목을 넣지 않았는가 |
| ☐ | 판매 플랫폼의 AI 콘텐츠 규정을 확인했는가 |
| ☐ | 클라이언트에게 AI 사용 사실과 권리 범위를 계약서에 적었는가 |
| ☐ | 작업 과정(원본, 프롬프트, 편집 파일)을 보관하고 있는가 |

외주 작업에서는 특히 **"저작권 양도"를 약속하지 않도록** 주의해야 합니다. 순수 AI 결과물에는 양도할 저작권이 없을 수 있으므로, 계약서에는 "AI 도구를 사용해 제작했으며, 사람이 작업한 부분의 권리와 결과물 사용 권한을 넘긴다"처럼 범위를 구체적으로 적는 편이 분쟁을 줄입니다. 스톡 사이트 판매처럼 플랫폼이 따로 규칙을 두는 경우는 [어도비 스톡 AI 이미지 판매](../adobe-stock-ai-image-selling/) 글을 참고하세요.

## AI 그림 저작권 문제, 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 블로그 썸네일에 AI 그림을 써도 되나? | 도구 약관이 허용하면 가능. 실존 인물·로고만 피하면 위험이 낮은 편 |
| AI 그림을 굿즈로 팔아도 되나? | 상업 이용이 허용된 요금제라면 가능. 다만 독점권은 약하므로 디자인을 직접 수정해 두는 것이 유리 |
| 내 AI 그림을 누가 베껴 쓰면? | 순수 AI 결과물은 저작권으로 막기 어려움. 직접 수정·편집한 부분이 있으면 그 부분은 주장 가능 |
| AI로 만들었다고 꼭 밝혀야 하나? | 「인공지능기본법」의 표시 의무는 AI 서비스 제공 사업자 대상. 다만 플랫폼·클라이언트가 표시를 요구하는 경우가 있음 |
| 저작권 등록 신청은 어디서 하나? | 한국저작권위원회 저작권 등록 시스템에서 신청하며, AI 활용 사실과 사람의 기여 부분을 밝혀야 함 |
