제품 사진을 찍으면 배경에 책상, 벽지, 생활용품이 함께 찍혀 깔끔하지 않은 경우가 많습니다. 예전에는 포토샵으로 한 장씩 '누끼'를 따야 했지만, 지금은 AI 도구가 몇 초 만에 배경을 지우고 새 배경까지 만들어 줍니다. 이 글에서는 제품 사진을 처음 다루는 분에게 배경 제거와 합성의 순서, 도구별 차이, 자연스럽게 보이게 만드는 요령을 정리했습니다.

## 배경 제거와 배경 합성은 다른 작업입니다

AI 이미지 편집에서 많이 쓰는 기능은 크게 두 가지입니다. 하나는 피사체만 남기고 배경을 투명하게 지우는 **배경 제거**이고, 다른 하나는 지운 자리에 새로운 배경을 만들어 넣는 **배경 합성(배경 생성)**입니다. 두 작업은 쓰는 도구와 주의할 점이 다르기 때문에 먼저 구분해 두는 것이 좋습니다.

| 구분 | 배경 제거 | 배경 합성 |
|---|---|---|
| 결과물 | 투명 배경 PNG 또는 흰 배경 이미지 | 새 장면 속에 제품이 놓인 이미지 |
| 주 용도 | 대표이미지, 오픈마켓 흰 배경 컷, 디자인 소스 | 상세페이지 연출 컷, SNS 광고, 배너 |
| AI가 하는 일 | 피사체 경계를 찾아 잘라냄 | 배경을 새로 그리고 그림자·조명을 맞춤 |
| 실물과 달라질 위험 | 낮음 (경계만 다듬음) | 있음 (제품 모양·색이 바뀔 수 있음) |
| 대표 도구 | remove.bg, Adobe Express, 캔바, 스마트폰 기본 기능 | 포토룸, 나노바나나, 캔바 매직 편집 |

제품의 모양과 색은 실제 사진을 기준으로 지키고, AI는 배경을 정리하거나 분위기를 더하는 데 쓰는 것이 기본 원칙입니다. 상세페이지 전체 흐름은 [AI로 상품 상세페이지 이미지 만들기](../ai-product-detail-page-images/) 글에서 자세히 다루었습니다.

## 배경 제거 도구 비교

배경 제거만 필요하다면 별도 도구를 설치하지 않아도 되는 경우가 많습니다. 아래는 2026년 10월 기준 공식 안내를 바탕으로 정리한 주요 도구입니다. 요금은 환율과 프로모션에 따라 자주 바뀌므로 표에는 요금 구조만 적었고, 정확한 가격은 각 공식 페이지에서 확인하는 것을 추천합니다.

| 도구 | 무료로 할 수 있는 것 | 유료로 바뀌는 점 | 특징 |
|---|---|---|---|
| remove.bg | 웹사이트에서 저해상도 미리보기 다운로드 | 크레딧으로 고해상도(최대 50메가픽셀) 다운로드 | 배경 제거 전문, API 제공 |
| Adobe Express | 이미지 배경 제거 무료 (JPEG·PNG·WebP) | 영상 배경 제거 등은 Premium 플랜 | 제거 후 바로 디자인 편집 가능 |
| 캔바(Canva) | 무료 플랜은 기본 배경 제거 기능 사용 불가 | Pro 등 유료 플랜에서 사용 (9MB 미만 사진) | 템플릿과 바로 연결, 무료 외부 앱도 있음 |
| 포토룸(Photoroom) | 무료 플랜 제공 (워터마크 포함) | 워터마크 제거, 고해상도, 일괄 편집 | 제품 사진 특화, 배경 생성까지 한 번에 |
| 스마트폰·PC 기본 기능 | 아이폰 '피사체 들어올리기', 갤럭시 갤러리 객체 추출, 윈도우 그림판 배경 제거 등 | 해당 없음 | 설치 없이 빠르게 처리, 세밀한 조정은 어려움 |

한두 장을 빠르게 처리할 때는 스마트폰 기본 기능이나 Adobe Express로 충분한 경우가 많습니다. 수십 장 이상을 같은 형식으로 만들어야 한다면 일괄 편집을 지원하는 포토룸 유료 플랜이나 remove.bg 크레딧을 고려해 볼 만합니다. 캔바를 이미 디자인 작업에 쓰고 있다면 Pro 구독 안에서 배경 제거까지 해결하는 방법도 있습니다.

## 배경을 잘 지우기 위한 촬영 요령

AI 배경 제거의 품질은 원본 사진에 크게 좌우됩니다. 피사체와 배경의 경계가 분명할수록 결과가 깔끔하고, 경계가 흐리면 아무리 좋은 도구를 써도 테두리가 뜯기거나 배경이 남습니다.

| 촬영 요소 | 추천 방법 | 피해야 할 것 |
|---|---|---|
| 배경색 | 제품과 대비되는 단색 (흰 제품이면 회색·짙은 색) | 제품과 비슷한 색, 무늬 있는 천 |
| 조명 | 창가의 부드러운 자연광, 양쪽에서 고르게 | 한쪽만 강한 직사광선, 형광등 아래 노란 빛 |
| 초점 | 제품 전체가 선명하게 | 인물 모드의 강한 배경 흐림 (경계가 뭉개짐) |
| 구도 | 제품 주변에 여백을 넉넉히 | 프레임 끝에 제품이 잘린 사진 |
| 해상도 | 스마트폰 기본 카메라 원본 그대로 | 메신저로 주고받아 압축된 사진 |

유리병, 투명 컵, 머리카락, 털 소재처럼 경계가 복잡한 제품은 AI가 가장 어려워하는 대상입니다. 이런 제품은 단색 배경 앞에서 촬영하고, 결과물을 확대해 테두리를 꼭 확인하는 것이 좋습니다.

## 새 배경에 자연스럽게 합성하는 법

배경 합성은 두 가지 방법이 있습니다. 하나는 배경을 지운 PNG를 캔바나 Adobe Express 같은 디자인 도구에서 다른 배경 이미지 위에 올리는 **직접 합성**이고, 다른 하나는 나노바나나나 포토룸에 사진을 올리고 배경을 새로 만들어 달라고 요청하는 **AI 생성 합성**입니다.

직접 합성은 제품이 바뀔 위험이 없지만 그림자와 조명이 어색해지기 쉽습니다. AI 생성 합성은 그림자와 빛을 자연스럽게 맞춰 주는 대신, 제품의 글자나 색이 미세하게 바뀌는 경우가 있습니다. 나노바나나처럼 대화로 수정하는 도구를 쓸 때는 아래처럼 **바꾸지 말아야 할 것**을 먼저 적는 것이 중요합니다.

```
첨부한 핸드크림 사진을 사용해 주세요.
제품의 모양, 색상, 라벨 글자, 크기 비율은 절대 바꾸지 말고 그대로 유지해 주세요.
배경만 밝은 대리석 욕실 선반으로 바꿔 주세요.
왼쪽 위에서 부드러운 자연광이 들어오고, 제품 아래에 옅은 그림자가 생기게 해 주세요.
배경은 살짝 흐리게, 제품은 화면 중앙에 두고 정사각형 비율로 만들어 주세요.
```

결과가 어색하면 같은 대화에서 한 가지씩 고치는 것이 효과적입니다.

```
제품은 그대로 두고, 그림자를 조금 더 진하게 해 주세요.
배경의 수건만 지워 주세요.
```

조명 방향, 렌즈 느낌, 분위기를 표현하는 용어는 [AI 이미지 프롬프트 기본 공식](../ai-image-prompt-formula/) 글에 정리해 두었습니다. 합성 결과가 자연스러운지는 아래 기준으로 확인할 수 있습니다.

| 확인 항목 | 자연스러운 경우 | 어색한 경우와 해결 방법 |
|---|---|---|
| 그림자 방향 | 배경의 빛 방향과 같음 | 방향이 반대면 "그림자를 오른쪽 아래로" 요청 |
| 접지감 | 제품이 바닥에 닿아 있음 | 떠 보이면 "제품 아래 접촉 그림자 추가" 요청 |
| 색온도 | 제품과 배경의 톤이 비슷함 | 배경이 따뜻한데 제품만 차가우면 전체 톤 맞추기 |
| 크기 비율 | 주변 소품과 크기가 현실적임 | 제품이 너무 크거나 작으면 소품을 줄이거나 빼기 |
| 원근 | 제품과 배경의 시점이 같음 | 위에서 찍은 제품을 정면 배경에 넣지 않기 |

## 자주 생기는 문제와 해결법

AI 배경 제거와 합성에서 반복해서 나오는 문제는 대부분 원인이 정해져 있습니다. 문제가 생기면 도구를 바꾸기 전에 원본 사진과 요청 문장을 먼저 점검해 보세요.

| 문제 | 주요 원인 | 해결 방법 |
|---|---|---|
| 테두리에 배경색이 남음 | 제품과 배경색이 비슷함 | 대비되는 배경에서 다시 촬영, 도구의 지우개·복원 브러시로 보정 |
| 제품 일부가 같이 지워짐 | 손잡이·끈 등 얇은 부분 | 해당 부분을 복원 브러시로 되살리기 |
| 투명한 부분이 하얗게 막힘 | 유리·비닐 소재 | 단색 배경에서 촬영 후 투명도 조정, 필요하면 수작업 보정 |
| 라벨 글자가 바뀜 | AI 생성 합성에서 제품까지 다시 그림 | "라벨 글자 그대로 유지" 명시, 직접 합성 방식으로 전환 |
| 제품 색이 달라짐 | 배경 조명에 맞춰 색이 보정됨 | 원본과 나란히 비교, 색이 중요한 제품은 직접 합성 사용 |
| 결과물 화질이 낮음 | 무료 미리보기, 압축된 원본 | 원본 해상도 사진 사용, 고해상도 다운로드 조건 확인 |
| 워터마크가 붙음 | 무료 플랜 정책 | 상업용이면 워터마크 없는 요금제인지 확인 |

특히 나노바나나는 Gemini 무료·AI Pro 요금제 결과물에 눈에 보이는 표시가 붙을 수 있고, 포토룸도 무료 플랜 결과물에 워터마크가 들어갑니다. 판매용 이미지라면 작업을 시작하기 전에 요금제별 워터마크 조건을 확인하는 것이 좋습니다. 이미지 도구별 요금과 워터마크 차이는 [미드저니 vs 나노바나나 비교](../midjourney-vs-nano-banana/) 글에서 더 자세히 볼 수 있습니다.

## 판매용으로 쓸 때 지킬 것

배경을 바꾼 제품 사진은 쇼핑몰, 오픈마켓, 광고에 바로 쓰이는 경우가 많습니다. 이때는 이미지 품질만큼 소비자가 오해하지 않도록 하는 것이 중요합니다.

| 원칙 | 이유 |
|---|---|
| 제품 자체는 실제 사진 그대로 사용 | AI가 모양·색·구성을 바꾸면 실물과 다른 광고가 될 수 있음 |
| 크기를 오해하게 만드는 배경 피하기 | 작은 제품을 크게 보이게 하는 소품 배치는 분쟁 원인이 됨 |
| AI 활용 사실 안내 | 2026년부터 네이버쇼핑·쿠팡 등에서 AI 생성물 관련 기준이 강화됨 |
| 다른 사람의 사진을 배경으로 쓰지 않기 | 배경 이미지에도 저작권이 있음 |
| 원본 사진 보관 | 실물과 같다는 것을 설명할 때 근거가 됨 |

오픈마켓별 AI 생성물 기준은 자주 바뀌므로 상품을 등록하기 전에 판매자센터 공지사항에서 최신 내용을 확인하세요.

## 마무리

AI 배경 제거는 이제 스마트폰 기본 기능만으로도 충분히 쓸 만한 수준이 되었고, 배경 합성까지 더하면 촬영 장소가 없어도 다양한 연출 컷을 만들 수 있습니다. 다만 결과의 품질은 원본 사진에서 대부분 결정되므로, 단색 배경과 고른 조명으로 촬영하는 습관을 먼저 들이는 것을 추천합니다.

정리하면 흰 배경 대표이미지는 배경 제거 도구로, 분위기 있는 연출 컷은 직접 합성이나 AI 생성 합성으로 만들고, 어떤 경우든 제품의 모양·색·글자는 실물과 비교해 확인하는 순서가 안전합니다. 도구별 무료 범위와 요금은 자주 바뀌므로 결제 전에는 각 공식 페이지를 다시 확인하시기 바랍니다.
