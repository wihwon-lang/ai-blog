AI 이미지 생성 사이트는 많지만, 무료로 얼마나 쓸 수 있는지와 어떤 작업에 강한지는 사이트마다 꽤 다릅니다. 이 글은 처음 AI 그림을 만들어 보려는 분이나 지금 쓰는 도구의 무료 한도가 아쉬운 분을 위해, 2026년 11월 기준 각 서비스의 공식 요금·도움말 페이지를 바탕으로 무료 범위와 고르는 기준을 정리했습니다. 무료 사용량 숫자는 공식 페이지에 적힌 것만 옮겼고, 숫자를 밝히지 않은 곳은 그렇게 표시했습니다.

## 먼저 결론 — 용도별 추천 사이트

AI 이미지 생성 사이트를 하나만 고르기 어렵다면 아래 표에서 내 용도에 맞는 줄부터 보시면 됩니다.

| 이런 분께 | 먼저 써 볼 사이트 | 이유 |
|---|---|---|
| 한국어로 대화하듯 만들고 싶다 | 챗GPT, 제미나이 | 한국어 요청을 그대로 이해하고, 결과를 말로 고쳐 달라고 할 수 있음 |
| 사진 보정·합성을 하고 싶다 | 제미나이(나노바나나) | 올린 사진을 바탕으로 부분 편집하는 데 강점 |
| 돈 들이지 않고 여러 장 뽑고 싶다 | 빙 이미지 크리에이터 | 하루 빠른 생성 횟수와 일반 속도 생성 한도가 공개되어 있음 |
| 광고·상업용으로 쓸 이미지가 필요하다 | 어도비 파이어플라이 | 파이어플라이 모델 결과물의 상업적 이용을 공식적으로 안내 |
| 포스터·카드뉴스 디자인까지 한 번에 | 캔바 | 생성한 이미지를 바로 디자인 템플릿에 넣을 수 있음 |
| 이미지 안에 영문 글자를 넣고 싶다 | 아이디오그램 | 로고·포스터처럼 글자가 들어간 이미지에 맞춰진 서비스 |
| 그림체를 세밀하게 고르고 싶다 | 레오나르도 | 여러 모델과 스타일 설정을 고를 수 있음 |
| 예술적인 고품질 이미지가 목표다 | 미드저니 | 무료 체험은 없고 유료 구독 필요 |

처음이라면 이미 계정이 있는 챗GPT나 제미나이로 시작하고, 한도가 아쉬울 때 빙 이미지 크리에이터나 파이어플라이를 함께 쓰는 조합이 부담이 적습니다.

## AI 이미지 생성 사이트 무료 범위 비교

무료로 얼마나 쓸 수 있는지가 가장 많이 묻는 부분입니다. 공식 페이지 기준으로 정리하면 다음과 같습니다.

| 사이트 | 무료 사용 | 공식 페이지에 적힌 무료 범위 (2026년 11월 기준) |
|---|---|---|
| 챗GPT | 가능 | 무료 요금제는 '제한된 이미지 생성'으로 표시, 정확한 장수는 공개하지 않음 |
| 제미나이 | 가능 | 무료 사용자도 나노바나나 2로 이미지 생성 가능, 사용량은 5시간마다 회복되고 주간 한도가 있음 |
| 빙 이미지 크리에이터 | 가능 | 하루 15회 빠른 생성, 이후 일반 속도로 24시간에 최대 200개 프롬프트 |
| 어도비 파이어플라이 | 가능 | '제한된 무료 일일 생성'으로 표시, 정확한 횟수는 공개하지 않음 |
| 캔바 | 가능 | 무료 계정은 프리미엄 AI 도구를 매월 제한된 횟수만 사용, 남은 양은 설정의 결제 메뉴에서 확인 |
| 아이디오그램 | 가능 | 주 단위로 무료 크레딧 지급, 수량과 대상 계정 조건은 공식 페이지에서 확인 |
| 레오나르도 | 가능 | 매일 무료 토큰 지급, 수량은 공식 요금 페이지에서 확인 |
| 미드저니 | 불가 | 웹사이트와 디스코드에서는 무료 체험 없음 |

무료 사용량은 대부분 계정 단위로 주어지기 때문에, 이 표의 사이트는 기본적으로 로그인한 상태에서 쓰는 방식입니다. "로그인 없이 쓰는 사이트"를 찾는 분도 많지만, 계정 없이 쓰는 서비스는 운영 주체나 이미지 이용 조건을 확인하기 어려운 경우가 많아 업무용으로는 추천하지 않습니다.

챗GPT의 한도가 막혔을 때 확인할 순서는 [챗GPT 이미지 생성 제한 — 하루 한도와 막혔을 때 해결법](../chatgpt-image-generation-limit/)에 따로 정리해 두었습니다.

## 유료로 바꾸면 얼마인가 — 가격 비교

무료 한도로 부족해지면 유료 요금제를 검토하게 됩니다. 공식 페이지에서 금액을 확인한 곳만 적었습니다.

| 사이트 | 가장 저렴한 유료 요금제 | 포함 내용 |
|---|---|---|
| 어도비 파이어플라이 | Firefly Standard 월 9.99달러 | 월 2,000 생성 크레딧 |
| 어도비 파이어플라이 | Firefly Pro 월 19.99달러 | 월 4,000 생성 크레딧 (기간 한정 할인이 붙는 경우가 있음) |
| 미드저니 | Basic 월 10달러 | 연간 결제 시 20% 할인 |
| 챗GPT | Go·Plus·Pro | 요금제가 올라갈수록 이미지 생성량이 늘어남, 가격은 지역별로 달라 요금 페이지에서 확인 |
| 제미나이 | 구글 AI 플러스·프로·울트라 | 무료 대비 2배·4배 등 사용량 배수로 안내, 가격은 구글 원 요금 페이지에서 확인 |

달러로 결제하는 서비스는 환율과 카드사 해외 결제 수수료에 따라 실제 청구 금액이 달라집니다. 미드저니 요금제는 [미드저니 가격 — 요금제 비교와 무료로 쓸 수 있는지](../midjourney-pricing/)에서 더 자세히 비교했습니다.

## 사이트별 특징 한눈에 보기

같은 무료라도 잘하는 작업이 다릅니다. 기능 기준으로 정리하면 아래와 같습니다.

| 사이트 | 한국어 요청 | 사진 올려서 편집 | 잘 맞는 작업 | 알아 둘 점 |
|---|---|---|---|---|
| 챗GPT | 자연스럽게 가능 | 가능 | 일러스트, 썸네일 시안, 한글 글자 넣기 시도 | 무료 한도가 숫자로 공개되지 않음 |
| 제미나이 | 자연스럽게 가능 | 가능 | 사진 보정, 인물·배경 합성, 캐릭터 유지 | 사용량이 연산량 기준이라 장수가 일정하지 않음 |
| 빙 이미지 크리에이터 | 가능 | 생성 이미지 편집 기능 제공 | 많은 시안을 빠르게 뽑기 | 마이크로소프트 개인 계정 필요, 회사·학교 계정은 지원하지 않음 |
| 어도비 파이어플라이 | 가능 | 가능 | 광고 소재, 제품 배경, 포토샵 연계 작업 | 제휴 모델로 만든 결과는 직접 이용 조건 확인 필요 |
| 캔바 | 가능 | 가능 | 카드뉴스, 포스터, SNS 게시물 | 생성 횟수가 모든 프리미엄 AI 도구와 합산됨 |
| 아이디오그램 | 영어가 유리 | 가능 | 영문 글자가 들어간 포스터·로고 시안 | 무료 크레딧 조건이 가입 방식에 따라 다를 수 있음 |
| 레오나르도 | 영어가 유리 | 가능 | 게임·판타지 그림체, 스타일 실험 | 메뉴와 모델 종류가 많아 처음엔 복잡하게 느껴질 수 있음 |
| 미드저니 | 영어가 유리 | 가능 | 분위기 있는 예술 이미지 | 유료 전용 |

한국어 문장을 이미지 속에 정확히 넣는 작업은 아직 어느 도구나 실수가 생길 수 있습니다. 글자가 중요한 이미지라면 그림만 AI로 만들고 글자는 캔바 같은 디자인 도구에서 얹는 방식이 안정적입니다.

## 상업적 이용과 저작권, 무엇을 확인해야 할까

블로그 썸네일이나 광고에 쓸 생각이라면 사이트를 고르기 전에 이용 조건을 먼저 봐야 합니다. 같은 사이트라도 무료·유료 요금제나 사용한 모델에 따라 조건이 다를 수 있습니다.

| 확인할 것 | 왜 중요한가 | 확인 위치 |
|---|---|---|
| 결과물 상업적 이용 허용 여부 | 광고·판매용 사용 가능 여부가 갈림 | 서비스 이용약관, 요금 페이지 FAQ |
| 무료 요금제 이미지 공개 여부 | 일부 서비스는 무료 생성물이 다른 사용자에게 보일 수 있음 | 요금 페이지의 공개·비공개 생성 항목 |
| 사용한 모델의 조건 | 파이어플라이처럼 제휴 모델 결과물은 조건이 다를 수 있음 | 생성 화면의 모델 정보, FAQ |
| 업로드한 사진의 권리 | 남의 사진을 올려 편집하면 문제 소지가 있음 | 각 서비스 사용 정책 |
| 실존 인물·상표 포함 여부 | 초상권·상표권 문제로 이어질 수 있음 | 사용 정책, 콘텐츠 정책 |

어도비는 파이어플라이 모델로 만든 결과물을 상업적 용도로 쓸 수 있다고 FAQ에 밝히고 있습니다. 다만 AI 이미지 자체의 저작권 인정 여부는 별개의 문제이므로, 자세한 기준은 [AI 그림 저작권 — 상업적으로 써도 되는 경우와 안 되는 경우](../ai-image-copyright-commercial/)를 함께 참고하시면 좋습니다.

## 처음 쓸 때 결과를 좋게 만드는 요령

어느 사이트를 쓰든 요청을 잘 적으면 다시 만드는 횟수가 줄어 무료 한도를 아낄 수 있습니다.

| 요령 | 예시 | 효과 |
|---|---|---|
| 용도를 먼저 밝히기 | "유튜브 썸네일 배경으로 쓸 이미지" | 구도와 여백이 용도에 맞게 나옴 |
| 비율을 숫자로 적기 | "가로 16:9", "세로 9:16" | 비율이 틀려 다시 만드는 일 방지 |
| 장면을 구체적으로 | 장소, 시간대, 인물 수, 행동 | 엉뚱한 장면이 나오는 경우 감소 |
| 그림체 지정 | 수채화, 3D 일러스트, 사진처럼 | 원하는 분위기에 빨리 도달 |
| 수정은 한 가지씩 | "배경만 밤으로 바꿔 줘" | 다른 부분이 바뀌는 재작업 방지 |

아래처럼 한 번에 조건을 몰아 적는 방식을 추천합니다.

```
블로그 대표 이미지로 쓸 그림을 만들어 줘.
가로 16:9 비율, 창가 책상 위 노트북과 커피잔,
오후 햇살이 들어오는 장면, 파스텔 톤 플랫 일러스트,
이미지 안에 글자는 넣지 마.
```

영어 위주 사이트(아이디오그램, 레오나르도, 미드저니)에서는 같은 내용을 영어로 옮겨 넣으면 의도에 더 가깝게 나오는 경우가 많습니다. 프롬프트 구조는 [AI 이미지 프롬프트 작성법 — 5칸 공식과 바로 쓰는 용어 모음](../ai-image-prompt-formula/)에 정리해 두었습니다.

## 마무리

AI 이미지 생성 사이트는 "어디가 제일 좋다"보다 "내 작업에 무엇이 맞나"로 고르는 편이 실패가 적습니다. 한국어로 편하게 만들고 고치려면 챗GPT와 제미나이, 무료로 많은 시안을 뽑으려면 빙 이미지 크리에이터, 상업용 이미지가 필요하면 파이어플라이, 디자인까지 이어 가려면 캔바를 먼저 살펴보시길 추천합니다. 무료 범위와 요금은 자주 바뀌므로, 결제하거나 업무에 쓰기 전에는 각 서비스의 공식 요금 페이지에서 현재 조건을 다시 확인하시기 바랍니다.
