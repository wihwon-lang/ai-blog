시댄스 2.5는 바이트댄스가 2026년 7월 31일에 공개한 AI 영상 생성 모델로, 한 번에 최대 30초 영상을 만들고 사진·영상·음성 참고 자료를 많이 넣을 수 있는 것이 특징입니다. 이 글은 시댄스 2.0을 써 봤거나 새로 시작하려는 분께 2.5에서 무엇이 바뀌었는지, 어디서 어떻게 쓰는지, 한 달 요금으로 몇 초를 만들 수 있는지를 2026년 11월 기준 공식 페이지 내용으로 정리합니다.

## 시댄스 2.5 핵심 요약

먼저 결론부터 정리합니다. 국내에서는 보통 **드리미나(Dreamina) 웹**이나 **캡컷(CapCut)** 에서 시댄스 2.5를 고르면 됩니다. 2.0보다 길고 정교한 영상을 만들 수 있지만, 같은 길이를 만들 때 크레딧은 두 배 넘게 듭니다.

| 항목 | 내용 (2026년 11월 기준) |
|---|---|
| 만든 곳 | 바이트댄스 Seed 팀 |
| 공개일 | 2026년 7월 31일 |
| 한 번에 만드는 길이 | 최대 30초 (2.0은 15초) |
| 참고 자료 | 이미지 최대 30개, 영상 10개, 오디오 10개 (드리미나·캡컷 기준 전체 최대 50개) |
| 소리 | 영상과 오디오를 함께 생성, 싱크 유지 |
| 쓰는 곳 | 드리미나 웹, 캡컷 구독 계정, BytePlus ModelArk API |
| 드리미나 720p 비용 | 1초당 37크레딧 |

## 시댄스 2.0과 달라진 점

공식 블로그에서 강조하는 변화는 크게 세 가지입니다. 한 번에 만드는 길이가 늘었고, 참고 자료를 더 많이 넣을 수 있으며, 만든 영상의 일부만 고치는 편집 기능이 추가됐습니다.

| 비교 | 시댄스 2.0 | 시댄스 2.5 |
|---|---|---|
| 1회 생성 길이 | 최대 15초 | 최대 30초, 이어 붙이기로 더 길게 가능 |
| 긴 영상 모드 | 없음 | 베타로 최대 180초 (드리미나·캡컷 안내 기준) |
| 참고 자료 수 | 상대적으로 적음 | 최대 50개 (이미지·영상·오디오·텍스트) |
| 부분 편집 | 다시 생성하는 방식 | 특정 구간(타임스탬프)·인물·요소만 수정 |
| 기타 편집 | 기본 생성 위주 | 그린스크린 편집, 카메라 시점 편집, 참고 기반 편집 |
| 드리미나 720p 비용 | 1초당 17크레딧 (Fast 8, Mini 5) | 1초당 37크레딧 |

길이가 30초로 늘어난 것은 숏폼에서 의미가 큽니다. 15초 두 컷을 이어 붙이면 인물 얼굴이나 조명이 바뀌는 경우가 많은데, 한 번에 30초를 만들면 장면이 끊기지 않습니다. 해상도는 출처마다 표현이 다릅니다. 캡컷 소개 페이지는 4K 출력을 내세우고, 드리미나의 Draft 모드는 480p 초안과 1080p 최종본을 기준으로 설명합니다. 실제로 고를 수 있는 해상도는 계정과 요금제에 따라 다르니 생성 화면에서 확인하세요.

## 시댄스 2.5 사용법 — 드리미나에서 만드는 순서

드리미나 공식 안내에 나온 순서를 따라가면 처음이어도 어렵지 않습니다.

| 단계 | 할 일 | 요령 |
|---|---|---|
| 1 | 드리미나 'AI Video' 화면에서 모델을 Seedance 2.5로 선택 | 목록에 없으면 계정 지역이나 요금제를 확인 |
| 2 | 'Omni reference' 모드를 켜고 + 버튼으로 자료 추가 | 인물 사진, 배경, 음악, 콘티 이미지 등 |
| 3 | 프롬프트 작성, @Image1처럼 자료를 지정 | 장면 순서대로 카메라·조명·분위기·소리를 적기 |
| 4 | 화면 비율과 길이를 고르고 Generate | 쇼츠는 세로, 영화 느낌은 가로 |
| 5 | 결과 확인 후 필요하면 업스케일·프레임 보간 | 보간은 24fps를 30fps나 60fps로 올림 |
| 6 | 위쪽 Download 버튼으로 저장 | 마음에 안 드는 구간만 다시 생성 가능 |

프롬프트에서 참고 자료를 지정하는 방식은 아래처럼 쓰면 됩니다. 자료 번호와 역할을 분명히 적어 주는 것이 핵심입니다.

```
@Image1의 여성이 주인공, @Image2의 카페가 배경.
0~10초: 창가 자리에 앉아 커피를 마시는 모습, 천천히 다가가는 카메라.
10~20초: 휴대폰을 보고 웃음, 따뜻한 오후 햇살.
20~30초: 일어나서 문 밖으로 나감, 카메라는 뒤에서 따라감.
배경음은 @Audio1의 잔잔한 피아노, 카페 소음은 작게.
```

카메라 움직임이나 조명을 표현하는 용어가 헷갈린다면 [AI 영상 프롬프트 작성법](../ai-video-prompt-camera-lighting/)의 용어표를 함께 보면 편합니다.

## 크레딧 아끼는 Draft 모드

시댄스 2.5는 비용이 높아서 처음부터 최종 화질로 여러 번 돌리면 크레딧이 빨리 줄어듭니다. 드리미나에는 이를 줄이는 'Seedance 2.5 Draft' 방식이 있습니다.

| 구분 | 초안(Draft) | 최종본 |
|---|---|---|
| 해상도 | 480p | 1080p |
| 목적 | 구도·움직임·카메라 경로 확인 | 고른 초안을 고화질로 다시 생성 |
| 방법 | 여러 번 생성해 비교 | 고른 초안의 작업 ID를 제출 |
| 유지되는 것 | 프롬프트, 참고 자료, 시드, 비율, 길이 | 초안의 구도와 움직임 |
| 주의 | 작업 ID 유효 기간 14일 (2026년 10월 28일 이후 생성분) | 기간이 지나면 최종본을 만들 수 없음 |

최종본은 초안을 단순히 키운 것이 아니라 새로 생성하되 초안의 구성을 따라가는 방식이라고 안내되어 있습니다. 마음에 드는 초안이 나오면 유효 기간 안에 최종본을 만들어 두는 것이 좋습니다.

## 시댄스 2.5 가격과 무료 사용

드리미나 공식 요금 페이지 기준 요금제와 크레딧은 아래와 같습니다. 첫 달 할인 행사가 자주 바뀌므로 정가 기준으로 적었습니다.

| 요금제 | 월 요금 (정가) | 월 크레딧 | 시댄스 2.5 720p로 만들 수 있는 길이 (계산값) |
|---|---|---|---|
| Basic | $15 | 1,575 | 약 42초 |
| Standard | $36 | 3,885 | 약 1분 45초 |
| Advanced | $79 | 8,645 | 약 3분 53초 |
| Advanced (상위 구간) | $159 | 17,600 | 약 7분 55초 |
| Ultra | $520 | 59,000 | 약 26분 34초 |

계산은 720p 1초당 37크레딧 기준이며, 다시 생성하는 횟수까지 고려하면 실제로 쓸 수 있는 길이는 더 짧아집니다. 예를 들어 10초 영상 하나는 370크레딧, 30초 영상 하나는 1,110크레딧이 듭니다. Basic 요금제라면 10초 영상 4개 정도가 한 달 분량이라는 뜻입니다. 1080p 같은 다른 해상도의 초당 크레딧은 공식 요금 페이지에 따로 적혀 있지 않으니 생성 화면에 표시되는 예상 크레딧을 확인하세요.

**시댄스 2.5 무료**로 쓸 수 있는지도 많이 찾는 질문입니다. 드리미나는 "조건에 맞는 사용자에게 무료 체험 크레딧을 줄 수 있다"고만 안내하고 있고, 정확한 양은 계정마다 다르다고 밝히고 있습니다. 출시 직후 있었던 무료 생성 행사는 이미 끝났습니다. 캡컷에서는 구독 계정을 대상으로 제공됩니다. 그래서 무료로 길게 쓰기는 어렵고, 테스트는 저렴한 시댄스 2.0 Mini나 Fast로 하고 최종본만 2.5로 만드는 방식을 추천합니다. 다른 영상 도구와의 요금 비교는 [AI 영상 툴 가격 비교](../ai-video-tools-pricing-2026/)에 정리해 두었습니다.

## 캡컷에서 쓸 때와 주의할 점

캡컷 공식 뉴스룸에 따르면 시댄스 2.5는 유럽, 아시아, 중동, 남미의 **구독 계정**부터 순차 적용됐고, 만 16세 이상만 쓸 수 있습니다. 캡컷 안에서 생성한 뒤 특정 구간이나 인물만 골라 수정할 수 있어서, 편집까지 한 곳에서 끝내려는 분께 맞습니다.

| 확인할 것 | 내용 |
|---|---|
| 모델이 안 보일 때 | 지역별 순차 적용이라 계정마다 다를 수 있음, 앱 업데이트 후 모델 목록 확인 |
| AI 표시 | 보이지 않는 워터마크, C2PA 콘텐츠 자격 증명, 눈에 보이는 AI 라벨이 붙음 |
| 실존 인물 | 허락 없이 다른 사람의 얼굴·목소리를 쓰는 것은 정책상 금지 |
| 상업 이용 | 광고·제품 소개에 쓸 수 있으나 캡컷 이용 약관을 따라야 함 |
| 제3자 권리 | 유료 구독이라도 참고 자료로 넣은 남의 사진·음악 권리까지 해결되지는 않음 |

드리미나 요금 페이지도 "유료 구독만으로 제3자 권리가 해결되지는 않는다"고 적고 있습니다. 참고 자료로 넣는 사진과 음악은 직접 만들었거나 사용 허락을 받은 것을 쓰는 것이 안전합니다. 클링과 시댄스 중 무엇을 고를지 고민된다면 [클링 vs Seedance 2.0 비교](../kling-vs-seedance-2/)도 참고해 보세요.

## 마무리

시댄스 2.5는 한 번에 30초, 참고 자료 최대 50개, 구간별 부분 편집이 핵심 변화입니다. 대신 720p 기준 1초당 37크레딧으로 2.0보다 두 배 넘게 비싸므로, 구도는 Draft 모드나 2.0 Mini로 먼저 확인하고 마음에 드는 장면만 2.5로 마무리하는 흐름이 크레딧을 가장 아끼는 방법입니다. 요금과 지원 지역은 자주 바뀌니 결제 전에 공식 페이지를 다시 확인하세요.
