나노바나나 프롬프트 모음을 찾는 분들은 대부분 "피규어처럼 만드는 문장", "사진 두 장을 합치는 문장"처럼 바로 붙여 넣을 수 있는 예시를 원합니다. 이 글은 Gemini 앱의 나노바나나(Nano Banana)에서 자주 쓰이는 작업을 용도별로 나누어, 복사해서 단어만 바꿔 쓰는 프롬프트와 결과가 어긋날 때 고치는 방법을 2026년 10월 기준으로 정리했습니다. 행인 지우기, 하늘 바꾸기 같은 기본 사진 보정은 [나노바나나 사용법](../nano-banana-photo-editing-guide/) 글에서 따로 다뤘습니다.

## 한눈에 보는 나노바나나 프롬프트 모음

아래 표에서 원하는 작업을 고른 뒤, 해당 소제목의 예시를 복사해 쓰면 됩니다.

| 작업 | 올릴 사진 | 핵심 문장 | 아래 소제목 |
|---|---|---|---|
| 피규어 만들기 | 인물·반려동물 사진 1장 | "책상 위 피규어로 만들어 줘" | 피규어 프롬프트 |
| 그림체 변환 | 원본 사진 1장 | "구도와 인물은 그대로, 그림체만" | 그림체 변환 |
| 두 사진 합성 | 사진 2장 이상 | "1번 사진의 인물을 2번 사진 배경에" | 합성 프롬프트 |
| 프로필·증명사진 | 얼굴이 잘 보이는 사진 | "얼굴 생김새는 바꾸지 말고" | 프로필 사진 |
| 옷·헤어 바꾸기 | 인물 사진 + 옷 사진 | "얼굴과 자세는 유지, 옷만 교체" | 옷 바꾸기 |
| 제품 광고 컷 | 제품 사진 1장 | "스튜디오 조명의 제품 사진" | 제품 컷 |
| 스티커·4컷 만화 | 캐릭터 사진 또는 설명 | "흰 테두리 스티커", "4칸 만화" | 스티커·만화 |

모든 예시는 Gemini 앱(웹, 안드로이드, iOS)에서 입력창의 + 버튼으로 사진을 올리고, 도구 메뉴의 이미지 만들기를 선택한 상태에서 쓰는 것을 기준으로 했습니다.

## 프롬프트 기본 틀 — 어떤 작업이든 이 순서로

구글은 Gemini API 이미지 생성 문서에서 편집 요청을 "제공한 이미지를 바탕으로, [바꿀 요소]만 [새 모습]으로 바꾸라"는 형태로 쓰도록 안내합니다. 바꿀 부분만 이름 붙이고 나머지는 그대로 두라고 적는 방식입니다. 이를 한국어로 옮기면 아래 틀이 됩니다.

```
올린 사진에서 [유지할 것]은 그대로 두고,
[바꿀 부분]만 [원하는 모습]으로 바꿔 줘.
스타일은 [사진처럼/일러스트/3D 등], 비율은 [1:1/4:5/9:16 등]으로 해 줘.
```

| 칸 | 채우는 법 | 예시 |
|---|---|---|
| 유지할 것 | 얼굴, 자세, 구도, 제품 글자처럼 바뀌면 안 되는 것 | "얼굴 생김새와 머리 모양" |
| 바꿀 부분 | 한 번에 한 가지 | "배경", "옷", "그림체" |
| 원하는 모습 | 장소·색·빛을 구체적으로 | "해 질 녘 한강 공원, 주황빛 역광" |
| 스타일 | 사진인지 그림인지 먼저 밝힘 | "실사 사진", "수채화 일러스트" |
| 비율 | 올릴 곳에 맞춰 지정 | 인스타 피드 4:5, 쇼츠 9:16 |

구글 문서에 따르면 Nano Banana 2.1은 1:1, 3:2, 2:3, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9 비율을 지원합니다. 다만 Gemini 앱에서는 비율 지정이 문장으로만 전달되므로, 원하는 비율이 나오지 않으면 "정사각형으로 다시"처럼 한 번 더 요청하는 편이 빠릅니다. 프롬프트 용어(샷 크기, 조명, 렌즈)를 더 알고 싶다면 [AI 이미지 프롬프트 기본 공식](../ai-image-prompt-formula/)을 함께 보면 좋습니다.

## 피규어 프롬프트 — 사진을 책상 위 피규어로

나노바나나를 유명하게 만든 작업 중 하나가 인물이나 반려동물 사진을 수집용 피규어처럼 바꾸는 것입니다. 피규어 본체, 받침대, 상자, 주변 소품을 함께 설명해야 진짜 제품 사진처럼 보입니다.

```
올린 사진 속 인물을 1/7 크기의 수집용 피규어로 만들어 줘.
피규어는 투명한 원형 받침대 위에 서 있고, 컴퓨터 책상 위에 놓여 있어.
뒤쪽에는 같은 캐릭터가 그려진 피규어 상자가 있고, 실내 조명은 부드럽게 해 줘.
얼굴 생김새와 옷 색깔은 사진과 같게, 전체는 실사 제품 사진처럼 만들어 줘.
```

| 바꿔 쓸 부분 | 선택지 예시 |
|---|---|
| 피규어 종류 | 수집용 피규어, 넨도로이드풍 2등신, 레고풍 미니 피규어, 봉제 인형 |
| 놓인 장소 | 컴퓨터 책상, 진열장 선반, 매장 진열대 |
| 함께 둘 소품 | 피규어 상자, 모델링 작업 화면이 켜진 모니터, 조각 도구 |
| 반려동물용 | "사진 속 강아지를 털 질감이 살아 있는 피규어로" |

상자에 이름을 넣고 싶다면 따옴표로 정확한 글자를 적습니다. 구글 문서도 이미지 속 글자는 넣을 문구를 정확히 쓰고 글꼴 느낌을 함께 설명하라고 안내합니다. 한글은 영어보다 획이 틀리게 나오는 경우가 있어, 짧은 영문이나 숫자를 쓰거나 글자 없이 만든 뒤 편집 앱에서 넣는 방법도 많이 씁니다.

## 그림체 변환 — 사진을 애니메이션·수채화·픽셀 아트로

그림체를 바꿀 때는 **구도와 인물은 그대로, 표현 방식만 바꾼다**는 조건이 가장 중요합니다. 이 문장이 빠지면 자세나 배경까지 새로 그려지는 경우가 많습니다.

```
올린 사진의 구도, 인물 수, 자세, 배경 배치는 그대로 유지해 줘.
표현 방식만 [그림체]로 바꿔 줘. 색감은 [색감 설명]으로 맞춰 줘.
```

| 그림체 | [그림체]에 넣을 말 | [색감 설명] 예시 |
|---|---|---|
| 일본 애니메이션풍 | 셀 애니메이션 스타일, 깔끔한 선과 단순한 명암 | 맑은 하늘색과 흰 구름 |
| 수채화 | 종이 질감이 보이는 수채화 일러스트 | 번지는 파스텔 톤 |
| 3D 애니메이션 | 가족 애니메이션 영화 같은 3D 렌더링 | 따뜻하고 부드러운 조명 |
| 픽셀 아트 | 16비트 게임풍 픽셀 아트 | 제한된 색 수의 선명한 색 |
| 연필 스케치 | 흑연 연필 소묘, 손으로 그린 선 | 흑백, 종이의 미색 |
| 유화 | 두꺼운 붓 터치의 인상파 유화 | 빛이 번지는 노란빛 |

특정 작가나 스튜디오 이름을 넣는 요청은 결과가 일정하지 않고, 상업적으로 쓸 때는 저작권 시비가 생길 수 있습니다. 작가 이름 대신 선의 굵기, 명암 방식, 색감을 말로 설명하는 것을 추천합니다.

## 합성 프롬프트 — 사진 두 장 이상 합치기

나노바나나는 여러 장의 참조 이미지를 한 번에 받아 합칠 수 있습니다. 구글 공식 문서 기준으로 Nano Banana 2.1은 한 요청에 참조 이미지를 최대 14장까지 받으며, 인물은 최대 4명, 사물은 최대 10개까지 모습을 유지하도록 설계되었습니다. Gemini 앱에서 한 번에 올릴 수 있는 장수는 앱 화면에서 확인하는 것이 정확합니다.

사진을 여러 장 올릴 때는 순서대로 번호를 붙여 부르면 헷갈리지 않습니다.

```
첫 번째 사진의 인물을 두 번째 사진의 카페 창가 자리에 앉혀 줘.
인물의 얼굴, 머리 모양, 옷은 첫 번째 사진과 같게 유지해 줘.
조명 방향과 색온도는 두 번째 사진의 창문 빛에 맞추고, 그림자도 자연스럽게 넣어 줘.
```

| 합성 종류 | 프롬프트 핵심 | 어색해지는 원인과 해결 |
|---|---|---|
| 인물 + 배경 | "1번 인물을 2번 배경에" | 빛 방향이 달라 붕 떠 보임 → 조명·그림자 맞추라고 명시 |
| 여러 인물 단체 사진 | "1~3번 사람을 한 장의 단체 사진으로" | 키 차이가 이상함 → "실제 키 비율대로" 추가 |
| 인물 + 소품 | "1번 인물이 2번 가방을 들고 있게" | 소품 모양이 변함 → "가방의 모양과 로고는 그대로" |
| 반려동물 + 인물 | "1번 사람이 2번 강아지를 안고 있게" | 털 색이 바뀜 → 털 색과 무늬를 문장으로 설명 |

본인이 아닌 사람의 사진을 합성해 게시하면 초상권 문제가 생길 수 있고, 실존 인물을 오해하게 만드는 합성은 Gemini 정책상 거절될 수 있습니다. 같은 캐릭터를 여러 장면에 이어서 쓰고 싶다면 기준 이미지를 먼저 한 장 만들어 두고 매번 함께 올리는 방식이 안정적입니다.

## 프로필 사진과 옷 바꾸기 프롬프트

프로필 사진은 얼굴이 조금만 달라져도 본인처럼 보이지 않기 때문에, 유지 조건을 맨 앞에 두고 배경과 조명만 바꾸는 방식이 실패가 적습니다.

```
얼굴 생김새, 피부 톤, 머리 모양은 절대 바꾸지 말아 줘.
배경을 밝은 회색 단색 스튜디오 배경으로 바꾸고, 정면에서 부드러운 조명을 비춘 것처럼 해 줘.
어깨까지 나오는 상반신 구도, 4:5 비율로 만들어 줘.
```

옷을 바꿀 때는 인물 사진과 옷 사진을 함께 올리면 원하는 디자인이 더 정확히 반영됩니다.

```
첫 번째 사진의 인물이 두 번째 사진의 네이비색 재킷을 입은 모습으로 바꿔 줘.
얼굴, 자세, 배경은 그대로 두고, 재킷의 단추 위치와 주머니 모양은 두 번째 사진과 같게 해 줘.
```

| 목적 | 바꿔 쓸 배경·옷 | 주의할 점 |
|---|---|---|
| 링크드인·이력서 | 단색 배경, 셔츠나 재킷 | 실제 증명사진 제출용으로는 규정 확인 필요 |
| SNS 프로필 | 카페, 공원, 노을 배경 | 피부를 지나치게 매끈하게 만들지 말라고 요청 |
| 쇼핑몰 착장 미리보기 | 판매할 옷 사진 | 실제 옷과 색이 달라질 수 있어 상품 설명에 고지 |
| 헤어스타일 시험 | "단발 웨이브", "투블럭" | 얼굴형이 바뀌지 않게 유지 조건 반복 |

여권이나 공공기관 제출용 증명사진은 기관마다 보정 허용 범위가 정해져 있으므로, AI로 바꾼 사진을 그대로 제출하기 전에 해당 기관의 사진 규정을 확인해야 합니다.

## 제품 컷·스티커·4컷 만화 프롬프트

구글 문서는 제품 사진을 요청할 때 스튜디오 구성, 조명, 카메라 각도를 함께 쓰라고 안내합니다. 스마트스토어 상세페이지용 이미지라면 아래처럼 쓸 수 있습니다.

```
올린 제품 사진을 바탕으로 고해상도 스튜디오 제품 사진을 만들어 줘.
제품의 모양, 색, 라벨 글자는 그대로 유지해 줘.
밝은 대리석 테이블 위에 놓고, 왼쪽 위에서 부드러운 빛이 들어오게, 45도 위에서 내려다본 각도로 해 줘.
```

캐릭터 스티커나 짧은 만화도 자주 쓰이는 작업입니다.

```
올린 사진 속 고양이를 귀여운 스티커 일러스트로 만들어 줘.
굵은 외곽선, 단순한 명암, 흰색 테두리, 배경은 흰색으로 해 줘.
웃는 표정, 하품하는 표정, 놀란 표정 세 가지를 한 장에 나란히 그려 줘.
```

```
이 캐릭터가 나오는 4칸 만화를 그려 줘. 그림체는 깔끔한 웹툰풍으로 해 줘.
1칸 출근길에 비가 옴, 2칸 우산이 없음, 3칸 편의점으로 달려감, 4칸 우산이 다 팔림.
말풍선은 비워 둬.
```

| 작업 | 잘 나오게 하는 한 줄 | 활용처 |
|---|---|---|
| 제품 컷 | "라벨 글자는 그대로 유지" | 상세페이지, 광고 소재 |
| 스티커 | "흰 테두리, 흰 배경" | 메신저 이모티콘 시안, 굿즈 |
| 4컷 만화 | "칸마다 장면을 번호로 설명" | 인스타툰, 카드뉴스 |
| 인테리어 시안 | "가구 배치는 유지, 벽지와 조명만" | 집 꾸미기 비교 |

말풍선 글자는 비워 두고 편집 앱에서 넣으면 한글이 깨지는 문제를 피할 수 있습니다. 판매용 제품 이미지 전체 흐름은 [상세페이지 AI 제작](../ai-product-detail-page-images/) 글에 정리해 두었습니다.

## 결과가 이상할 때 프롬프트 고치는 법

같은 프롬프트라도 결과는 매번 조금씩 다르게 나옵니다. 아래 표처럼 증상별로 한 문장을 추가하거나 바꾸면 대부분 해결되는 경우가 많습니다.

| 증상 | 추가하거나 바꿀 문장 |
|---|---|
| 얼굴이 다른 사람처럼 바뀜 | "얼굴 생김새는 원본과 똑같이"를 첫 줄로 올림 |
| 요청 안 한 배경까지 바뀜 | "[바꿀 부분]만 바꾸고 나머지는 그대로" |
| 그림체가 어중간함 | 사진인지 일러스트인지 첫 문장에서 밝힘 |
| 합성한 인물이 떠 보임 | "조명 방향과 그림자를 배경에 맞춰" |
| 글자가 깨짐 | 글자를 짧게 줄이거나 빼고 나중에 편집 |
| 여러 번 고치다 화질이 떨어짐 | 새 대화에서 원본과 최종 요청을 한 번에 입력 |
| 요청이 거절됨 | 실존 인물·신분증·폭력적 내용이 있는지 확인 |

한국어로 써도 잘 알아듣지만, 원하는 그림체 이름이나 조명 용어가 한국어로 애매할 때는 "cinematic lighting", "flat illustration"처럼 영어 단어를 섞어 쓰는 방법도 있습니다. 결과물에는 끌 수 없는 SynthID 워터마크가 들어가며, 눈에 보이는 표시와 무료 사용 한도는 요금제와 국가에 따라 다르므로 Gemini 공식 도움말에서 확인하는 것을 추천합니다.

## 마무리

나노바나나 프롬프트는 길고 화려할 필요가 없습니다. **유지할 것을 먼저 적고, 바꿀 것 하나를 구체적으로 설명하고, 스타일과 비율을 덧붙이는 순서**만 지키면 피규어, 그림체 변환, 합성, 프로필 사진까지 같은 틀로 쓸 수 있습니다. 여러 장을 합칠 때는 사진에 번호를 붙여 부르고, 글자는 되도록 짧게 쓰거나 나중에 넣는 것이 실패를 줄이는 방법입니다.

위의 예시는 출발점일 뿐이니, 결과를 보면서 한 문장씩 고쳐 나가세요. 만든 이미지를 움직이는 영상으로 이어 가고 싶다면 [사진 영상 변환 AI](../image-to-video-guide/) 글도 함께 참고하시기 바랍니다.
