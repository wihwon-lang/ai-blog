일레븐랩스 한국어 음성은 목소리와 모델을 어떻게 고르느냐에 따라 같은 대본도 결과가 크게 달라집니다. 이 글은 일레븐랩스(ElevenLabs)로 한국어 내레이션을 처음 만들려는 분을 위해 2026년 10월 기준 공식 문서를 바탕으로 한국어 목소리 고르는 법, 모델 선택, 무료 플랜 한도와 상업 이용 조건을 정리했습니다. 다른 한국어 TTS 서비스와의 비교는 [TTS 사이트 추천](../korean-ai-tts-comparison/) 글에서 따로 다룹니다.

## 결론부터 — 일레븐랩스 한국어로 되는 것

일레븐랩스는 별도의 한국어 설정을 켜지 않아도 한국어를 지원하는 모델을 고르고 한국어 대본을 넣으면 한국어 음성이 만들어집니다. 다만 영어로 학습된 목소리를 그대로 쓰면 억양이 외국인처럼 들리는 경우가 많아, **한국어로 학습된 목소리를 보이스 라이브러리에서 골라 쓰는 것**이 핵심입니다.

| 질문 | 답 (2026년 10월 기준) |
|---|---|
| 한국어를 지원하나요? | 지원합니다. Eleven v3, Multilingual v2, Flash v2.5 모델 모두 한국어(ko)를 지원 언어로 안내합니다. |
| 한국어 설정을 따로 해야 하나요? | 웹에서는 한국어 대본을 입력하면 됩니다. 자연스러운 억양을 원하면 한국어 목소리를 고르는 것이 중요합니다. |
| 무료로 쓸 수 있나요? | Free 플랜은 매달 10,000크레딧을 줍니다. |
| 무료로 만든 음성을 수익 영상에 써도 되나요? | 안 됩니다. 무료 플랜 결과물은 비상업적 용도로만, 출처 표기를 하고 쓸 수 있습니다. |
| 내 목소리를 복제할 수 있나요? | 목소리 복제는 Starter 요금제부터 가능합니다. |

## 한국어에 쓸 모델 고르기

일레븐랩스에는 여러 음성 모델이 있고, 한국어 결과물의 느낌과 크레딧 소모가 모델마다 다릅니다. 공식 모델 문서에 나온 내용을 한국어 작업 기준으로 정리하면 아래와 같습니다.

| 모델 | 지원 언어 | 한 번에 넣을 수 있는 글자 | 특징 | 잘 맞는 작업 |
|---|---|---|---|---|
| Eleven v3 | 70개 이상 | 5,000자 (약 5분) | 감정 표현이 풍부하고 대괄호 오디오 태그로 연출 가능 | 숏폼 내레이션, 캐릭터 대사, 감정이 필요한 낭독 |
| Multilingual v2 | 29개 | 10,000자 (약 10분) | 안정적이고 감정 표현이 자연스러운 다국어 모델 | 긴 강의·해설 영상, 오디오북 |
| Flash v2.5 | 32개 | 40,000자 (약 40분) | 지연 시간이 짧고 크레딧이 적게 듦 | 대량 작업, 실시간 응답, 초안 확인 |

공식 도움말 기준 웹사이트에서 Eleven v3는 **1글자당 1크레딧**이 차감되고, Flash 계열은 **1글자당 0.5크레딧**으로 안내되어 있습니다. Multilingual v2의 차감 기준은 공식 요금 페이지에서 확인하는 것을 추천합니다.

처음이라면 Eleven v3로 짧은 문장을 만들어 보고, 긴 원고는 Multilingual v2, 많은 분량을 빠르게 시험할 때는 Flash v2.5를 쓰는 순서가 무난합니다. Eleven v3에서는 대본 안에 대괄호로 말투를 지시할 수 있습니다.

```
[차분하게] 오늘은 AI로 쇼츠 내레이션 만드는 법을 알아보겠습니다.
[밝게] 대본만 있으면 몇 분이면 충분합니다.
[속삭이듯] 마지막에 꼭 확인할 부분도 알려 드릴게요.
```

## 일레븐랩스 한국어 목소리 추천 — 필터로 고르는 법

보이스 라이브러리의 목소리는 수시로 추가되고 내려가기 때문에, 특정 목소리 이름을 외워 두기보다 **필터 조합으로 찾는 방법**을 익혀 두는 편이 오래 쓸 수 있습니다. 공식 문서에 따르면 보이스 라이브러리는 아래 필터를 제공합니다.

| 필터 | 고를 수 있는 값 | 한국어 작업에서 쓰는 법 |
|---|---|---|
| 언어 (Language) | 목소리가 학습된 언어 | 반드시 Korean을 먼저 선택 |
| 억양 (Accent) | 언어를 고른 뒤 열리는 억양 목록 | 표준어 내레이션이면 서울 억양 계열을 우선 확인 |
| 카테고리 | Conversational, Narration, Characters, Social Media, Educational, Advertisement, Entertainment | 용도에 맞는 값 하나만 고르면 후보가 크게 줄어듦 |
| 성별 | Male, Female, Neutral | 채널 분위기에 맞게 선택 |
| 나이 | Young, Middle Aged, Old | 시청자 연령대에 맞게 선택 |

용도별로 필터를 이렇게 조합하면 한국어 목소리 후보를 빠르게 좁힐 수 있습니다.

| 만들 콘텐츠 | 카테고리 | 나이 | 추천 모델 | 고를 때 들어 볼 부분 |
|---|---|---|---|---|
| 정보형 유튜브 쇼츠 | Social Media 또는 Narration | Young | Eleven v3 | 문장 끝 억양이 처지지 않는지 |
| 강의·교육 영상 | Educational | Middle Aged | Multilingual v2 | 긴 문장에서도 속도가 일정한지 |
| 제품 광고 | Advertisement | Young 또는 Middle Aged | Eleven v3 | 제품명·숫자 발음이 또렷한지 |
| 오디오북·낭독 | Narration | Middle Aged 또는 Old | Multilingual v2 | 쉼표에서 자연스럽게 쉬는지 |
| 애니메이션·캐릭터 대사 | Characters | 상관없음 | Eleven v3 | 감정 태그에 반응이 큰지 |
| 상담·안내 음성 | Conversational | Middle Aged | Flash v2.5 | 짧은 문장이 어색하지 않은지 |

후보를 고를 때는 미리듣기 샘플만 듣지 말고, **실제로 쓸 대본 두세 문장**을 넣어 비교하는 것을 추천합니다. 샘플이 좋아도 숫자나 영어 단어가 섞인 내 대본에서는 다르게 들리는 경우가 많습니다. 마음에 드는 목소리는 My Voices에 저장해 두면 다음부터 목소리 선택 메뉴에서 바로 고를 수 있고, 라이브러리에서 저장한 목소리는 커스텀 보이스 슬롯을 차지하지 않습니다.

## 일레븐랩스 무료 플랜 한도와 분량 계산

Free 플랜은 매달 10,000크레딧을 주고, 남은 크레딧은 다음 달로 넘어가지 않습니다. 유료 요금제는 남은 크레딧이 다음 달로 이월되는 것과 차이가 있습니다. 1분짜리 한국어 내레이션 대본은 보통 공백 포함 300~400자 정도이므로, 350자를 기준으로 무료 크레딧으로 만들 수 있는 분량을 계산하면 아래와 같습니다.

| 모델 (웹 기준) | 1글자당 크레딧 | 10,000크레딧으로 만들 수 있는 글자 수 | 1분 대본(350자) 기준 |
|---|---|---|---|
| Eleven v3 | 1 | 약 10,000자 | 약 28개 |
| Flash v2.5 | 0.5 | 약 20,000자 | 약 57개 |

이 숫자는 한 번에 마음에 드는 결과가 나왔을 때의 계산입니다. 다시 만들기를 할 때마다 크레딧이 다시 차감되므로 실제 분량은 이보다 적습니다. 또 보이스 라이브러리의 일부 목소리는 **크레딧 배수(multiplier)**가 붙어 있어, 2배 목소리를 쓰면 같은 대본에 크레딧이 두 배로 듭니다. 목소리를 고를 때 배수 표시를 확인하세요.

무료 플랜에서 함께 알아 둘 제한은 아래와 같습니다.

| 항목 | Free 플랜 (2026년 10월 기준) |
|---|---|
| 월 크레딧 | 10,000, 다음 달로 이월 안 됨 |
| Studio 프로젝트 | 3개 |
| 커스텀 보이스 슬롯 | 3개 (Voice Design으로 만든 목소리 저장용) |
| 목소리 복제 | 불가, Starter부터 가능 |
| 보이스 라이브러리 | 웹에서 사용 가능, 일부 목소리는 유료 사용자 전용 |
| API로 라이브러리 목소리 사용 | 무료 사용자는 불가 |
| 상업적 이용 | 불가 |

## 무료로 만든 한국어 음성, 어디까지 쓸 수 있나

공식 도움말에 따르면 무료 플랜으로 만든 음성은 비상업적 용도로만 쓸 수 있고, 공개할 때는 제목에 "elevenlabs.io" 또는 "11.ai"를 넣어 출처를 밝혀야 합니다. 유료 요금제에는 상업 라이선스가 포함되지만, **유료 구독 기간 밖(가입 전이나 해지 후)에 만든 음성은 상업적으로 쓸 수 없다**고 안내합니다. 무료로 만들어 둔 음성을 나중에 결제한다고 해서 상업용으로 바뀌지 않는다는 뜻입니다.

| 상황 | 상업적 이용 | 해야 할 일 |
|---|---|---|
| 무료 플랜으로 만든 개인 연습용 음성 | 불가 | 공개한다면 제목에 elevenlabs.io 또는 11.ai 표기 |
| 무료로 만든 뒤 Starter 결제 | 불가 | 결제 후 같은 대본으로 다시 생성해서 사용 |
| 유료 구독 중 만든 음성 | 가능 | 해지 후에도 그 기간에 만든 음성은 계속 사용 가능 |
| 베타 기능으로 만든 음성 | 별도 조건 | 서비스별 약관 확인 |

수익 창출 채널, 광고, 외주 납품에 쓸 음성이라면 상업 라이선스가 포함된 가장 낮은 요금제인 Starter(월 6달러, 30,000크레딧)부터 검토하면 됩니다. 첫 달 할인 행사가 자주 열리므로 결제 전에 공식 요금 페이지에서 현재 가격을 확인하세요.

## 한국어 발음을 자연스럽게 다듬는 요령

어떤 목소리를 고르든 대본을 TTS에 맞게 고쳐 쓰면 다시 만들기 횟수가 줄어 크레딧도 아낄 수 있습니다.

| 문제 | 고치는 방법 |
|---|---|
| 숫자를 어색하게 읽음 | "3개"는 "세 개", "2026년"은 "이천이십육 년"처럼 한글로 풀어 쓰기 |
| 영어 약어를 단어처럼 읽음 | "AI"는 "에이아이"처럼 소리 나는 대로 쓰기 |
| 쉬지 않고 빠르게 읽음 | 한 문장을 40자 안팎으로 끊고 쉼표 넣기 |
| 억양이 단조로움 | Eleven v3에서 대괄호 태그로 말투 지시, 어미를 섞어 쓰기 |
| 문장마다 목소리 톤이 달라짐 | 한 번에 너무 긴 대본 대신 문단 단위로 나눠 생성 |

한국어 음성을 영상의 다른 언어 버전으로 옮기고 싶다면 [AI 더빙 사이트 비교](../ai-video-multilingual-dubbing/) 글에서 일레븐랩스 더빙 기능과 다른 서비스를 함께 확인할 수 있습니다.

## 마무리

일레븐랩스 한국어 음성은 한국어를 지원하는 모델과 한국어로 학습된 목소리를 함께 골라야 자연스럽게 들립니다. 보이스 라이브러리에서 언어를 Korean으로 두고 카테고리, 나이, 성별 필터로 후보를 좁힌 뒤, 실제 대본 몇 문장으로 비교해 고르는 방법을 추천합니다.

무료 플랜의 월 10,000크레딧은 Eleven v3 기준 1분 대본 30개 안팎을 시험해 볼 수 있는 양이지만, 결과물은 상업적으로 쓸 수 없습니다. 수익 영상이나 납품용 음성은 유료 구독 기간에 새로 만들어야 한다는 점을 꼭 기억하세요. 요금과 모델 정책은 자주 바뀌므로 결제 전에는 공식 페이지에서 최신 조건을 다시 확인하시기 바랍니다.
