AI 그림 판독기를 찾는 분들은 대부분 "이 그림이 AI로 만든 건지 한 번에 알려 주는 사이트"를 원합니다. 결론부터 말하면 모든 AI 그림을 확실하게 가려내는 판독기는 아직 없고, **워터마크 확인 → 출처 정보 확인 → 판독 사이트 점수 → 눈으로 보는 확인**을 겹쳐 써야 판단이 정확해집니다. 이 글은 2026년 10월 기준으로 무료로 쓸 수 있는 확인 방법과 결과를 읽는 요령을 정리했습니다.

## AI 그림 판독기, 결론부터 — 방법별로 알 수 있는 것

판독 방법은 크게 네 가지입니다. 각각 "확실하게 알려 주는 범위"가 다르므로 아래 표로 먼저 차이를 보고 고르는 것이 좋습니다.

| 방법 | 대표 도구 | 알 수 있는 것 | 한계 |
|---|---|---|---|
| 보이지 않는 워터마크 확인 | Gemini 앱(SynthID), 구글 렌즈 | 구글 AI로 만들었거나 고친 이미지인지 | 다른 회사 AI 이미지는 판별하지 못함 |
| 출처 정보(콘텐츠 자격 증명) 확인 | Content Credentials Verify, Gemini | 어떤 프로그램으로 만들고 편집했는지 기록 | 메타데이터가 지워진 파일은 정보가 없음 |
| AI 판독 사이트 | Hive Detect 등 | AI일 가능성을 점수로 추정 | 추정치라서 오판이 생길 수 있음 |
| 눈으로 확인 + 역방향 이미지 검색 | 구글 이미지 검색, 렌즈 | 어색한 부분, 최초 게시처 | 최신 모델은 육안 구별이 어려움 |

가장 확실한 근거는 **워터마크와 출처 정보**입니다. 이 둘은 만든 쪽이 파일에 남긴 기록을 읽는 방식이라 "있다"는 결과가 나오면 신뢰도가 높습니다. 반대로 판독 사이트의 점수는 그림의 특징을 보고 추정하는 방식이라 참고용으로 쓰는 편이 안전합니다.

## Gemini로 확인하기 — 구글 AI 이미지는 SynthID로 판별

구글은 나노바나나, Imagen, Veo 같은 자사 AI로 만든 이미지·영상·오디오에 SynthID라는 보이지 않는 워터마크를 넣습니다. Gemini 앱에 파일을 올리고 질문하면 이 워터마크가 있는지 확인해 줍니다.

| 순서 | 할 일 |
|---|---|
| 1 | gemini.google.com 또는 Gemini 앱에 로그인합니다 |
| 2 | 파일 추가 버튼으로 확인할 이미지를 올립니다(내 기기, 구글 포토, 구글 드라이브 가능) |
| 3 | "이거 AI로 만든 거야?" 또는 "구글 AI로 만들거나 편집한 이미지야?"라고 묻습니다 |
| 4 | SynthID 감지 여부와 설명을 확인합니다 |

```
이 이미지가 AI로 만들어졌는지 SynthID로 확인해 줘.
```

구글 고객센터 안내(2026년 10월 확인)에 따르면 한 번에 파일 1개, 100MB 이하만 올릴 수 있고, 24시간 기준으로 이미지 확인은 약 10회까지 가능합니다. 화면 캡처를 올릴 때는 확인할 그림 부분만 꼭 맞게 잘라야 하고, 여러 장을 이어 붙인 콜라주는 정확도가 떨어진다고 안내되어 있습니다.

| 결과 | 뜻 |
|---|---|
| SynthID 감지됨 | 이미지 전체 또는 일부가 구글 AI로 만들어졌거나 편집됨 |
| SynthID 감지 안 됨 | 구글 AI 결과물은 아님. 다른 회사 AI로 만들었을 가능성은 남음 |
| 불분명 | 워터마크를 넣기엔 너무 작은 편집이거나 정보가 부족한 경우 |

중요한 점은 **"감지 안 됨"이 "사람이 그렸다"는 뜻이 아니라는 것**입니다. 미드저니나 다른 서비스로 만든 그림은 SynthID가 없으므로 이 방법으로는 걸러지지 않습니다. 구글은 2026년 5월 구글 검색의 렌즈, AI 모드, 서클 투 서치에서도 같은 질문으로 SynthID를 확인할 수 있게 넓혔다고 발표했습니다. 나노바나나 결과물에 워터마크가 들어가는 방식은 [나노바나나 사용법](../nano-banana-photo-editing-guide/) 글에서도 다뤘습니다.

## 콘텐츠 자격 증명(C2PA)으로 출처 확인하기

C2PA는 어도비, 구글, 마이크로소프트, OpenAI 등이 참여하는 출처 기록 표준입니다. 이 표준을 따르는 프로그램은 파일 안에 "어떤 도구로 만들었는지, 어떻게 편집했는지"를 서명과 함께 기록하는데, 이 기록을 콘텐츠 자격 증명(Content Credentials)이라고 부릅니다. AI 이미지뿐 아니라 일반 카메라 사진에도 쓰입니다.

| 확인 도구 | 쓰는 법 | 특징 |
|---|---|---|
| Content Credentials Verify | contentcredentials.org/verify에 파일을 끌어다 놓기 | 웹에서 바로 확인, 편집 이력 표시 |
| Gemini | 파일을 올리고 AI 생성 여부를 질문 | 웹과 안드로이드 앱에서 지원 |
| 크롬 확장 프로그램 | 웹 페이지 이미지에서 우클릭 후 확인 | 사이트를 둘러보며 바로 확인 |

결과 화면에서 "생성형 AI 사용" 같은 항목이 보이면 AI 도구가 관여했다는 기록이 남아 있다는 뜻입니다. 다만 아래 경우에는 기록이 사라지거나 읽히지 않습니다.

| 기록이 없어지는 경우 | 이유 |
|---|---|
| SNS·메신저로 주고받은 사진 | 업로드 과정에서 메타데이터가 지워지는 경우가 많음 |
| 화면 캡처한 이미지 | 원본 파일 정보가 따라오지 않음 |
| 표준을 지원하지 않는 프로그램으로 다시 저장 | 기록이 빠지거나 서명이 깨짐 |
| 처음부터 기록을 넣지 않는 서비스 | 확인할 정보 자체가 없음 |

그래서 콘텐츠 자격 증명이 **없다고 해서 사람이 만든 그림이라고 단정할 수는 없습니다.** 구글 안내도 콘텐츠 자격 증명은 출처와 이력을 보여 줄 뿐 AI 생성 여부를 확정하는 증거는 아니라고 설명합니다.

## AI 그림 판독 사이트 — 점수를 읽는 법

워터마크도 출처 기록도 없는 그림이라면 판독 사이트를 씁니다. 이런 사이트는 수많은 AI 이미지와 실제 이미지를 학습한 모델로, 올린 그림이 AI일 확률을 추정합니다. 예를 들어 Hive는 무료 판독 도구(Hive Detect)와 크롬 확장 프로그램을 제공하며, AI 생성 가능성 점수와 함께 추정되는 생성 모델을 보여 준다고 안내합니다.

| 점수 범위(예시) | 읽는 법 | 다음 할 일 |
|---|---|---|
| 매우 높음 | AI일 가능성이 큼 | 원본 출처와 다른 근거로 한 번 더 확인 |
| 중간 | 판단하기 어려운 구간 | 다른 판독 사이트 결과와 비교 |
| 매우 낮음 | AI 흔적이 적게 보임 | 그래도 확정하지 말고 출처 확인 |

판독 사이트를 쓸 때 알아 둘 점은 다음과 같습니다.

| 주의할 점 | 설명 |
|---|---|
| 오판 가능성 | 사람이 그린 디지털 일러스트가 AI로 나오거나, 그 반대가 나올 수 있음 |
| 압축·크기 변경 | 여러 번 저장되어 화질이 떨어진 이미지는 정확도가 낮아지는 경우가 많음 |
| 부분 편집 | 사진 일부만 AI로 고친 경우 전체 점수가 낮게 나올 수 있음 |
| 업로드 내용 | 개인 사진이나 미공개 작업물은 서비스 약관을 확인한 뒤 올리기 |

판독 점수 하나만으로 누군가를 "AI 그림을 그렸다"고 지적하는 것은 피하는 것이 좋습니다. 특히 공모전이나 커미션 의뢰처럼 분쟁이 생길 수 있는 상황에서는 작가에게 작업 과정 파일(레이어가 있는 원본, 스케치 단계)을 요청하는 쪽이 훨씬 확실한 근거가 됩니다.

## 눈으로 AI 그림 구별하는 체크리스트

도구 없이도 확인할 수 있는 부분이 있습니다. 최신 모델은 예전보다 실수가 크게 줄었지만, 아래 항목을 차례로 보면 단서를 찾는 경우가 많습니다.

| 볼 곳 | AI 그림에서 자주 보이는 흔적 |
|---|---|
| 손·손가락 | 손가락 개수, 관절 방향, 물건을 쥔 모양이 어색함 |
| 글자 | 간판·책 표지·옷의 글자가 뭉개지거나 없는 문자처럼 보임 |
| 배경 | 뒤쪽 사람 얼굴이 녹아내린 듯하거나 건물 선이 이어지지 않음 |
| 대칭 소품 | 귀걸이 좌우가 다르거나 안경테가 중간에 끊김 |
| 질감 | 피부가 지나치게 매끈하고, 머리카락 끝이 배경과 섞임 |
| 빛과 그림자 | 그림자 방향이 광원과 맞지 않음 |
| 그림 전체 | 세부 묘사는 화려한데 선이 그어진 순서나 의도가 느껴지지 않음 |

이 흔적은 AI 결과물을 고칠 때 자주 손보는 부분과도 겹칩니다. AI 영상에서 손가락·글자가 깨지는 이유는 [AI 영상 오류 해결](../ai-video-common-failures-fix/) 글에서 정리했습니다.

여기에 **역방향 이미지 검색**을 더하면 좋습니다. 구글 렌즈나 구글 이미지 검색에 그림을 올려 처음 올라온 곳을 찾고, 같은 작가가 비슷한 그림을 꾸준히 올려 왔는지, 작업 과정 영상이 있는지를 보면 판단 근거가 늘어납니다. 구글의 "이 이미지 정보" 기능은 이미지가 처음 색인된 시점과 메타데이터에 남은 AI 생성 표시를 함께 보여 줍니다.

## 상황별로 추천하는 확인 순서

목적에 따라 확인 순서를 다르게 잡으면 시간을 아낄 수 있습니다.

| 상황 | 추천 순서 |
|---|---|
| SNS에서 본 뉴스 사진이 의심될 때 | 역방향 이미지 검색 → Gemini·렌즈로 SynthID 확인 → 언론사 공식 보도 확인 |
| 커미션·외주 작업물을 받았을 때 | 작업 과정 파일 요청 → 콘텐츠 자격 증명 확인 → 판독 사이트 참고 |
| 공모전 심사 | 응모 규정에 AI 사용 여부 기준 명시 → 원본·레이어 파일 제출 요구 → 판독 도구는 보조로 사용 |
| 내 그림이 AI로 오해받을 때 | 스케치·레이어 파일과 작업 영상 공개 → 판독 결과는 참고 자료로만 제시 |
| 쇼핑몰 상품 사진 확인 | 역방향 이미지 검색으로 도용 여부 확인 → 실제 후기 사진과 비교 |

## AI로 만든 그림을 올릴 때 알아 둘 표시 규칙

반대로 내가 AI 그림을 올리는 입장이라면 표시 규칙도 알아 두는 것이 좋습니다. 우리나라 인공지능기본법은 2026년 1월 22일부터 시행되었고, 생성형 AI로 만든 결과물에 AI 생성 사실을 알리거나 표시하는 의무를 두고 있습니다. 표시 의무를 지는 대상과 방식(눈에 보이는 표시, 보이지 않는 워터마크 등)은 시행령과 정부 안내에서 정하므로, 업무로 활용한다면 국가법령정보센터의 법령 원문과 과학기술정보통신부 안내를 직접 확인하는 것을 추천합니다.

| 올리는 곳 | 확인할 것 |
|---|---|
| 유튜브 | 사실적인 AI 콘텐츠는 업로드할 때 AI 사용 여부를 공개 |
| 스톡 사이트 | 사이트마다 AI 이미지 제출 규칙과 표시 방법이 다름 |
| 공모전·외주 | 규정과 계약서에 AI 사용 허용 여부가 적혀 있는지 |
| 상업적 이용 | 서비스 약관과 저작권 문제를 함께 검토 |

유튜브의 AI 표시 정책은 [유튜브 AI 영상 수익 창출](../youtube-shorts-ai-content-policy/) 글에서, 상업적 이용과 저작권은 [AI 영상 저작권 문제](../ai-video-copyright-commercial/) 글에서 자세히 다뤘습니다.

## 마무리

AI 그림 판독기는 하나의 사이트로 끝나는 도구가 아니라, 여러 근거를 모으는 과정에 가깝습니다. 구글 AI 결과물은 Gemini의 SynthID 확인으로, 출처 기록이 있는 파일은 콘텐츠 자격 증명으로 비교적 확실하게 알 수 있습니다. 둘 다 없는 그림은 판독 사이트 점수와 눈으로 보는 체크리스트, 역방향 이미지 검색을 함께 보고 판단하는 것이 좋습니다. 어떤 도구도 완벽한 판별을 보장하지 않으므로, 결과를 근거로 남을 지적할 때는 특히 신중하게 접근하는 것을 추천합니다.
