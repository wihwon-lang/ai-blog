분양 홍보 영상은 보통 모델하우스 촬영, 드론 촬영, 편집까지 외주로 맡기면 비용과 시간이 꽤 듭니다. 그런데 아직 완공 전인 현장은 찍을 실물도 없습니다. 그래서 AI 이미지와 AI 영상 도구로 홍보 영상을 만들어 봤고, 그 과정과 실제 비용을 정리했습니다.

> ✍️ 직접 작성: 어떤 현장(지역, 규모 정도만)의 영상을 만들었는지, AI로 만들게 된 계기. 클라이언트 정보는 밝히지 않아도 됩니다.

## 기존 촬영 방식 vs AI 제작

| 항목 | 기존 촬영·외주 | AI 제작 |
|---|---|---|
| 제작 기간 | ✍️ | ✍️ |
| 비용 | ✍️ | ✍️ (도구 구독료 기준) |
| 완공 전 현장 | 조감도·CG 필요 | 조감도·이미지로 영상화 가능 |
| 수정 | 재촬영 필요 | 해당 장면만 다시 생성 |
| 인물 출연 | 모델 섭외 | AI 인물 (초상권 걱정 적음) |
| 한계 | 비용·일정 | 실제와 다른 부분이 생길 수 있음 |

> ✍️ 직접 작성: 위 표의 ✍️ 칸을 실제 숫자로 채워 주세요. 대략적인 범위여도 괜찮습니다.

## 사용한 도구

| 단계 | 도구 | 용도 |
|---|---|---|
| 기획·대본 | ✍️ (ChatGPT, Claude 등) | 장면 구성, 내레이션 |
| 이미지 | ✍️ (나노바나나 등) | 단지 외관, 내부, 인물 장면 |
| 영상 | ✍️ (클링, Seedance 등) | 이미지 → 영상 |
| 편집 | ✍️ (CapCut 등) | 컷 편집, 자막, 음악, 보이스오버 |

## 제작 과정

### 1. 기획: 무엇을 보여줄지 정하기

분양 영상에서 보여줘야 할 요소는 대체로 정해져 있습니다.

| 장면 | 전달할 내용 | 영상 예시 |
|---|---|---|
| 오프닝 | 단지의 첫인상 | 드론으로 단지 전체를 비추는 장면 |
| 입지 | 교통·학군·생활 편의 | 지도 그래픽, 주변 풍경 |
| 단지 | 조경, 커뮤니티 시설 | 산책하는 가족, 커뮤니티 시설 |
| 세대 내부 | 평면, 인테리어 | 거실·주방을 천천히 훑는 장면 |
| 마무리 | 분양 일정, 문의처 | 로고와 연락처 화면 |

> ✍️ 직접 작성: 실제 영상은 몇 장면, 몇 초였는지. 위 구성과 달랐다면 어떻게 구성했는지.

### 2. 이미지 만들기

> ✍️ 직접 작성: 조감도나 평면도를 참고 이미지로 썼는지, 이미지 단계에서 가장 어려웠던 점(건물 형태 유지, 실제와 다르게 나오는 부분 등).

### 3. 영상 만들기

> ✍️ 직접 작성: 장면당 평균 몇 번 다시 뽑았는지, 잘 나온 장면과 안 나온 장면의 차이.

### 4. 편집

> ✍️ 직접 작성: 자막·내레이션·음악은 어떻게 넣었는지, 편집에 걸린 시간.

## 실제로 해 보니 주의할 점

| 주의할 점 | 이유 |
|---|---|
| 실제와 다른 부분 표시 | AI 이미지는 실제 설계와 다를 수 있어, "이미지 연출" 문구를 넣는 게 안전 |
| 숫자 정보는 공식 자료로 | 분양가, 세대수, 일정은 모집공고 기준으로 직접 확인 |
| 과장 광고 주의 | 부동산 광고는 표시·광고 관련 법 적용을 받으므로 확정되지 않은 호재 표현 주의 |
| 건물 형태 확인 | AI가 층수·동 배치를 바꾸는 경우가 있어 장면마다 확인 필요 |
