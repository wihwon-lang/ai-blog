런웨이 가격을 찾는 분들이 가장 궁금해하는 것은 "한 달에 얼마인지", "그 크레딧으로 영상을 몇 초나 만들 수 있는지", "연 결제가 정말 이득인지"입니다. 이 글은 AI 영상 서비스 런웨이(Runway)의 요금제를 2026년 11월 기준 공식 요금 페이지와 고객센터 안내를 바탕으로 정리합니다. 런웨이는 달러로 결제하고 할인 행사가 자주 바뀌므로, 아래 금액은 조회 시점(2026년 11월 28일) 기준이라는 점을 먼저 알아 두세요.

## 런웨이 가격 한눈에 보기

결론부터 말하면 런웨이 개인 요금제는 **Free, Standard, Pro, Max 4가지**입니다. 예전에 있던 무제한(Unlimited) 요금제는 새로 가입할 수 없고, 기존 이용자도 2026년 11월 30일에 Max로 옮겨집니다.

| 요금제 | 월 결제 | 연 결제 (월 환산) | 연 결제 첫해 행사가 (월 환산) | 월 크레딧 |
|---|---|---|---|---|
| Free | $0 | - | - | 125 (1회만 지급) |
| Standard | $15 | $12 | $8.40 | 625 |
| Pro | $35 | $28 | $19.60 | 2,250 |
| Max | $95 | $76 | $53.20 | 9,500 |

연 결제는 월 결제보다 20% 저렴합니다. 2026년 11월 요금 화면에는 여기에 **연 결제 첫해 30% 추가 할인** 쿠폰이 붙어 있어 Standard가 월 $8.40까지 내려갑니다. 이 할인은 11월 행사로 표시되어 있으므로, 결제 직전 화면에서 적용 여부를 다시 확인하세요.

1년 동안 실제로 내는 돈으로 바꾸면 차이가 더 분명해집니다.

| 요금제 | 월 결제 12개월 | 연 결제 1년 | 연 결제 첫해 행사가 |
|---|---|---|---|
| Standard | $180 | $144 | $100.80 |
| Pro | $420 | $336 | $235.20 |
| Max | $1,140 | $912 | $638.40 |

원화 금액은 환율과 카드사 해외 결제 수수료에 따라 달라집니다. 여러 사람이 함께 쓰는 Team 요금제(2~9명, 1인당 월 6,900크레딧 공유)와 Enterprise 요금제도 있으며, 가격은 요금 페이지의 팀 탭과 영업팀 문의로 확인할 수 있습니다.

## 런웨이 무료로 쓸 수 있을까

무료(Free) 요금제는 있지만 **매달 충전되는 크레딧은 없습니다.** 가입할 때 한 번 주는 125크레딧으로 써 보는 구조입니다.

| 항목 | 무료 요금제 내용 |
|---|---|
| 크레딧 | 125 (1회 지급, 다시 채워지지 않음) |
| 크레딧 만료 | 만료되지 않음 |
| 쓸 수 있는 모델 | 일부 모델만 (업그레이드 표시가 뜨면 무료 대상 아님) |
| 워터마크 | 모든 영상에 런웨이 워터마크 |
| 크레딧 추가 구매 | 불가 |
| 저장 공간 | 5GB |

대표 모델인 Gen-4.5는 1초에 12크레딧이 들기 때문에, 무료 모델 목록에 있다 해도 125크레딧은 5초 영상 두 개 정도 분량입니다. 무료 모델 목록은 자주 바뀌므로 로그인한 뒤 화면에서 확인하는 것이 정확합니다. 매일 무료 크레딧을 주는 서비스가 궁금하다면 [클링 AI 무료 크레딧 정리](../kling-ai-free-credits/) 글을 참고하세요.

## 요금제별 크레딧으로 영상 몇 초 만들 수 있나

런웨이 요금 페이지는 요금제마다 월 크레딧으로 만들 수 있는 분량을 함께 보여 줍니다. 공식 수치를 정리하면 아래와 같습니다.

| 요금제 (월 크레딧) | Gen-4.5 | Gen-4 Turbo | Gen-4 Image (1080p) |
|---|---|---|---|
| Standard (625) | 약 52초 (5초 영상 약 10개) | 약 104초 | 약 78장 |
| Pro (2,250) | 약 187초 (약 37개) | 약 375초 | 약 281장 |
| Max (9,500) | 약 791초 (약 158개) | 약 1,900초 | 약 1,187장 |

같은 장면을 여러 번 다시 뽑는 경우가 많으므로, 실제로 건지는 완성 영상은 이보다 적다고 보는 편이 안전합니다. 런웨이 고객센터도 Standard는 많이 생성하는 작업보다 **가볍게 탐색하는 용도**에 맞는 요금제라고 안내합니다.

### 모델별 크레딧 소모량

런웨이 안에서는 자체 모델뿐 아니라 클링, Seedance, 나노바나나 같은 외부 모델도 쓸 수 있습니다. 2026년 11월 요금 페이지에 나온 크레딧은 다음과 같습니다.

| 구분 | 모델 | 크레딧 |
|---|---|---|
| 영상 | Gen-4.5 | 5초 60 (1초 12) |
| 영상 | Aleph 2.0 (영상 편집) | 5초 140 |
| 영상 | Kling 4.0 1080p | 5초 118 (11월 30일까지 25% 할인 89) |
| 영상 | Seedance 2.0 Pro 1080p | 4초 160 |
| 이미지 | Gen-4 Image 1080p / Turbo | 1장 8 / 1장 2 |
| 이미지 | Nano Banana Pro 2K | 1장 20 |
| 오디오 | Lyria 3 Pro / Lyria 3 Clip | 1곡 8 / 1곡 4 |
| 오디오 | 텍스트 음성 변환(TTS) | 50자당 1 |

외부 모델과 소리가 들어간 영상은 크레딧이 더 많이 듭니다. 구도와 움직임은 Gen-4 Turbo나 이미지 모델로 먼저 확인하고, 마음에 드는 장면만 Gen-4.5로 뽑으면 크레딧을 아낄 수 있습니다.

## 요금제별 기능 차이

크레딧 양 말고도 동시 생성 수, 프로젝트 수, 4K 업스케일, 크레딧 이월에서 차이가 납니다.

| 기능 | Free | Standard | Pro | Max |
|---|---|---|---|---|
| 모든 영상·이미지 모델 | 일부만 | 가능 | 가능 | 가능 (신모델 먼저 사용) |
| 워터마크 없는 다운로드 | 불가 | 가능 | 가능 | 가능 |
| 동시 생성 | - | 5개 | 15개 | 20개 |
| 프로젝트 | - | 최대 3개 | 최대 5개 | 최대 10개 |
| 4K 업스케일 | 불가 | 요금 페이지에 표시 (고객센터는 Pro 이상으로 안내) | 무제한 | 무제한 |
| 커스텀 음성 복제 | 불가 | 불가 | 1개 | 최대 3개 |
| 남은 크레딧 이월 | - | 불가 | 불가 | 1개월치 이월 |
| HDR·ProRes 내보내기 | 불가 | 불가 | 불가 | 가능 |
| 저장 공간 (요금 페이지 표시) | 5GB | 20GB | 100GB | 500GB |

Pro 저장 공간은 요금 페이지와 고객센터 문서(500GB)의 숫자가 달라, 용량이 중요하다면 결제 화면에서 확인하는 것이 좋습니다. 모든 유료 요금제에서 크레딧을 추가로 살 수 있고, 한 번에 최소 1,000크레딧부터 구매할 수 있습니다.

## 어떤 요금제를 골라야 할까

| 이런 분에게 | 추천 요금제 | 이유 |
|---|---|---|
| 런웨이를 처음 써 보는 분 | Free → Standard 월 결제 | 무료 크레딧으로 화면을 익히고 한 달만 결제 |
| 쇼츠용 짧은 영상을 가끔 만드는 분 | Standard | Gen-4.5 5초 영상 약 10개 분량 |
| 매주 여러 편을 만드는 분 | Pro | 크레딧 3.6배, 동시 생성 15개, 4K 업스케일 무제한 |
| 외주·광고 영상을 매일 만드는 분 | Max | 9,500크레딧과 1개월 이월, 빠른 생성 |
| 여러 명이 한 작업 공간을 쓰는 팀 | Team | 크레딧 공유와 댓글 기능 |

처음이라면 **Standard 월 결제로 한 달 써 본 뒤** 크레딧이 모자라면 올리는 순서를 추천합니다. 상위 요금제로 바꾸면 즉시 적용되고 남은 기간만큼만 차액을 냅니다. 런웨이 사용 순서 자체가 궁금하다면 [런웨이 AI 사용법](../runway-gen45-guide/) 글을, 다른 영상 도구와 가격을 함께 보려면 [AI 영상 툴 가격 비교](../ai-video-tools-pricing-2026/) 글을 참고하세요.

## 환불·해지·크레딧 만료 조건

결제 전에 알아 둘 조건을 고객센터 안내 기준으로 정리했습니다.

| 항목 | 공식 안내 내용 |
|---|---|
| 월 크레딧 (Standard·Pro) | 결제일에 소멸, 다음 달로 이월되지 않음 |
| 월 크레딧 (Max·Team) | 최대 1개월치 이월 |
| 추가 구매 크레딧 | 만료되지 않음 |
| 크레딧 사용 순서 | 이번 달 크레딧 → 이월 크레딧 → 구매 크레딧 |
| 구독 환불 | 결제·갱신 후 30일 이내, 거의 쓰지 않은 경우에 한해 런웨이 판단으로 가능 |
| 크레딧 구매 환불 | 30일 이내, 쓰지 않은 크레딧만 |
| 결과물이 마음에 안 들 때 | 환불 사유가 되지 않음 |
| 생성 오류 | 오류로 끝난 생성은 몇 분 안에 크레딧 자동 반환 |
| 하위 요금제·월 결제로 변경 | 남은 금액은 결제한 카드로 자동 환불 (일부 예외는 계정 잔액으로 적립) |
| 앱스토어·구글플레이 결제 | 애플·구글 환불 정책을 따름 |

연 결제를 실수로 골랐다면 월 결제로 바꾼 뒤 차액을 돌려받을 수 있다고 안내되어 있습니다. 다만 영상이나 이미지를 이미 만들었다면 "사용한 것"으로 보아 환불이 어려운 경우가 많습니다.

## 런웨이 가격을 아끼는 방법

| 방법 | 설명 |
|---|---|
| 5초로 먼저 테스트 | Gen-4.5 10초는 120크레딧, 5초는 60크레딧 |
| 시안은 Turbo·이미지로 | Gen-4 Turbo는 같은 크레딧으로 Gen-4.5의 약 2배 길이 |
| 소리는 마지막에 | 소리가 들어간 생성은 크레딧이 더 듦 |
| 행사 쿠폰 확인 | 연 결제 첫해 30% 할인 같은 행사는 기간 한정 |
| 월 크레딧은 그달에 소진 | Standard·Pro는 남은 크레딧이 이월되지 않음 |
| 프롬프트를 미리 다듬기 | 다시 뽑는 횟수가 줄어 크레딧 절약 |

카메라 움직임과 조명을 처음부터 정확히 지시하면 다시 생성하는 횟수가 줄어듭니다. 프롬프트 쓰는 요령은 [AI 영상 프롬프트 작성법](../ai-video-prompt-camera-lighting/) 글에 정리해 두었습니다.

## 마무리

런웨이 가격은 2026년 11월 기준 월 결제 Standard $15, Pro $35, Max $95이며, 연 결제를 하면 각각 월 $12, $28, $76로 내려갑니다. 11월 행사 기간에는 연 결제 첫해 30% 추가 할인까지 붙어 Standard를 월 $8.40에 쓸 수 있습니다. 무료 요금제는 125크레딧을 한 번만 주고 영상에 워터마크가 붙으며, 유료 요금제 차이는 월 크레딧, 동시 생성 수, 4K 업스케일, Max의 크레딧 이월에서 갈립니다. 쓴 뒤에는 환불이 어렵고 Standard·Pro 크레딧은 이월되지 않으므로, Standard 월 결제로 먼저 써 보고 필요한 만큼 올리는 방법을 추천합니다. 할인과 크레딧 소모량은 자주 바뀌니 결제 직전에 공식 요금 화면을 다시 확인하세요.
