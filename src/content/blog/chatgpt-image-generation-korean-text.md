ChatGPT는 대화창에서 바로 이미지를 만들고 고칠 수 있어서, 별도 이미지 도구를 배우지 않아도 포스터·썸네일·카드뉴스 시안을 뽑을 수 있습니다. 이 글은 ChatGPT로 이미지를 처음 만들어 보려는 분이나, 이미지 속 한글이 깨지고 원하지 않는 부분까지 바뀌어서 고민인 분을 위해 2026년 10월 기준 사용 순서와 프롬프트 요령을 정리했습니다.

## ChatGPT 이미지 생성, 지금 어떤 모델인가 (2026년 10월 기준)

ChatGPT의 이미지 기능은 몇 달 간격으로 모델이 바뀌어 왔습니다. 2026년 4월에 ChatGPT Images 2.0(API 이름 gpt-image-2)이 나오면서 한국어·일본어·중국어 같은 비라틴 문자의 글자 표현이 크게 좋아졌다는 평가를 받았고, 2026년 9월 8일에는 ChatGPT Images 2.5가 공개되었습니다.

| 버전 | 공개 시기 | 주요 변화 |
|---|---|---|
| ChatGPT Images 2.0 (gpt-image-2) | 2026년 4월 | 한국어 등 비라틴 문자 표현 개선, 생각(Thinking) 방식 이미지 생성 도입 |
| ChatGPT Images 2.5 | 2026년 9월 8일 | 응답 속도 개선, 여러 번 고칠 때의 일관성 향상, 스케치·템플릿·이미지 코멘트 기능 추가 |
| API 모델 (2.5) | 2026년 9월 | 빠른 기본형 gpt-image-2.5-flare, 정밀 작업용 gpt-image-2.5-sunburst |

OpenAI는 Images 2.5가 ChatGPT의 모든 요금제에서 데스크톱·모바일·웹으로 제공된다고 발표했습니다. OpenAI가 밝힌 속도 개선 폭(최대 50% 빠름)은 회사 측 수치이므로 실제 체감은 작업 내용에 따라 다를 수 있습니다.

## 요금제별로 무엇이 다른가

무료 사용자도 같은 이미지 모델을 쓸 수 있지만, 만들 수 있는 양과 일부 기능에 차이가 있습니다.

| 항목 | 무료 | Plus·Pro·Business |
|---|---|---|
| 기본 이미지 생성·편집 | 사용 가능 | 사용 가능 |
| 사용량 | 가장 적음, 한도에 가까워지면 안내 표시 | 더 많음 (요금제가 높을수록 여유) |
| 생각(Thinking) 방식 이미지 생성 | 제공 안 됨 | 사용 가능 |
| 스케치·템플릿·코멘트 | 무료에서도 쓸 수 있다는 보도가 많음 | 사용 가능 |

Go 요금제는 무료보다 사용량이 많지만, 기능 범위는 공식 요금 페이지에서 확인하는 것이 정확합니다.

OpenAI는 무료 사용자가 하루에 몇 장을 만들 수 있는지 고정된 숫자를 공식적으로 밝히지 않고 있습니다. 인터넷에 돌아다니는 "하루 몇 장" 같은 숫자는 개인 리뷰 기준이니 참고만 하고, 요금제별 가격과 혜택은 결제 전에 ChatGPT 요금 페이지에서 직접 확인하는 것을 추천합니다. 생각 방식 이미지 생성은 만들기 전에 요청을 정리하고 필요하면 웹 검색까지 활용하기 때문에, 정보가 많이 들어가는 인포그래픽이나 글자가 많은 포스터에서 차이가 나는 경우가 많습니다.

## 이미지 만드는 기본 순서

웹(chatgpt.com)과 모바일 앱에서 흐름은 같습니다. 메뉴 이름은 업데이트에 따라 조금씩 달라질 수 있습니다.

| 단계 | 할 일 | 요령 |
|---|---|---|
| 1 | 새 대화를 열고 입력창에 원하는 이미지를 설명 | "이미지 만들어 줘"를 넣으면 이미지 요청이 분명해짐 |
| 2 | 비율과 용도를 함께 적기 | "인스타그램 피드용 4:5 세로", "유튜브 썸네일용 16:9 가로" |
| 3 | 참고 이미지가 있으면 + 버튼으로 첨부 | 제품 사진, 로고, 원하는 분위기의 사진 등 |
| 4 | 결과를 보고 같은 대화에서 고칠 점 요청 | 한 번에 한 가지씩 고치기 |
| 5 | 마음에 드는 결과 다운로드 | 이미지 라이브러리에서 다시 찾을 수 있음 |

데스크톱에서는 템플릿 메뉴에서 전단지, 포스터, 굿즈, 제품 사진처럼 자주 쓰는 형식을 골라 시작할 수도 있습니다. 입력창에 `@Sketch`를 입력하면 스케치 도구가 열려, 대략적인 배치를 손으로 그린 뒤 그 그림을 바탕으로 완성 이미지를 만들게 할 수 있습니다. 구도를 말로 설명하기 어려울 때 특히 쓸모가 있습니다.

기본 요청은 아래 형식으로 쓰면 빠뜨리는 내용이 줄어듭니다.

```
[용도]에 쓸 이미지를 만들어 줘. 비율은 [가로:세로].
주제는 [무엇이 무엇을 하는 장면]이고, 스타일은 [사진/일러스트/3D 등], 분위기는 [밝은/차분한 등].
이미지 안에 들어갈 글자는 "[문구]" 하나뿐이고, 위치는 [상단 가운데 등].
```

구도·조명·스타일 용어를 더 다양하게 쓰고 싶다면 [AI 이미지 프롬프트 기본 공식](../ai-image-prompt-formula/) 글을 함께 참고하세요.

## 한글 글자를 깨지지 않게 넣는 요령

Images 2.0 이후 한글 표현이 많이 좋아졌지만, 문구가 길거나 글자가 작으면 여전히 받침이 빠지거나 비슷한 글자로 바뀌는 경우가 있습니다. 글자가 들어가는 이미지는 아래 원칙을 지키면 실패가 크게 줄어듭니다.

| 원칙 | 이렇게 요청합니다 | 이유 |
|---|---|---|
| 문구는 따옴표로 정확히 | 문구는 "가을 신메뉴 출시" 그대로 | 모델이 문구를 바꾸거나 덧붙이지 않게 함 |
| 문구는 짧게 | 제목 한 줄 + 부제 한 줄 정도 | 글자가 많을수록 오타 확률이 높아짐 |
| 글자 크기와 위치 지정 | 상단 가운데에 크고 굵은 글씨로 | 작은 글씨일수록 획이 뭉개지기 쉬움 |
| 그 외 글자 금지 | 그 밖의 글자, 로고, 숫자는 넣지 마 | 배경에 의미 없는 글자가 생기는 것을 막음 |
| 서체 느낌 묘사 | 굵은 고딕체, 손글씨 느낌 등 | 분위기에 맞는 글꼴로 맞춰 줌 |
| 틀린 글자만 다시 요청 | "출시"의 "시"가 틀렸어, 그 글자만 고쳐 줘 | 전체를 다시 만들면 다른 부분이 바뀜 |

카페 홍보 포스터를 예로 들면 이렇게 요청할 수 있습니다.

```
카페 매장 앞에 붙일 세로 2:3 포스터를 만들어 줘.
따뜻한 갈색 톤의 사진 느낌으로, 나무 테이블 위에 밤 라떼 한 잔이 놓인 장면.
이미지 안의 글자는 아래 두 줄만 정확히 넣어 줘.
상단 가운데, 크고 굵은 고딕체: "가을 신메뉴 출시"
하단 가운데, 작은 글씨: "밤 라떼 · 고구마 라떼"
그 밖의 글자, 로고, 숫자는 넣지 마.
```

글자가 많은 메뉴판이나 가격표처럼 한 글자도 틀리면 안 되는 이미지는, ChatGPT로 배경과 그림만 만들고 글자는 캔바나 미리캔버스 같은 디자인 도구에서 직접 얹는 방법이 더 안전합니다. 카드뉴스처럼 여러 장에 글이 들어가는 작업은 [AI로 카드뉴스 만들기](../ai-card-news-guide/) 글에서 이 방식으로 정리해 두었습니다.

## 일부만 고치는 방법 — 선택 도구와 코멘트

이미지 전체를 다시 만들지 않고 특정 부분만 고치는 방법은 크게 세 가지입니다.

| 방법 | 사용법 | 잘 맞는 작업 |
|---|---|---|
| 대화로 요청 | 같은 대화에서 "배경만 바다로 바꿔 줘"처럼 입력 | 분위기·색감·배경처럼 넓은 범위 수정 |
| 선택 도구 | 이미지를 열고 선택 도구로 고칠 부분을 칠한 뒤 바꿀 내용을 입력 | 물체 하나 지우기, 소품 바꾸기, 글자 한 줄 수정 |
| 이미지 코멘트 (2.5) | 이미지 위 특정 위치에 코멘트를 달아 수정 내용을 적음 | 여러 곳을 각각 다르게 고칠 때 |

OpenAI 도움말은 선택 영역이 항상 정확하지는 않아서, 수정이 선택한 범위 밖까지 번질 수 있다고 안내합니다. 그래서 선택 도구를 쓸 때도 바꾸지 말아야 할 것을 문장으로 함께 적어 두는 것이 좋습니다.

```
선택한 부분의 컵만 투명한 유리컵으로 바꿔 줘.
테이블, 배경, 조명, 상단 글자 "가을 신메뉴 출시"는 그대로 유지해 줘.
```

여러 번 고치다 보면 얼굴이나 글자가 조금씩 원본에서 멀어질 수 있습니다. 대여섯 번 이상 수정해도 어색하다면 마음에 들었던 버전을 내려받아 새 대화에 첨부하고, 지금까지의 요청을 한 번에 정리해서 다시 시작하는 편이 결과가 안정적인 경우가 많습니다. 대화로 사진을 고치는 요령은 다른 도구에서도 비슷해서, [나노바나나로 사진 보정·편집하기](../nano-banana-photo-editing-guide/) 글의 프롬프트 형식도 그대로 응용할 수 있습니다.

## 상업적으로 쓸 때 확인할 점

만든 이미지를 블로그, 광고, 판매용으로 쓸 계획이라면 표시 방식과 권리 문제를 미리 확인해야 합니다.

| 확인 항목 | 2026년 10월 기준 내용 |
|---|---|
| 출처 정보 | OpenAI 이미지에는 C2PA 메타데이터와 눈에 보이지 않는 SynthID 워터마크가 들어간다고 OpenAI 도움말이 안내함 |
| 메타데이터 유지 | 스크린샷이나 일부 앱 저장 과정에서 메타데이터가 사라질 수 있음 |
| 결과물 권리 | OpenAI 이용약관상 이용자에게 결과물에 대한 권리가 넘어가지만, 법적 저작권 인정 여부는 별개 문제 |
| 실존 인물·브랜드 | 유명인 얼굴, 다른 회사 로고·캐릭터를 넣은 이미지는 초상권·상표권 문제가 생길 수 있음 |
| 플랫폼 표시 의무 | 유튜브·인스타그램 등은 사실처럼 보이는 AI 이미지에 표시를 요구하는 경우가 있음 |

약관과 정책은 자주 바뀌므로 상업적으로 쓰기 전에는 OpenAI 이용약관과 사용 정책을 다시 확인하세요. AI 생성물의 저작권과 상업 이용 전반은 [AI 영상 저작권과 상업적 이용](../ai-video-copyright-commercial/) 글에서 더 자세히 다뤘습니다.

## 자주 생기는 문제와 해결법

| 문제 | 원인 | 해결법 |
|---|---|---|
| 한글 받침이 빠지거나 글자가 바뀜 | 문구가 길거나 글자가 작음 | 문구를 줄이고 크게, 틀린 글자만 지목해서 다시 요청 |
| 배경에 이상한 글자가 생김 | 글자 관련 조건을 안 적음 | "지정한 문구 외 글자는 넣지 마" 추가 |
| 고치지 않은 부분까지 바뀜 | 수정 범위가 넓거나 여러 개를 한꺼번에 요청 | 선택 도구나 코멘트로 범위를 좁히고 유지할 것을 명시 |
| 비율이 원하는 대로 안 나옴 | 비율을 문장 끝에 흐리게 적음 | 첫 문장에 "세로 9:16"처럼 숫자로 명시 |
| 생성 요청이 거절됨 | 실존 인물, 저작권 캐릭터 등 정책 제한 | 요청 내용을 바꾸고 사용 정책 확인 |
| 잠시 기다리라는 안내가 뜸 | 요금제별 사용량 한도 도달 | 시간이 지난 뒤 다시 시도하거나 요금제 확인 |

유튜브 썸네일처럼 클릭률이 중요한 이미지는 여러 시안을 만들어 비교하는 과정이 필요합니다. 이 과정은 [AI로 유튜브 썸네일 만들기](../ai-youtube-thumbnail-guide/) 글에 정리해 두었습니다.

## 마무리

ChatGPT 이미지 생성은 대화하듯 요청하고 고칠 수 있다는 점이 가장 큰 장점입니다. 한글 글자를 넣을 때는 **문구를 따옴표로 정확히, 짧고 크게, 그 밖의 글자는 넣지 말라고** 적는 것이 핵심이고, 일부만 고칠 때는 선택 도구나 코멘트로 범위를 정하면서 유지할 부분을 함께 적으면 결과가 안정적입니다.

다만 이미지 모델과 요금제별 한도는 2026년에만 여러 번 바뀌었습니다. 이 글의 내용은 2026년 10월 기준이며, 중요한 작업이나 상업적 사용 전에는 OpenAI 공식 도움말과 요금 페이지에서 현재 조건을 확인하시기 바랍니다.
