AI 전자책 만들기는 챗GPT나 클로드 같은 도구로 원고 초안을 빠르게 쓰고, 이미지 생성 도구로 표지를 만들어 판매하는 방법입니다. 이 글은 AI로 전자책을 처음 만들어 보려는 분을 위해 주제 정하기부터 판매 등록까지의 과정을 6단계로 나누고, 단계마다 쓸 수 있는 프롬프트와 주의할 규칙을 정리했습니다. 플랫폼 규정은 2026년 11월 공식 안내 기준이며, 바뀔 수 있으므로 등록 전에 각 공식 페이지를 다시 확인하시기 바랍니다.

## AI 전자책 만들기 6단계 한눈에 보기

먼저 전체 흐름을 정리하면 아래와 같습니다. AI가 가장 크게 시간을 줄여 주는 부분은 목차와 초안이고, 주제 선정과 검수는 사람이 맡아야 하는 부분입니다.

| 단계 | 할 일 | AI가 하는 일 | 사람이 하는 일 |
|---|---|---|---|
| 1. 주제 정하기 | 누구의 어떤 문제를 풀지 정함 | 아이디어 목록, 독자 질문 정리 | 내가 아는 분야인지, 수요가 있는지 판단 |
| 2. 목차 짜기 | 장·절 구성 | 목차 초안 여러 개 제안 | 순서 조정, 빠진 내용 추가 |
| 3. 초안 쓰기 | 장별 원고 작성 | 장 단위로 초안 생성 | 내 사례·자료 넣기 |
| 4. 검수·편집 | 사실 확인, 문체 통일 | 맞춤법, 중복 문장 찾기 | 숫자·법규·출처 확인 |
| 5. 표지·디자인 | 표지와 본문 편집 | 표지 이미지 생성 | 제목 글자 배치, 파일 변환 |
| 6. 판매 등록 | 플랫폼에 올리기 | 소개 문구 초안 | 가격 결정, 규정 확인 |

한 권을 만드는 데 걸리는 시간은 분량과 검수 수준에 따라 크게 달라집니다. 초안은 하루 만에 나오더라도 검수와 편집에 그보다 몇 배의 시간이 드는 경우가 많다는 점을 미리 알아 두면 좋습니다.

## 1단계 — 팔리는 주제 정하기

AI 전자책이 잘 팔리지 않는 가장 흔한 이유는 주제가 너무 넓거나, 누구나 무료로 찾을 수 있는 내용이라는 점입니다. "재테크 입문"보다 "사회초년생 첫 월급 통장 나누기"처럼 독자와 문제를 좁히는 편이 구매로 이어지기 쉽습니다.

| 좋은 주제의 조건 | 피해야 할 주제 |
|---|---|
| 내가 직접 해 본 업무나 경험이 있는 분야 | 검색 한 번이면 나오는 일반 상식 |
| 독자가 구체적인 문제를 가진 주제 | "성공하는 법"처럼 막연한 주제 |
| 체크리스트·템플릿처럼 바로 쓸 수 있는 결과물 | 의료·법률 판단처럼 전문 자격이 필요한 조언 |
| 비슷한 상품의 후기에서 아쉬운 점이 보이는 주제 | 실존 인물이나 다른 책 내용을 그대로 요약한 것 |

주제 후보를 찾을 때는 아래처럼 AI에게 독자 질문을 뽑게 하면 목차 짜기까지 이어서 쓸 수 있습니다.

```
나는 5년 차 온라인 쇼핑몰 운영자야.
"처음 스마트스토어를 여는 사람"이 실제로 막히는 질문을 30개 뽑아 줘.
질문은 준비, 상품 등록, 사진, 배송, 정산으로 묶어서 보여 줘.
```

## 2단계 — 목차 짜기 프롬프트

목차는 전자책의 품질을 좌우합니다. AI에게 한 번에 정답을 받기보다 여러 안을 받아서 비교하는 방식을 추천합니다.

```
아래 독자 질문 목록을 바탕으로 전자책 목차를 3가지 안으로 만들어 줘.
- 독자: 처음 스마트스토어를 여는 직장인
- 분량: A5 기준 60~80쪽
- 조건: 각 장 끝에 체크리스트 1개, 장 제목은 독자가 얻는 결과로 쓰기
- 각 안의 장점과 단점도 한 줄씩 적어 줘
```

받은 목차에서 순서를 바꾸고, 내가 꼭 넣고 싶은 사례나 자료가 들어갈 자리를 표시해 두면 다음 단계가 쉬워집니다. 독자 질문 가운데 목차에 들어가지 않은 것이 있으면 부록이나 자주 묻는 질문 장으로 묶는 방법도 있습니다.

## 3단계 — AI로 초안 쓰기

초안은 책 전체를 한 번에 요청하지 말고 장 단위로 나눠서 씁니다. 한 번에 길게 요청하면 앞뒤 내용이 겹치거나 뒤로 갈수록 내용이 얕아지는 경우가 많기 때문입니다.

```
아래 목차의 3장을 써 줘.
- 3장 제목: 상품 사진, 스마트폰 하나로 찍는 법
- 분량: 3,000자 안팎
- 문체: 존댓말, 짧은 문장, 전문 용어는 처음 나올 때 풀어서 설명
- 반드시 넣을 내용: 아래 메모 (내가 실제로 쓰는 촬영 순서)
- 모르는 숫자나 사실은 지어내지 말고 [확인 필요]로 표시해 줘
[메모 붙여넣기]
```

마지막 줄처럼 "모르면 표시하라"는 조건을 넣으면 검수할 곳을 찾기 쉬워집니다. 초안 작성에 쓰는 도구별 특징과 블로그 글쓰기 프롬프트는 [클로드 블로그 글쓰기 프롬프트](../claude-blog-draft-writing/) 글에서도 참고할 수 있습니다.

## 4단계 — 검수와 편집에서 확인할 것

AI 초안은 문장은 매끄럽지만 사실이 틀리거나 근거 없는 숫자가 들어가는 경우가 있습니다. 판매하는 책이라면 이 부분이 환불과 나쁜 후기로 이어질 수 있으므로 아래 항목을 꼭 확인합니다.

| 검수 항목 | 확인 방법 |
|---|---|
| 숫자·통계·법 규정 | 공식 기관이나 서비스 공식 페이지에서 직접 확인 |
| [확인 필요] 표시 | 모두 찾아 사실로 채우거나 문장 삭제 |
| 장마다 반복되는 문장 | 같은 설명이 여러 장에 나오면 한 곳으로 합치기 |
| 문체 통일 | 존댓말·반말, 용어 표기를 한 가지로 맞추기 |
| 다른 저작물과 비슷한 문장 | 특정 책·글과 지나치게 비슷한 부분은 다시 쓰기 |
| 내 경험·사례 | 책마다 다른 곳에 없는 내용이 들어갔는지 확인 |

검수를 마친 뒤에는 AI에게 "독자 입장에서 이해하기 어려운 부분을 찾아 달라"고 한 번 더 요청하면, 설명이 빠진 단계를 찾는 데 도움이 됩니다.

## 5단계 — 표지와 본문 디자인

표지 이미지는 이미지 생성 도구로 만들 수 있습니다. 다만 이미지 안에 한글 제목을 정확하게 넣는 것은 아직 도구마다 결과가 들쭉날쭉하므로, 배경 이미지만 생성하고 제목 글자는 캔바 같은 편집 도구에서 직접 올리는 방법이 안정적입니다.

```
Minimal e-book cover background, a smartphone on a small tripod
photographing a product on a white table, soft pastel colors,
large empty space at the top for a title, no text, no letters
```

본문은 워드나 구글 문서로 정리한 뒤 판매처가 받는 형식(PDF, EPUB 등)으로 변환합니다. 판매처마다 받는 파일 형식이 다르므로 등록할 곳을 먼저 정하고 형식을 맞추는 편이 수정이 적습니다.

## 6단계 — 판매 등록 전 확인할 규정

AI로 만든 전자책도 판매할 수 있지만, 플랫폼마다 AI 사용 표시와 유통 조건이 다릅니다. 대표적으로 아마존 KDP는 AI 사용을 두 가지로 구분합니다.

| 구분 (아마존 KDP, 2026년 11월 공식 도움말 기준) | 뜻 | 신고 필요 여부 |
|---|---|---|
| AI 생성(AI-generated) | 글·이미지·번역을 AI 도구가 만든 경우, 이후 크게 수정했더라도 포함 | 새 책 출간이나 재출간 때 알려야 함 |
| AI 보조(AI-assisted) | 내가 쓴 내용을 AI로 다듬거나 오류를 찾거나 아이디어를 얻은 경우 | 알리지 않아도 됨 |
| 공통 | 표지·본문 이미지도 대상 | 콘텐츠 지침과 지식재산권 준수 책임은 저자에게 있음 |

KDP 전자책 인세는 35%와 70% 두 가지 옵션이 있고, 70% 옵션은 대상 지역 판매에만 적용되며 파일 크기에 따른 전송 비용이 빠집니다. 국내에서는 크몽 같은 재능 마켓이나 전자책 유통 플랫폼을 많이 이용하는데, 판매 수수료는 구간별로 달라지고 개편되기도 하므로 판매자 센터의 수수료 안내에서 직접 확인해야 합니다.

| 판매처 유형 | 특징 | 등록 전 확인할 것 |
|---|---|---|
| 재능 마켓(크몽 등) | 실용 노하우 전자책 수요가 많음, 상품 심사 있음 | 판매 수수료, 전자책 카테고리 심사 기준 |
| 서점 유통 플랫폼 | 온라인 서점에 책으로 유통 | ISBN 필요 여부, 지원 파일 형식 |
| 해외(아마존 KDP) | 영어권 독자 대상 | AI 생성 신고, 인세 옵션, 지원 언어 |
| 내 블로그·스토어 직접 판매 | 수수료 부담이 적음 | 결제 수단, 파일 전달 방법, 세금 신고 |

서점 유통에 필요한 ISBN은 국립중앙도서관 ISBN 센터에서 발행자(출판사) 단위로 신청하는 구조이므로, 개인이라면 출판사 등록을 하거나 ISBN 발급을 대행하는 유통 플랫폼을 이용하는 방법을 확인해 보시기 바랍니다.

## AI 전자책 저작권, 내 책으로 인정받을 수 있을까

한국저작권위원회의 생성형 AI 저작권 안내서는 AI가 만든 결과물 자체는 저작물로 보지 않고, 사람이 창작적으로 기여한 부분만 저작권 등록 대상이 된다는 입장입니다. 즉 AI 초안을 거의 그대로 판매하면 그 부분은 내 저작물로 보호받기 어렵고, 다른 사람이 비슷한 책을 내도 막기 어려울 수 있습니다.

| 상황 | 저작권 관점에서 보는 방향 |
|---|---|
| AI 초안을 거의 수정 없이 판매 | 사람의 창작적 기여가 적어 보호받기 어려움 |
| 내가 쓴 원고를 AI로 맞춤법·문장만 다듬음 | 내 원고 부분은 내 저작물로 볼 여지가 큼 |
| AI가 만든 표지 이미지 | 이미지 자체는 보호받기 어려움, 글자 배치·편집은 별도로 판단 |
| AI 결과물을 골라 새로 구성 | 선택·배열에 창작성이 있으면 편집저작물로 볼 여지 |

결국 판매도 잘되고 권리도 지키려면 내 경험과 자료를 많이 넣는 것이 가장 현실적인 방법입니다. AI 결과물의 상업적 이용 기준은 [AI 그림 저작권 — 상업적으로 써도 되는 경우](../ai-image-copyright-commercial/) 글에 더 자세히 정리했습니다.

## 마무리

AI 전자책 만들기는 주제 정하기, 목차, 초안, 검수, 표지, 판매 등록의 순서로 진행합니다. AI는 목차와 초안 시간을 크게 줄여 주지만, 팔리는 책을 만드는 것은 좁고 구체적인 주제와 꼼꼼한 검수, 그리고 다른 곳에 없는 내 경험입니다. 등록 전에는 판매처의 AI 표시 규정과 수수료를 공식 페이지에서 확인하고, 전자책 말고 다른 AI 부업도 함께 비교해 보고 싶다면 [AI 부업 종류와 현실 비교](../ai-side-hustle-types/) 글을 참고하시기 바랍니다.
