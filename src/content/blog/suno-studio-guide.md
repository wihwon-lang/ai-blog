수노 스튜디오는 Suno로 만든 노래를 트랙별로 나누고, 악기를 더하고, 직접 녹음까지 할 수 있는 웹 기반 음악 편집 화면입니다. 일반 생성 화면과 달리 쓸 수 있는 요금제가 정해져 있고 메뉴 구성도 달라서 처음 열면 어디서부터 손대야 할지 헷갈리는 경우가 많습니다. 이 글은 Suno로 곡을 만들어 본 분을 위해 수노 스튜디오의 가격, 기본 화면, 스템 분리, 내보내기 방법을 2026년 11월 기준 Suno 공식 요금 페이지와 도움말을 바탕으로 정리합니다.

## 수노 스튜디오, 결론부터

수노 스튜디오는 **Premier(월 $30) 이상 요금제에서만** 열 수 있습니다. 무료 플랜과 Pro 플랜에서는 스튜디오 메뉴를 쓸 수 없고, Pro는 노래 단위의 스템 추출과 편집까지만 됩니다. 현재 버전은 2026년에 나온 **Studio 2.0**으로, MIDI 트랙·신시사이저·이펙트·채팅으로 만드는 플러그인이 추가되었습니다.

| 궁금한 점 | 답 (2026년 11월 공식 안내 기준) |
|---|---|
| 무료로 쓸 수 있나 | 불가, Premier·Platinum 전용 |
| 어디서 여나 | 왼쪽 메뉴의 Create 아이콘 아래 Studio 아이콘 |
| 어떤 기기에서 되나 | 화면 너비 768px 이상인 데스크톱·노트북·태블릿 (휴대폰 미지원) |
| 무엇을 할 수 있나 | 트랙 나누기, AI 악기 추가, 녹음, MIDI 편집, 이펙트, 멀티트랙 내보내기 |
| 내보내기 형식 | 32비트 WAV 또는 MP3, 스템은 WAV |
| 외부 플러그인 | VST·AU 플러그인 미지원 |

## 수노 스튜디오 가격 — 어떤 요금제가 필요할까

Suno 요금 페이지에서 스튜디오가 들어 있는 요금제는 Premier와 Platinum 두 가지입니다. Pro와의 차이를 함께 보면 어떤 플랜을 골라야 할지 판단하기 쉽습니다.

| 항목 | Free | Pro | Premier | Platinum |
|---|---|---|---|---|
| 월 결제 | $0 | $10 | $30 | $120 |
| 연간 결제 (월 환산) | $0 | $8 | $24 | $100 |
| 월 크레딧 | 하루 50 | 2,500 | 10,000 | 15,000 |
| 월 다운로드 | 없음 | 20곡 | 60곡 | 120곡 |
| 수노 스튜디오 | 불가 | 불가 | 가능 | 가능 |
| 스템 분리 방식 | 없음 | 2종 (Auto, Split from Mix) | 3종 (Advanced Split 추가) | 3종 |
| 상업적 이용 | 불가 | 가능 | 가능 | 가능 |

월 크레딧은 다음 달로 이월되지 않습니다. 원화 결제 금액은 환율과 카드사 해외 결제 수수료에 따라 달라지므로, 결제 직전 화면의 금액을 기준으로 보는 것이 안전합니다. 무료 플랜과 Pro의 차이, 무료로 만든 곡의 상업적 이용 조건은 [AI 노래 만들기 무료](../ai-song-maker-free/) 글에 따로 정리해 두었습니다.

스튜디오가 꼭 필요하지 않다면 Pro로도 노래 전체를 스템으로 나눠 받을 수 있습니다. 반대로 **곡 안의 일부 구간만 다시 만들거나, 악기 트랙을 쌓고, 내 녹음을 섞는 작업**을 하려면 Premier가 필요합니다.

## 수노 스튜디오 화면 구성

스튜디오는 일반 음악 편집 프로그램(DAW)처럼 가로로 흐르는 타임라인 위에 트랙을 쌓는 구조입니다. 공식 도움말에 나온 주요 영역은 아래와 같습니다.

| 영역 | 위치 | 하는 일 |
|---|---|---|
| 타임라인 | 화면 가운데 | 메인 트랙과 테이크 레인(Take Lanes)을 놓고 편집 |
| 채팅 바 (Chat Bar) | 타임라인 아래 | 대화로 오디오·MIDI 클립 생성, 플러그인 만들기, 곡 배치 |
| 상세 패널 | 오른쪽 | 라이브러리 곡의 Remix/Edit와 스템 목록 |
| 트랜스포트 | 화면 아래 | 재생·정지, 업로드, 녹음 |
| 프로젝트 메뉴 | 프로젝트 제목 클릭 | 자동 저장된 버전(Versions) 확인 |
| 내보내기 버튼 | 오른쪽 위 | 전체 곡, 선택 구간, 멀티트랙 내보내기 |

Studio 2.0에서는 예전 버전의 컨텍스트 바가 **채팅 바**로 바뀌었습니다. 스튜디오는 자동으로 저장되므로 따로 저장 버튼이 없고, 이전 상태로 돌아가고 싶을 때는 프로젝트 메뉴의 버전 목록에서 시간별 저장본을 고르면 됩니다.

## 수노 스튜디오 사용법 — 기본 작업 순서

처음이라면 이미 만든 곡을 불러와 트랙을 나누고, 악기 하나를 더해 보는 순서가 가장 이해하기 쉽습니다.

| 단계 | 할 일 | 방법 |
|---|---|---|
| 1 | 스튜디오 열기 | 왼쪽 메뉴 Create 아래 Studio 아이콘 선택 |
| 2 | 곡 불러오기 | 라이브러리에서 곡 선택 → 상세 패널 Remix/Edit → 스템 옆 화살표 또는 Insert All |
| 3 | 파일 올리기 | 트랜스포트의 Upload로 WAV·MP3·MIDI 파일 가져오기 |
| 4 | AI 악기 추가 | 채팅 바에서 원하는 파트를 설명해 오디오나 MIDI 클립 생성 |
| 5 | 테이크 고르기 | 생성할 때마다 2개가 나오므로 테이크 레인에서 들어 보고 Copy to Main Track |
| 6 | 녹음 | 오디오 트랙 추가 → 트랙의 빨간 녹음 버튼으로 준비 → 트랜스포트 Record |
| 7 | 다듬기 | 이펙트, 볼륨·패닝 오토메이션 적용 |
| 8 | 내보내기 | 오른쪽 위 Export에서 형식 선택 |

AI로 악기를 추가할 때는 장르보다 **악기, 연주 방식, 들어갈 구간**을 구체적으로 적는 편이 원하는 결과에 가깝게 나오는 경우가 많습니다. 채팅 바에는 아래처럼 영어로 짧게 요청하면 됩니다.

```
Add a warm electric piano part playing soft chords in the chorus, 4 bars, low velocity
```

```
Create a simple four-on-the-floor drum loop that matches the current tempo
```

여러 테이크에서 좋은 부분만 골라 하나로 합치는 **컴핑(Comping)** 도 지원합니다. 또 타임라인의 특정 구간을 생성 패널로 끌어 놓으면 그 구간을 바탕으로 새 곡을 만들어 라이브러리에 저장할 수 있습니다. 노래를 처음 만들 때 쓰는 스타일 프롬프트는 [Suno AI 사용법](../suno-ai-background-music/) 글을 참고하세요.

## 스템 분리 방법과 크레딧

스템은 보컬, 드럼, 베이스, 기타, 건반처럼 악기별로 나눈 트랙입니다. 스튜디오에서는 타임라인의 오디오 클립을 마우스 오른쪽 버튼으로 누르고 **Split Stems**를 고른 뒤 분리 방식을 선택해 Extract를 누르면 됩니다.

| 분리 방식 | 결과 | 크레딧 | 쓸 수 있는 요금제 |
|---|---|---|---|
| Auto Split | 최대 12개 스템으로 자동 분리 | 1회 50크레딧 | Pro, Premier |
| Split from Mix | 원하는 스템만 골라 분리 | 스템 1개당 10크레딧 | Pro, Premier |
| Advanced Split | 약 100가지 악기 목록에서 골라 분리 | 스템 1개당 10크레딧 | Premier 전용 |

보컬만 빼서 반주를 만들거나 드럼만 바꾸고 싶다면 필요한 스템만 고르는 Split from Mix가 크레딧을 아끼는 데 유리합니다. 모든 악기를 한 번에 나눠 편집하려면 Auto Split이 편합니다. 크레딧 숫자는 Suno 도움말 기준이며, 도움말 문서마다 표기가 조금씩 다른 경우가 있으니 실행 전 화면에 표시되는 크레딧을 확인하세요.

## MIDI·신시사이저·이펙트 (Studio 2.0 기능)

Studio 2.0에서 추가된 기능은 음악 편집 프로그램을 써 본 분이라면 익숙한 것들입니다.

| 기능 | 내용 |
|---|---|
| MIDI 트랙 | 피아노 롤 편집, 컴퓨터 키보드 입력(코드 모드·아르페지에이터), 외부 MIDI 컨트롤러 연결 |
| 오디오 → MIDI 변환 | 오디오 클립을 MIDI 트랙으로 끌어 놓으면 음표로 변환 |
| 신시사이저 | 웨이브테이블 신스 등 내장 악기와 기본 프리셋, Cmd-K로 화면 건반 열기 |
| 이펙트 | 컴프레서, 컨볼루션, 딜레이, 디스토션, EQ, 게이트, 리버브 |
| 오토메이션 | 볼륨·패닝·플러그인 값 변화를 선으로 그리기, MIDI Learn 지원 |
| 나만의 플러그인 | 채팅 바에 원하는 효과를 설명하면 플러그인을 만들어 개인 라이브러리에 저장 |

예전 Studio 1.x 프로젝트는 2.0에서 열 수 있지만, 2.0으로 바꾼 뒤의 작업은 1.x로 되돌릴 수 없다고 안내되어 있습니다. 공식 도움말은 1.x를 2026년 9월 초에 종료할 예정이라고 밝혔습니다.

## 내보내기 형식과 다운로드 한도

작업이 끝나면 오른쪽 위 Export 버튼으로 내보냅니다. 공식 도움말 기준 선택지는 세 가지입니다.

| 내보내기 방식 | 저장 위치 | 형식 |
|---|---|---|
| 전체 곡 (Full Song) | Suno 라이브러리 | 32비트 WAV 또는 MP3 |
| 선택 구간 (Selected Time Range) | Suno 라이브러리 | 32비트 WAV 또는 MP3 |
| 멀티트랙 (Multitracks) | 내 기기로 다운로드 | 트랙·스템별 개별 파일 (스템은 WAV) |

일반 노래 다운로드는 Premier 기준 월 60곡까지이고, 같은 곡을 다시 받거나 여러 형식으로 받아도 1곡으로 계산됩니다. Suno 다운로드 도움말은 **스튜디오 작업 흐름은 이 다운로드 한도의 영향을 받지 않는다**고 안내합니다. 다만 세부 계산 방식은 바뀔 수 있으므로 대량으로 내보내기 전에 계정 화면의 남은 다운로드 수를 확인하는 것이 좋습니다.

내보낸 파일을 다른 편집 프로그램으로 옮겨 마무리할 수 있지만, 스튜디오 자체는 VST·AU 플러그인이나 다른 DAW와의 직접 연동을 지원하지 않습니다. 수익 영상이나 음원 유통에 쓸 계획이라면 [AI 노래 저작권 수익](../ai-song-copyright-revenue/) 글에서 권리 관계를 먼저 확인하세요.

## 수노 스튜디오가 안 될 때 확인할 것

스튜디오가 열리지 않거나 기능이 보이지 않을 때는 아래 항목을 차례로 확인합니다.

| 증상 | 확인할 것 |
|---|---|
| Studio 메뉴가 없음 | 요금제가 Premier 또는 Platinum인지 계정 페이지(suno.com/account)에서 확인 |
| 휴대폰에서 열리지 않음 | 휴대폰은 미지원, 화면 너비 768px 이상 기기 사용 |
| MIDI 컨트롤러가 인식되지 않음 | 사파리는 Web MIDI 미지원, 구글 크롬 사용 권장 |
| 화면이 느리거나 멈춤 | 메모리 4GB 이상, SIMD(SSE4.1 또는 Neon) 지원 CPU 필요 |
| 새로 만든 파트 박자가 어긋남 | 공식 도움말의 알려진 문제, 메트로놈(Shift-C)이나 솔로(Shift-S)로 확인 후 위치 조정 |
| Advanced Split이 안 보임 | Pro 플랜은 Auto Split, Split from Mix만 가능 |

자주 쓰는 단축키는 재생·정지(스페이스바), 녹음(Shift-R), 메트로놈(Shift-C), 반복 재생(Cmd-L)입니다.

## 마무리

수노 스튜디오는 2026년 11월 기준 Premier(월 $30, 연간 결제 시 월 $24)와 Platinum 요금제에서만 쓸 수 있는 웹 음악 편집 화면입니다. 곡을 불러와 스템으로 나누고, 채팅 바로 악기 파트를 더하고, 직접 녹음한 소리와 섞은 뒤 32비트 WAV나 MP3로 내보내는 흐름이 기본입니다. 스템 분리만 필요하다면 Pro로도 충분하고, 구간 편집·MIDI·이펙트까지 쓰려면 Premier가 필요합니다. 요금과 크레딧, 지원 기능은 자주 바뀌므로 결제 전에 Suno 공식 요금 페이지를 다시 확인하시기 바랍니다.
