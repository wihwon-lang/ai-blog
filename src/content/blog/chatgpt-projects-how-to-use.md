ChatGPT를 업무에 자주 쓰다 보면 대화가 수십 개로 늘어나고, 매번 같은 설명과 같은 파일을 다시 넣어야 하는 일이 생깁니다. 챗GPT 프로젝트는 관련 대화와 파일, 지침을 한 폴더처럼 묶어 두는 기능입니다. 이 글은 챗GPT 프로젝트 사용법을 만들기부터 지침 작성, 파일 추가, 공유, 메모리 설정까지 2026년 11월 기준 OpenAI 공식 도움말을 바탕으로 정리했습니다.

## 먼저 결론 — 프로젝트는 '지침과 파일이 붙은 폴더'입니다

프로젝트 안에서 시작한 대화는 프로젝트에 넣어 둔 지침과 파일을 자동으로 참고합니다. 그래서 같은 주제의 일을 반복할 때 매번 배경 설명을 다시 쓰지 않아도 됩니다.

| 구분 | 일반 대화 | 프로젝트 안의 대화 |
|---|---|---|
| 대화 정리 | 사이드바에 날짜순으로 쌓임 | 프로젝트별로 묶여 따로 보관 |
| 지침 | 계정 전체에 적용되는 맞춤 지침만 사용 | 프로젝트 지침이 맞춤 지침보다 우선 적용 |
| 파일 | 대화마다 다시 올려야 함 | 프로젝트에 한 번 올리면 모든 대화에서 참고 |
| 메모리 | 계정 메모리 사용 | 기본 메모리 또는 프로젝트 전용 메모리 중 선택 |
| 공유 | 대화 링크 공유 | 프로젝트 자체에 다른 사람을 초대 |
| 비용 | 요금제에 포함 | 추가 요금 없음, 사용량은 일반 대화와 같게 계산 |

OpenAI 도움말에 따르면 프로젝트는 Free(무료), Go, Plus, Pro, Business, Enterprise, Edu 요금제에서 쓸 수 있고, 만들 수 있는 프로젝트 개수에는 제한이 없습니다.

## 챗GPT 프로젝트 만들기

프로젝트를 만드는 과정은 1분이면 끝납니다. 웹과 모바일 앱 모두 같은 흐름입니다.

| 단계 | 웹(PC) | 모바일 앱 |
|---|---|---|
| 1 | 왼쪽 사이드바에서 '새 프로젝트' 선택 | 메뉴에서 더하기(+) 아이콘 선택 |
| 2 | 프로젝트 이름 입력 | 프로젝트 이름 입력 |
| 3 | 아이콘과 색상 고르기 | 아이콘과 색상 고르기 |
| 4 | 메모리 방식 선택(기본 또는 프로젝트 전용) | 메모리 방식 선택 |
| 5 | 프로젝트 화면에서 지침과 파일 추가 | 프로젝트 화면에서 지침과 파일 추가 |

이름은 나중에 찾기 쉽도록 **일의 단위**로 짓는 것을 추천합니다. '업무'처럼 넓은 이름보다 '스마트스토어 상세페이지', '11월 블로그 원고', '영어 회화 연습'처럼 목적이 드러나는 이름이 관리하기 편합니다.

이미 나눈 대화도 프로젝트로 옮길 수 있습니다. 사이드바의 대화를 프로젝트 위로 끌어다 놓거나, 대화 메뉴(•••)에서 '프로젝트로 이동'을 고르면 됩니다. 옮긴 대화는 그때부터 프로젝트의 지침과 파일을 참고합니다. 다만 GPT(맞춤형 GPT)로 시작한 대화는 프로젝트로 옮길 수 없습니다.

## 챗GPT 프로젝트 지침 짜는 법

프로젝트 지침은 프로젝트 메뉴(•••)의 '프로젝트 설정'에서 입력합니다. 지침은 그 프로젝트 안에서만 적용되고, 계정 전체에 걸어 둔 맞춤 지침보다 우선합니다. 그래서 평소에는 짧은 답을 받다가도, 특정 프로젝트에서만 긴 보고서 형식으로 답하게 만들 수 있습니다.

좋은 지침은 대체로 네 가지를 담고 있습니다.

| 들어갈 내용 | 무엇을 적나 | 예시 |
|---|---|---|
| 역할 | ChatGPT가 맡을 입장 | 온라인 쇼핑몰 마케팅 담당자 |
| 배경 | 매번 설명하던 고정 정보 | 판매 상품, 주요 고객층, 브랜드 말투 |
| 결과물 형식 | 답변의 모양 | 표로 정리, 500자 이내, 소제목 사용 |
| 금지·주의 | 하지 말아야 할 것 | 과장 표현 금지, 확인 안 된 수치 쓰지 않기 |

아래는 쇼핑몰 상세페이지 문구를 만드는 프로젝트에 넣을 수 있는 지침 예시입니다.

```
너는 수제 디퓨저를 파는 온라인 쇼핑몰의 카피라이터야.
주요 고객은 20~30대 직장인이고, 말투는 차분하고 친절한 존댓말로 써.

결과물 규칙
- 상세페이지 문구는 제목 1줄, 핵심 장점 3개, 사용 방법 순서로 써.
- 장점은 표로 정리하고, 한 줄은 30자를 넘기지 마.
- "최고", "무조건" 같은 과장 표현은 쓰지 마.
- 프로젝트에 올린 상품 정보 파일에 없는 수치(용량, 지속 시간)는 지어내지 말고 물어봐.
```

지침을 쓴 뒤에는 새 대화를 열어 짧은 요청을 한 번 해 보고, 원하는 형식과 다르면 지침 문장을 고치는 식으로 다듬으면 됩니다. 지침이 너무 길고 규칙이 많으면 서로 부딪히는 경우가 있으니, 꼭 필요한 규칙부터 적는 것이 좋습니다.

## 프로젝트 파일(소스) 추가와 요금제별 한도

프로젝트에 파일을 올려 두면 그 안의 모든 대화가 파일 내용을 참고합니다. 회사 소개서, 상품 정보, 스타일 가이드, 자주 쓰는 데이터처럼 반복해서 참고하는 자료를 넣어 두기 좋습니다. 2026년 11월 기준 OpenAI 도움말에 적힌 한도는 다음과 같습니다.

| 요금제 | 프로젝트당 파일 수 | 공유 시 함께할 수 있는 인원 |
|---|---|---|
| Free(무료) | 5개 | 5명 |
| Go, Plus | 25개 | 10명 |
| Pro | 40개 | 100명 |
| Business, Enterprise, Edu | 40개 | 100명 |

한 번에 올릴 수 있는 파일은 10개까지입니다. 무료 요금제는 파일이 5개뿐이라, 여러 자료를 하나의 문서로 합쳐 올리는 편이 효율적입니다.

파일 외에 Google 드라이브의 파일·폴더나 Slack 채널을 링크로 붙여 넣어 소스로 추가할 수도 있습니다. 다만 Google 드라이브 내용은 미리 동기화되지 않고, 필요할 때 검색해서 가져오는 방식이라고 안내되어 있습니다. 엑셀처럼 큰 파일이 올라가지 않는다면 [챗GPT 엑셀 업로드 오류](../chatgpt-excel-upload-error/) 글의 해결 순서를 참고하세요.

## 프로젝트 전용 메모리와 기본 메모리 차이

프로젝트는 만들 때나 나중에 프로젝트 설정에서 메모리 방식을 고를 수 있습니다. 어떤 방식을 고르느냐에 따라 ChatGPT가 프로젝트 밖의 정보를 참고하는지가 달라집니다.

| 항목 | 기본 메모리 | 프로젝트 전용 메모리 |
|---|---|---|
| 계정에 저장된 메모리 참고 | 참고함 | 참고하지 않음 |
| 프로젝트 밖 대화 참고 | 참고할 수 있음 | 참고하지 않음 |
| 어울리는 용도 | 개인 업무, 내 취향을 반영해야 하는 일 | 고객별·과제별로 정보를 섞지 않아야 하는 일 |
| 공유 프로젝트 | 해당 없음 | 공유 프로젝트는 항상 이 방식 사용 |

고객사 A와 고객사 B의 일을 따로 하는 경우처럼 정보가 섞이면 곤란한 작업이라면 프로젝트 전용 메모리를 추천합니다. 설정을 바꾼 뒤 적용되기까지 몇 시간이 걸릴 수 있다고 안내되어 있으니, 바꾸자마자 결과가 달라지지 않아도 잠시 기다려 보세요.

## 챗GPT 프로젝트 공유방법

프로젝트는 다른 사람을 초대해 함께 쓸 수 있습니다. 공유 기능은 Free(무료), Go, Plus, Pro, Business, Enterprise, Edu에서 쓸 수 있고, 초대할 때 권한을 두 가지 중에서 고릅니다.

| 권한 | 할 수 있는 일 | 할 수 없는 일 |
|---|---|---|
| 편집(Edit) | 지침 수정, 파일 추가·삭제, 다른 사람 초대 | 같은 대화를 여러 사람이 동시에 고쳐 쓰기 |
| 채팅(Chat) | 프로젝트 내용 보기, 대화하기 | 다른 사람 초대, 지침·파일 수정 |

공유 프로젝트에서 여러 사람이 같은 대화를 동시에 고쳐 쓸 수는 없고, 다른 사람의 대화에서 갈라져 나온 새 대화(분기)를 만들어 이어 가는 방식입니다. 공유 프로젝트에서 나갈 때는 내가 나눈 대화를 원래 이름 앞에 'Copy'가 붙은 새 프로젝트로 복사해 둘 수 있습니다.

팀에서 쓴다면 지침과 파일은 편집 권한을 가진 한두 사람만 관리하고, 나머지는 채팅 권한으로 초대하는 방식이 혼선을 줄입니다.

## 챗GPT 프로젝트가 사라짐·불러올 수 없을 때

프로젝트나 그 안의 대화가 보이지 않는다는 문의가 종종 있습니다. 실제로 삭제된 것인지, 화면에서만 안 보이는 것인지를 먼저 구분해야 합니다.

| 상황 | 확인할 점 | 해결 방향 |
|---|---|---|
| 사이드바에 프로젝트가 안 보임 | 다른 계정이나 워크스페이스로 로그인했는지 | 프로필 메뉴에서 계정·워크스페이스 전환 |
| '프로젝트를 불러올 수 없습니다' 안내 | 일시적인 접속·서비스 문제인지 | 새로고침, 다른 브라우저, OpenAI 상태 페이지 확인 |
| 공유 프로젝트가 사라짐 | 소유자가 삭제했거나 내 초대가 해제됐는지 | 프로젝트 소유자에게 문의 |
| 대화가 프로젝트에서 빠짐 | '프로젝트에서 제거'를 눌렀는지 | 일반 대화 목록에서 찾아 다시 이동 |
| 프로젝트를 직접 삭제함 | 삭제는 되돌릴 수 없음 | 복구 불가, 다른 곳에 저장한 파일만 남음 |

프로젝트를 삭제하면 그 안의 대화, 지침, 프로젝트에만 저장된 파일이 함께 지워지고 되돌릴 수 없습니다. 라이브러리 등 다른 곳에 따로 저장된 파일은 지워지지 않습니다. 중요한 지침 문장은 메모장 같은 곳에 따로 백업해 두는 것을 추천합니다.

## 프로젝트로 하기 좋은 일

프로젝트는 같은 배경 정보를 여러 번 쓰는 일일수록 효과가 큽니다. 아래는 많이 쓰이는 활용 예시입니다.

| 활용 | 지침에 넣을 것 | 파일로 올릴 것 |
|---|---|---|
| 블로그·SNS 원고 | 말투, 글 길이, 금지 표현 | 기존 글 샘플, 브랜드 소개 |
| 쇼핑몰 운영 | 상품 문구 형식 | 상품 정보표, 자주 묻는 질문 |
| 보고서·회의 정리 | 보고서 양식, 요약 길이 | 회의록, 지난 보고서 |
| 공부·자격증 준비 | 설명 수준, 문제 출제 방식 | 교재 요약, 기출 정리 |
| 외주 작업 관리 | 고객별 요구사항 | 계약 범위, 참고 자료 |

글쓰기 작업에 지침을 어떻게 쓰면 좋은지는 [클로드 블로그 글쓰기 프롬프트](../claude-blog-draft-writing/) 글의 초안·검수 요령도 함께 참고할 수 있습니다. 여러 자료를 모아 요약하는 일이 중심이라면 [NotebookLM 사용법](../notebooklm-guide/)과 비교해 보고 고르는 것도 방법입니다.

## 마무리

챗GPT 프로젝트 사용법의 핵심은 **반복해서 설명하던 내용을 지침으로, 반복해서 올리던 자료를 파일로** 옮겨 두는 것입니다. 프로젝트는 무료 요금제에서도 쓸 수 있지만 파일 수(무료 5개, Plus 25개, Pro 40개)와 공유 인원에 차이가 있으니, 자료가 많다면 파일을 합쳐 올리거나 요금제를 비교해 보세요. 정보가 섞이면 안 되는 일은 프로젝트 전용 메모리로 설정하고, 삭제는 되돌릴 수 없다는 점도 기억해 두는 것이 좋습니다.

요금제별 한도와 기능은 자주 바뀌므로 중요한 작업 전에는 OpenAI 도움말에서 현재 조건을 확인하시기 바랍니다.
