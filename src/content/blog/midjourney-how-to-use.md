미드저니 사용법을 찾는 분들은 대개 "디스코드를 꼭 써야 하는지", "어디에 프롬프트를 넣는지", "만든 그림을 어떻게 고치고 내려받는지"를 궁금해합니다. 이 글은 미드저니를 처음 쓰는 분을 위해 2026년 11월 기준 공식 문서를 바탕으로 웹사이트(midjourney.com)에서 첫 이미지를 만들고, 수정하고, 저장하는 과정을 순서대로 정리합니다. 요금제 자체가 궁금하다면 [미드저니 가격 정리](../midjourney-pricing/) 글을 먼저 보셔도 좋습니다.

## 미드저니 사용법 한눈에 보기

결론부터 말하면 지금은 **디스코드 없이 웹사이트에서 모든 작업을 할 수 있습니다.** 로그인하고 구독한 뒤 Create 페이지 맨 위의 입력창(Imagine bar)에 영어 프롬프트를 넣으면 이미지 4장이 한 묶음으로 만들어집니다.

| 단계 | 할 일 | 위치 |
|---|---|---|
| 1 | 구글 또는 디스코드 계정으로 로그인 | midjourney.com |
| 2 | 요금제 선택 후 구독 | 계정 메뉴의 구독 페이지 |
| 3 | 기본 설정(비율·모델·스타일 강도) 정하기 | Imagine bar의 설정 아이콘 |
| 4 | 프롬프트 입력 후 Enter | Create 페이지 맨 위 Imagine bar |
| 5 | 마음에 드는 이미지를 Vary·Upscale·Edit로 다듬기 | 이미지를 크게 연 화면의 Creation Actions |
| 6 | 다운로드 | 전체 화면 보기의 다운로드 버튼 또는 Organize 페이지 |

2026년 11월 기준 기본 이미지 모델은 2026년 7월 24일부터 기본값이 된 **V8.2**입니다. 메뉴 이름과 기능은 모델이 바뀔 때 함께 바뀌는 경우가 많으니, 아래 내용과 화면이 다르면 공식 문서를 확인하세요.

## 가입과 로그인 — 디스코드 없이도 되나요?

미드저니 공식 도움말에 따르면 로그인 방법은 **디스코드와 구글 두 가지뿐**입니다. 미드저니 전용 아이디·비밀번호를 따로 만드는 방식은 없습니다. 디스코드를 쓰지 않는 분이라면 구글 계정으로 로그인하면 됩니다.

| 상황 | 추천 로그인 방법 | 주의할 점 |
|---|---|---|
| 처음 가입하는 분 | 구글 또는 디스코드 중 편한 것 | 나중에 계정 설정에서 다른 방법을 추가로 연결 가능 |
| 예전에 디스코드에서 미드저니를 쓴 분 | 디스코드 | 2024년 8월 이전 계정은 디스코드 전용이었으므로 디스코드로 먼저 로그인 |
| 구글로 가입해 이미 구독한 분 | 구글 | 이미지 기록이 있는 다른 디스코드 계정은 나중에 연결할 수 없음 |
| 계정 두 개가 따로 생긴 경우 | 지원팀 문의 | 한 계정의 구독과 다른 계정의 작업 기록은 합칠 수 없음 |

가장 흔한 실수는 예전에 디스코드로 쓰던 분이 구글로 새로 가입해 구독하는 경우입니다. 이렇게 하면 과거 작업 기록이 있는 계정과 구독 계정이 갈라지니, 기존 사용자는 반드시 원래 쓰던 방법으로 먼저 로그인하세요.

## 미드저니 무료로 사용법 익힐 수 있나요?

웹사이트와 디스코드에서는 무료 체험이 없어서 **구독을 해야 첫 이미지를 만들 수 있습니다.** 가장 저렴한 Basic 요금제가 월 10달러이고, 연간 결제는 20% 할인됩니다(2026년 11월 공식 요금제 문서 기준). 요금제별 사용 시간과 환불 조건은 [미드저니 가격](../midjourney-pricing/) 글에 자세히 정리했습니다.

처음이라면 Basic 월 결제로 시작해 한 달 동안 기능을 익히고, 사용량이 부족하면 상위 요금제로 바꾸는 방법이 부담이 적습니다. 환불은 계정 전체 사용 GPU 시간이 20분 미만일 때만 가능하므로, 결제 직후 많이 생성하기 전에 판단하는 것이 좋습니다.

## 첫 이미지 만들기 — Imagine bar와 설정 메뉴

로그인 후 왼쪽 메뉴에서 **Create**를 누르면 맨 위에 프롬프트 입력창인 Imagine bar가 보입니다. 여기에 원하는 장면을 영어로 적고 Enter를 누르면 진행률이 100%가 될 때까지 생성되고, 이미지 4장이 한 묶음으로 나타납니다. Ctrl(맥은 Cmd)+Enter를 누르면 프롬프트를 실행하면서 입력한 문장을 입력창에 그대로 남겨 두어, 단어 몇 개만 바꿔 다시 실행하기 편합니다.

처음 써 보기 좋은 프롬프트 예시는 아래와 같습니다.

```
a cozy coffee shop on a rainy evening, warm window light, people reading books, cinematic photo --ar 16:9
```

```
a cute ceramic cat figurine on a wooden shelf, soft morning light, product photo, white background --ar 1:1
```

Imagine bar 오른쪽의 **설정 아이콘**을 누르면 매번 파라미터를 적지 않아도 기본값을 바꿀 수 있습니다.

| 설정 메뉴 | 들어 있는 항목 | 이렇게 쓰면 편합니다 |
|---|---|---|
| Aspect Ratio | 이미지 가로세로 비율 | 쇼츠·릴스용이면 9:16, 블로그 대표 이미지면 16:9로 미리 설정 |
| Model | SD/HD 선택, 기본 모델 버전, Raw 켜기 | 시안은 SD, 최종본만 HD로 만들면 사용 시간 절약 |
| Aesthetics | Stylization, Weirdness, Variety | 프롬프트대로 담백하게 원하면 Stylization을 낮추기 |
| More Options | GPU 속도(Fast·Relax 등), Stealth 모드, 영상 해상도·묶음 수 | Relax가 있는 요금제라면 급하지 않은 작업은 Relax로 |

Imagine bar의 **이미지 아이콘**으로 사진을 올릴 수도 있습니다. 올린 이미지는 Edit Model 참조, 스타일 참조(Style Reference), 이미지 프롬프트, 영상으로 움직이기(Animate) 중 하나로 쓰이며, 한 장당 최대 10MB까지 올릴 수 있습니다. 자물쇠 아이콘을 누르면 올린 이미지를 다음 프롬프트에도 계속 붙여 둘 수 있습니다.

## 만든 이미지 수정하기 — Vary·Upscale·Edit 버튼

4장 중 마음에 드는 이미지를 클릭해 크게 열면 **Creation Actions** 버튼이 보입니다. 버튼이 안 보이면 More options에서 켤 수 있습니다.

| 버튼 | 하는 일 | 이럴 때 씁니다 |
|---|---|---|
| Vary (Subtle) | 원본을 조금만 바꾼 변형 생성 | 구도는 좋은데 표정·소품만 살짝 다르게 보고 싶을 때 |
| Vary (Strong) | 원본에서 크게 바꾼 변형 생성 | 방향은 맞는데 다른 해석을 더 보고 싶을 때 |
| Upscale (Subtle) | 그림을 거의 바꾸지 않고 크기만 키움 | 원본 그대로 인쇄·대표 이미지로 쓸 때 |
| Upscale (Creative) | 크기를 키우면서 세부 묘사를 더함 | 질감과 디테일을 보강하고 싶을 때 |
| Remix | 프롬프트와 파라미터를 바꿔 다시 생성 | 같은 그림에서 계절·색감만 바꾸고 싶을 때 |
| Use | 이미지를 이미지 프롬프트·스타일 참조로 쓰거나 프롬프트 복사 | 같은 분위기로 연작을 만들 때 |
| Quick Edit / Open Editor | 글로 지시해 고치거나 편집기에서 부분 수정 | 배경 교체, 일부 지우기, 캔버스 넓히기 |
| Animate (Auto·Manual) | 이미지를 5초 영상으로 변환 | 숏폼용 짧은 움직임이 필요할 때 |

**Editor(편집기)** 에서는 일부 영역만 다시 그리는 Vary Region·Erase, 한쪽 방향으로 캔버스를 넓히는 Pan, 사방으로 넓히는 Zoom Out을 쓸 수 있습니다. 편집 중인 이미지는 Edit 페이지에 남아 있으므로 나중에 돌아와 이어서 작업할 수 있습니다.

V8.1·V8.2에서는 예전의 Omni Reference와 Character Reference가 **Edit Model**로 통합되었습니다. 참조 이미지를 최대 4장까지 넣고 "change the jacket to navy blue"처럼 영어 문장으로 수정 지시를 내리는 방식입니다. Edit Model은 `--tile`과 함께 쓸 수 없고, 그 결과물은 Remix에 쓸 수 없다는 제한이 있습니다.

## 자주 쓰는 미드저니 파라미터

파라미터는 프롬프트 맨 뒤에 붙이는 옵션입니다. 공식 문서는 대시 두 개(`--`) 앞에는 띄어쓰기를 하고, 대시 사이에는 띄어쓰지 않으며, 파라미터 안에 문장 부호를 넣지 말라고 안내합니다.

| 파라미터 | 쓰는 법 | 하는 일 |
|---|---|---|
| 비율 | `--ar 16:9` | 기본 정사각형 대신 원하는 비율로 생성 |
| 제외 | `--no text` | 넣고 싶지 않은 요소를 제외 (V8.2 지원) |
| 스타일 강도 | `--s 50` | 미드저니 특유의 미적 보정을 얼마나 넣을지 조절 |
| Raw | `--raw` | 보정을 줄여 프롬프트를 더 그대로 반영 |
| 다양성 | `--c 20` | 4장 사이의 차이를 키움 |
| 스타일 참조 | `--sref` + 이미지 주소 | 다른 이미지의 그림체·색감을 따라감 |
| 고해상도 | `--hd` | 2048px로 생성 (`--sd`는 1024px) |
| 반복 패턴 | `--tile` | 이어 붙여도 끊기지 않는 무늬 생성 |
| 버전 | `--v 8.1` | 기본 모델 대신 다른 버전으로 생성 |

공식 버전 문서 기준으로 SD 이미지 프롬프트 1회는 GPU 시간 약 0.8분, HD는 약 1.3분이 듭니다. 처음에는 SD로 여러 번 뽑아 방향을 정하고, 고른 이미지만 HD로 다시 만드는 순서가 사용 시간을 아끼는 방법입니다. 이미지를 크게 연 화면의 More Options에 있는 Run as HD로 SD 이미지를 HD로 다시 실행할 수 있습니다. 참고로 시안을 절반 비용으로 뽑는 Draft 모드는 V8.2에서는 지원되지 않습니다.

프롬프트 문장 자체를 어떻게 구성할지는 [AI 이미지 프롬프트 작성법](../ai-image-prompt-formula/) 글의 5칸 공식을 참고하면 도움이 됩니다.

## 저장·다운로드와 자주 막히는 부분

만든 이미지는 크게 연 화면의 **다운로드 버튼**이나 More Options 메뉴의 download로 내려받을 수 있습니다. 여러 장을 정리할 때는 왼쪽 메뉴의 **Organize** 페이지에서 폴더로 묶고, 정렬·필터로 찾은 뒤 내려받는 편이 편합니다. 지운 이미지도 Organize 페이지의 휴지통에서 되살릴 수 있습니다.

| 막히는 상황 | 확인할 것 |
|---|---|
| 프롬프트를 넣어도 생성이 안 됨 | 구독이 활성 상태인지, Basic에서 Fast 시간을 다 썼는지 계정 페이지에서 확인 |
| 이미지 업로드가 안 됨 | 파일 크기가 10MB를 넘는지 확인 |
| Vary·Upscale 버튼이 안 보임 | 이미지를 클릭해 크게 연 뒤 More options에서 Creation Actions 켜기 |
| 내 이미지가 다른 사람에게 보임 | Stealth 모드는 Pro·Mega 요금제에서만 가능 |
| 예전 작업 기록이 사라짐 | 다른 로그인 방법으로 새 계정이 생겼을 수 있으니 원래 방법으로 다시 로그인 |
| 한국어 프롬프트 결과가 엉뚱함 | 공식 문서 예시는 영어 기준이므로 번역기로 영어 문장을 만들어 입력 |

결제 오류나 계정 연결 문제처럼 설정으로 해결되지 않는 문제는 공식 도움말 사이트의 지원 메뉴로 문의해야 합니다. 로그인 방법 연결 해제도 결제 지원팀에서만 처리한다고 안내되어 있습니다.

## 마무리

미드저니 사용법의 핵심은 세 가지입니다. 첫째, 디스코드 없이 구글 계정으로 로그인해 웹 Create 페이지에서 바로 쓸 수 있습니다. 둘째, 설정 아이콘으로 비율과 SD·HD를 미리 정해 두면 프롬프트가 짧아집니다. 셋째, 4장 중 고른 이미지를 Vary로 변형하고, Edit로 고치고, Upscale·HD로 마무리하는 순서로 작업하면 사용 시간을 아낄 수 있습니다. 미드저니는 모델 업데이트가 잦아 버튼 이름이나 지원 기능이 바뀌는 경우가 많으니, 화면이 이 글과 다르면 공식 문서의 최신 안내를 확인하시기 바랍니다.
