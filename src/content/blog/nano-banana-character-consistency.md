AI로 시리즈 영상이나 광고를 만들 때 가장 골치 아픈 문제는 **장면마다 인물 얼굴이 바뀌는 것**입니다. 구글의 이미지 모델 나노바나나(Nano Banana)는 참조 이미지를 넣으면 같은 인물을 비교적 잘 유지해 줘서, 영상용 캐릭터를 만들 때 많이 쓰입니다. 이 글에서는 나노바나나로 캐릭터 일관성을 유지하는 방법을 정리했습니다.

> ✍️ 직접 작성: 나노바나나를 어떤 작업에 쓰는지, 캐릭터 얼굴이 바뀌어서 곤란했던 경험이 있다면 한두 문장.

## 나노바나나란?

나노바나나는 구글 Gemini의 이미지 생성·편집 모델에 붙은 별명입니다. 2026년 기준으로 많이 쓰는 버전은 이렇습니다.

| 버전 | 정식 이름 | 특징 |
|---|---|---|
| 나노바나나 | Gemini 2.5 Flash Image | 2025년 8월 공개, 빠르고 저렴, 캐릭터 일관성으로 유명해짐 |
| 나노바나나 2 | 후속 Flash 이미지 모델 | 속도와 품질 균형, Pro의 절반 정도 가격 |
| 나노바나나 Pro | Gemini 3 Pro Image | 고품질, 글자·인포그래픽 표현 강함, 참조 이미지 여러 장 활용 |

나노바나나 Pro는 한 장면에서 **최대 5명의 인물을 일관되게 유지**하고, 참조 이미지를 **최대 14장까지** 합칠 수 있다고 알려져 있습니다.

## 무료와 유료 차이

| 구분 | 사용처 | 제한 |
|---|---|---|
| 무료 | Gemini 앱 | Pro 모델은 하루 몇 장 수준으로 제한, 이후 기본 모델로 전환 |
| 구독 (Google AI Pro 등) | Gemini 앱, Flow | 사용량이 크게 늘어남 |
| API | 개발자용 | Pro 기준 1K·2K 이미지 장당 약 $0.134, 4K 약 $0.24 |

무료 한도와 요금은 자주 바뀌니 Gemini 앱에서 현재 한도를 확인하세요.

> ✍️ 직접 작성: 지금 무료로 쓰는지 유료로 쓰는지, 한 달에 대략 몇 장 정도 만드는지.

## 1단계: 기준 이미지(캐릭터 시트) 만들기

일관성의 핵심은 **처음 한 장을 잘 만드는 것**입니다. 이 한 장이 이후 모든 장면의 기준이 됩니다.

| 체크 항목 | 이유 |
|---|---|
| 정면, 얼굴이 크고 선명하게 | AI가 얼굴 특징을 정확히 읽음 |
| 단순한 배경 (흰색, 회색) | 배경이 인물 특징과 섞이지 않음 |
| 머리 모양·옷을 구체적으로 | 이후 장면에서도 같은 스타일 유지 |
| 조명은 고르게 | 그림자가 얼굴 특징을 가리지 않음 |

기준 이미지 프롬프트 예시:

```
한국인 30대 여성, 어깨 길이 검은 단발머리, 흰 셔츠와 베이지 재킷.
정면을 보고 살짝 미소. 단순한 밝은 회색 배경, 고른 스튜디오 조명, 사진처럼 사실적으로.
```

여유가 있다면 같은 인물의 **정면, 측면, 전신** 세 장을 만들어 두면 이후 장면에서 훨씬 안정적입니다.

## 2단계: 참조 이미지로 새 장면 만들기

새 장면을 만들 때는 기준 이미지를 첨부하고, **"이 인물을 유지하라"**는 문장을 프롬프트 맨 앞에 씁니다.

```
첨부한 이미지 속 여성과 같은 인물. 얼굴, 머리 모양, 옷은 그대로 유지.
아파트 거실 소파에 앉아 커피를 마시고 있다. 창으로 오후 햇살. 미디엄샷.
```

| 잘 되는 요청 | 잘 안 되는 요청 |
|---|---|
| 장소, 자세, 표정 바꾸기 | 나이, 체형을 크게 바꾸기 |
| 옷 하나만 바꾸기 | 옷·머리·배경을 한꺼번에 바꾸기 |
| 카메라 거리 바꾸기 (미디엄 → 클로즈업) | 얼굴이 아주 작은 롱샷 |
| 기준 이미지 1~3장 첨부 | 서로 다른 인물 사진 여러 장 섞기 |

## 3단계: 바뀐 부분만 고치기

결과가 90% 마음에 드는데 일부만 이상하다면, 처음부터 다시 만들지 말고 **편집 요청**을 하세요. 나노바나나는 대화하듯 수정하는 데 강합니다.

| 상황 | 편집 요청 예시 |
|---|---|
| 머리 색이 달라짐 | 머리 색을 첨부 이미지처럼 검은색으로 바꿔줘 |
| 옷이 바뀜 | 다른 건 그대로 두고 재킷만 베이지색으로 |
| 표정이 어색함 | 표정만 자연스러운 미소로 바꿔줘 |
| 배경이 과함 | 인물은 그대로, 배경만 더 단순하게 |

> ✍️ 직접 작성: 본인만의 일관성 유지 요령 1~2개. 예를 들어 기준 이미지를 몇 장 쓰는지, 실패했을 때 어떻게 고치는지.

## 4단계: 영상 도구로 넘기기

일관된 이미지가 준비되면 클링이나 Seedance의 **이미지로 영상 만들기**에 넣습니다. 장면마다 같은 인물 이미지를 쓰니 영상에서도 얼굴이 유지됩니다. 자세한 방법은 [이미지 한 장으로 AI 영상 만들기](../image-to-video-guide/) 글을 참고하세요.

## 자주 생기는 문제

| 문제 | 해결 |
|---|---|
| 몇 장 만들다 보면 점점 얼굴이 달라짐 | 직전 결과가 아니라 항상 **처음 기준 이미지**를 참조로 첨부 |
| 동양인 얼굴이 서양인처럼 바뀜 | "한국인", 나이대, 얼굴 특징을 프롬프트에 매번 명시 |
| 두 인물이 섞임 | 인물별 기준 이미지를 따로 만들고, 프롬프트에서 "왼쪽 인물", "오른쪽 인물"로 구분 |
| 글자가 깨짐 | 글자는 편집 프로그램에서 따로 넣기 (Pro 모델은 비교적 잘 그림) |

## 마무리

캐릭터 일관성은 "좋은 기준 이미지 한 장 + 매번 그 이미지를 참조"가 전부라고 해도 과언이 아닙니다. 기준 이미지를 만드는 데 시간을 들일수록 이후 장면과 영상 작업이 훨씬 편해집니다.

> ✍️ 직접 작성: 한 줄 총평. 나노바나나를 다른 이미지 도구와 비교했을 때 느낀 점.
