매출 정리, 주문 목록 정리, 설문 결과 집계처럼 매주 반복되는 스프레드시트 작업은 ChatGPT에 맡길 수 있는 부분이 꽤 많습니다. 이 글은 엑셀이나 구글시트를 자주 쓰지만 함수와 매크로에는 자신이 없는 직장인, 1인 사업자, 온라인 판매자를 위해 ChatGPT로 스프레드시트 업무를 줄이는 방법을 정리합니다. 기능과 요금은 2026년 10월 기준 OpenAI와 구글의 공식 안내를 바탕으로 했습니다.

## ChatGPT로 스프레드시트를 다루는 세 가지 방법

ChatGPT를 스프레드시트 업무에 쓰는 방법은 크게 세 가지입니다. 무엇을 하고 싶은지에 따라 고르면 됩니다.

| 방법 | 작업 방식 | 잘 맞는 일 | 주의할 점 |
|---|---|---|---|
| 채팅에서 함수·코드 요청 | 상황을 설명하고 함수나 매크로 코드를 받아 직접 붙여넣기 | VLOOKUP, SUMIFS 같은 함수 작성, 오류 원인 찾기 | 파일을 올리지 않으므로 표 구조를 글로 정확히 설명해야 함 |
| 파일을 올려 분석 요청 | .xlsx, .xls, .csv 파일을 채팅에 올리고 정리·분석 요청 | 중복 제거, 집계, 차트, 정리된 새 파일 받기 | 회사 기밀·개인정보가 담긴 파일은 올리기 전에 확인 |
| 엑셀·구글시트 안에서 ChatGPT 사용 | 추가 기능(애드인)을 설치해 시트 옆 패널에서 대화 | 열려 있는 시트를 보면서 수식 작성, 표 수정 | 요금제별 사용 한도가 있고, 회사 계정은 관리자 설정이 필요할 수 있음 |

처음이라면 **채팅에서 함수 요청**부터 시작하는 것을 추천합니다. 파일을 밖으로 보내지 않아도 되고, 받은 함수를 직접 넣어 보면서 원리를 함께 익힐 수 있습니다.

## 요금제와 이용 조건 (2026년 10월 기준)

파일 업로드와 데이터 분석은 OpenAI 도움말 기준 무료와 유료 요금제 모두에서 쓸 수 있지만, 요금제별 사용 한도가 다릅니다. 엑셀·구글시트용 ChatGPT 추가 기능은 2026년 3월 베타로 시작해 5월에 모든 요금제로 확대되었습니다.

| 요금제 | 월 요금 | 파일 업로드·분석 | 엑셀·구글시트 추가 기능 |
|---|---|---|---|
| Free | $0 | 사용 가능, 한도가 낮음 | 제한된 사용량 |
| Go | 미국 기준 $8 (일부 국가는 현지 가격) | 사용 가능 | 제한된 사용량 |
| Plus | $20 | 사용 가능, 한도가 더 넉넉함 | 요금제의 에이전트 사용 한도 안에서 사용 |
| Pro | 공식 요금 페이지에서 확인 | 사용 가능 | 요금제의 에이전트 사용 한도 안에서 사용 |
| Business·Enterprise | 공식 요금 페이지에서 확인 | 사용 가능 | 조직의 크레딧·이용 조건에 따름 |

OpenAI 도움말에 따르면 업로드 파일 하나의 최대 크기는 512MB이고, CSV와 스프레드시트는 행 크기에 따라 약 50MB를 넘기 어렵습니다. 원화 결제 금액과 세부 한도는 계정과 결제 경로(웹, 앱스토어)에 따라 다르게 보일 수 있으니 결제 전에 공식 요금 페이지에서 확인하세요.

## 함수와 수식을 대신 짜 달라고 하기

ChatGPT에 함수를 요청할 때 가장 중요한 것은 **표 구조를 정확히 알려 주는 것**입니다. 어느 열에 무엇이 있고, 결과를 어디에 넣을지 적어 주면 바로 붙여넣을 수 있는 수식이 나옵니다.

```
엑셀에서 쓸 수식을 만들어 주세요.
- 시트 '주문'의 A열: 주문일(날짜), B열: 상품명, C열: 수량, D열: 판매가
- 시트 '요약'의 A2부터 상품명이 한 줄씩 있습니다.
- 요약 시트 B2에, 해당 상품의 2026년 9월 매출 합계(수량×판매가)를 구하는 수식을 넣고 싶습니다.
- 엑셀 2021 이후 버전입니다. 수식이 어떻게 작동하는지 한 줄로 설명해 주세요.
```

자주 쓰는 요청을 유형별로 정리하면 아래와 같습니다.

| 하고 싶은 일 | 요청 예시 | ChatGPT가 주로 제안하는 함수 |
|---|---|---|
| 다른 표에서 값 가져오기 | "상품코드로 가격표 시트에서 단가를 찾아와 주세요" | XLOOKUP, VLOOKUP, INDEX·MATCH |
| 조건별 합계·개수 | "지역이 서울이고 9월인 주문의 합계를 구해 주세요" | SUMIFS, COUNTIFS |
| 텍스트 나누기·합치기 | "주소에서 시·도만 뽑아 주세요" | TEXTSPLIT, LEFT, FIND, SPLIT(구글시트) |
| 날짜 계산 | "주문일로부터 영업일 기준 3일 뒤 배송 예정일" | WORKDAY, EDATE |
| 중복·고유값 | "고객 이름 목록에서 중복 없이 뽑아 주세요" | UNIQUE, COUNTIF |
| 오류 숨기기 | "값이 없으면 #N/A 대신 빈칸으로 보여 주세요" | IFERROR, IFNA |

엑셀과 구글시트는 함수 이름은 비슷해도 지원 범위가 조금씩 다릅니다. 요청할 때 **어떤 프로그램과 버전을 쓰는지** 꼭 적어 주세요. 수식에서 오류가 나면 오류 메시지와 수식을 그대로 붙여넣고 "왜 이 오류가 나는지 알려 주세요"라고 물으면 원인을 짚어 주는 경우가 많습니다.

## 파일을 올려 데이터 정리·분석 맡기기

여러 사람이 입력해 형식이 뒤죽박죽인 표, 쇼핑몰에서 내려받은 주문 내역처럼 손으로 정리하기 번거로운 데이터는 파일째 올려 정리를 맡기는 방법이 편합니다. OpenAI는 열 이름이 분명하고 한 행에 하나의 기록이 들어간 구조로 올리고, 원하는 계산이나 차트 종류를 구체적으로 적으라고 안내합니다.

```
첨부한 주문내역.xlsx를 정리해 주세요.
1. '연락처' 열의 전화번호를 010-0000-0000 형식으로 통일
2. 주문번호가 같은 중복 행 제거 (몇 행이 지워졌는지 알려 주기)
3. 상품별 월간 매출 합계 표 만들기
4. 정리한 결과를 새 엑셀 파일로 내려받을 수 있게 해 주세요.
원본에서 바꾼 내용은 따로 목록으로 정리해 주세요.
```

| 작업 단계 | 요청 요령 | 확인할 것 |
|---|---|---|
| 올리기 전 | 개인정보 열(이름, 연락처)은 지우거나 가명으로 바꾸기 | 회사 보안 규정상 외부 업로드가 허용되는지 |
| 정리 요청 | 바꿀 규칙을 번호를 붙여 하나씩 적기 | 규칙이 서로 충돌하지 않는지 |
| 분석 요청 | "상품별·월별 합계", "막대 차트"처럼 기준을 구체적으로 | 합계가 원본 합계와 맞는지 |
| 결과 받기 | 새 파일로 내려받기, 바꾼 내용 목록 요청 | 행 수, 빈칸, 날짜 형식이 그대로인지 |
| 반복 업무 | 매주 같은 작업이면 요청문을 메모장에 저장해 재사용 | 매번 같은 결과가 나오는지 표본 몇 줄 비교 |

정리 결과는 그럴듯해 보여도 일부 행이 빠지거나 날짜가 다른 형식으로 바뀌는 경우가 있습니다. **원본 파일은 그대로 두고**, 받은 파일의 합계와 행 수를 원본과 비교한 뒤 쓰는 습관을 들이세요.

## 엑셀·구글시트 안에서 바로 쓰는 방법

창을 오가며 복사·붙여넣기를 하는 게 번거롭다면 시트 안에서 AI를 부르는 방법이 있습니다. ChatGPT 추가 기능과 구글시트 자체 AI 함수가 대표적입니다.

| 구분 | 엑셀용 ChatGPT | 구글시트용 ChatGPT | 구글시트 AI 함수 |
|---|---|---|---|
| 만든 곳 | OpenAI | OpenAI | 구글 (Gemini) |
| 설치 방법 | 홈 탭 → 추가 기능에서 ChatGPT 검색 후 추가 | Google Workspace Marketplace에서 설치 후 확장 프로그램 메뉴에서 실행 | 별도 설치 없이 셀에 =AI("요청", 범위) 입력 |
| 필요한 계정 | 지원 요금제의 ChatGPT 계정 | 지원 요금제의 ChatGPT 계정 | 대상 Google Workspace 요금제 또는 Google AI Pro·Ultra |
| 작업 방식 | 패널에서 대화하며 수식·표 수정 | 패널에서 대화하며 수식·표 수정 | 행마다 분류, 요약, 번역 결과를 셀에 채움 |
| 잘 맞는 일 | 모델·시나리오 계산, 수식 정리 | 공유 시트 정리, 수식 작성 | 리뷰 감정 분류, 상품 설명 요약 같은 반복 텍스트 작업 |

구글시트 AI 함수는 구글 공식 업데이트 기준 한국어를 지원하며, 짧은 기간과 긴 기간 각각 생성 횟수 제한이 있습니다. 예를 들어 B열에 고객 리뷰가 있다면 아래처럼 쓰고 아래로 끌어 채우면 됩니다.

```
=AI("이 리뷰를 긍정, 부정, 중립 중 하나로만 분류해 주세요", B2)
```

회사 계정이라면 관리자가 기능을 꺼 두었을 수 있습니다. 메뉴가 보이지 않으면 사내 관리자에게 먼저 확인하세요.

## 반복 작업은 매크로·Apps Script로 묶기

매주 같은 순서로 정리하는 작업이라면 ChatGPT에 **매크로 코드**를 받아 버튼 하나로 끝내는 방법도 있습니다. 엑셀은 VBA, 구글시트는 Apps Script를 씁니다.

```
구글시트 Apps Script 코드를 만들어 주세요.
- '원본' 시트의 데이터를 읽어서
- E열(상태)이 '배송완료'인 행만 '완료' 시트에 복사하고
- 복사한 뒤 '원본' 시트에서는 그 행을 지우지 말고 F열에 '이동함'이라고 표시해 주세요.
- 코드를 처음 써 보는 사람 기준으로 붙여넣는 위치와 실행 방법도 단계별로 알려 주세요.
```

| 단계 | 엑셀 (VBA) | 구글시트 (Apps Script) |
|---|---|---|
| 코드 넣는 곳 | 개발 도구 탭 → Visual Basic | 확장 프로그램 → Apps Script |
| 파일 저장 | 매크로 사용 통합 문서(.xlsm)로 저장 | 시트에 자동 연결되어 저장 |
| 첫 실행 | 보안 경고에서 매크로 허용 | 권한 승인 화면에서 계정 접근 허용 |
| 테스트 | 복사본 파일에서 먼저 실행 | 복사본 시트에서 먼저 실행 |
| 자동 실행 | 버튼에 매크로 연결 | 트리거로 매일·매주 실행 예약 |

매크로는 실행하면 되돌리기(Ctrl+Z)가 안 되는 경우가 많습니다. 반드시 **복사본에서 먼저 실행**해 보고, 결과가 맞을 때 원본에 적용하세요.

## 자주 생기는 문제와 해결 방법

| 문제 | 흔한 원인 | 해결 방법 |
|---|---|---|
| 받은 수식이 #NAME? 오류 | 내 버전에 없는 함수(XLOOKUP 등) 사용 | 프로그램과 버전을 알려 주고 다른 함수로 다시 요청 |
| 범위가 하나씩 밀림 | 머리글 행 위치를 잘못 설명 | "1행은 제목, 데이터는 2행부터"처럼 명확히 적기 |
| 합계가 원본과 다름 | 숫자가 텍스트로 저장된 셀이 섞임 | 숫자 형식 변환을 먼저 요청하고 다시 계산 |
| 날짜가 이상하게 바뀜 | 날짜 형식(연-월-일, 월/일) 해석 차이 | 원하는 날짜 형식을 예시와 함께 지정 |
| 결과가 매번 조금씩 다름 | AI 답변은 같은 요청에도 달라질 수 있음 | 확정된 수식·코드는 저장해 두고 재사용 |
| 큰 파일이 처리되지 않음 | 파일 크기·행 수가 한도에 가까움 | 필요한 열만 남기거나 기간별로 나눠 올리기 |

ChatGPT가 만든 결과는 **초안**으로 보고, 숫자가 중요한 보고서나 정산 자료는 표본 몇 줄을 직접 계산해 맞는지 확인한 뒤 쓰는 것을 추천합니다.

## 마무리

ChatGPT로 스프레드시트 업무를 줄이는 가장 쉬운 출발점은 함수 요청입니다. 표 구조와 프로그램 버전을 정확히 알려 주면 대부분의 수식을 바로 받을 수 있고, 익숙해지면 파일 정리와 분석, 매크로까지 범위를 넓힐 수 있습니다. 시트 안에서 바로 쓰고 싶다면 엑셀·구글시트용 ChatGPT 추가 기능이나 구글시트 AI 함수를 검토해 보세요.

어떤 방법이든 원본을 따로 보관하고, 개인정보는 지우고 올리고, 결과 숫자는 한 번 더 확인하는 세 가지 습관이 중요합니다. 같은 방식으로 글쓰기 업무를 줄이는 방법은 [Claude로 블로그 글 초안 쓰는 법](../claude-blog-draft-writing/)에서, 콘텐츠 기획에 쓰는 프롬프트는 [ChatGPT로 숏폼 대본·콘티 짜는 법](../chatgpt-shorts-script/)에서 확인할 수 있습니다. 요금제와 기능은 자주 바뀌므로 결제 전에는 공식 페이지를 다시 확인하시기 바랍니다.
